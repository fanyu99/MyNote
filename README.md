## ✍️ 笔记规范

- 每篇笔记包含 `title / type / topic / status / created / tags` 等 frontmatter 字段。
- 正文只有一个 H1，且与 `title` 完全一致；H1 后紧跟一行 `>` 概述。
- 图片统一放在各主题的 `图片/` 目录，引用时使用相对路径并填写 `alt`。
- 白板统一放在各主题的 `白板/` 目录，`_总览.canvas` 作为两级白板结构的入口。
- 笔记模板位于 [[模板/_模板-通用笔记\|模板/]]，包括课程笔记、主题笔记与通用笔记三套。
