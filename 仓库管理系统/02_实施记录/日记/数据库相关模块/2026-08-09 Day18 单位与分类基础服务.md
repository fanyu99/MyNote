# 单位与分类基础服务

  

**目标：** 补齐物资主数据依赖的单位和分类基础服务，为产品创建、编辑、筛选和入库页面下拉选择提供稳定数据源。

  

**重点任务：**

  

- 设计 `UnitService`、`CategoryService` 及对应 Repository Port。

- 明确单位、分类的启用/停用、名称唯一性、排序和分页查询策略。

- 实现 Fake Repository 与应用服务测试，先保证 Service 层边界清晰。

- 再接入 MySQL Repository，保持与 Product/Inbound 模块一致的异步回调和错误映射风格。

  

**验收标准：**

  

- 单位和分类能够被查询、创建、更新、启用/停用。

- Product 与 Inbound 后续 UI 能通过服务层获取可用单位和分类。

- 权限、参数校验、重复名称和 owner 生命周期保护均有测试覆盖。
