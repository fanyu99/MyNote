# 回调函数链的传递
## 简而言之:这一步会将下一步回调后的结果进行包装成回调函数传递


1. 最顶层调用方:UI的UIcallback(内部接收ProductOperateResult)

2. 调用方(ProductService)的callback(内部接收UIcallback)

3. findById将callback包装为lambda(内部会包装callback)存到pending_中,等待任务完成后进行调用

4. onTaskFinished接收到任务完成信号(taskFinished)调用lambda

5. lambda内部调用最原始的callback

6. callback中会调用UIcallback
