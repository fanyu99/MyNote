# 了解:SHA-256哈希
### Qt相关API:
	1. QByteArray 
	2. QByteArray::hash
	3. QCryptographicHash生成加密Hash
	4. QCryptographicHash::Sha256
### 随机盐是什么?
	 1. 盐是每个用户独有的随机值
	 2. 作用:让相同的密码在数据库中对应不同的值,使得即便密码一样,不同的用户的最终哈希也是不一样的,防止攻击者使用预计算表进行撞密码
	3. 在安全敏感的情况下使用QRandomGenerator::system()是最明确的系统加密安全随机源
### 胡椒是什么?
	胡椒为所有密码所共享的秘密,不能存储在数据库中,通常放在独立配置,环境变量,密钥管理系统里
	用于增加数据库泄露后的攻击成本
### 盐+密码+胡椒怎么拼?
	1. salt+password->hash
	2. 使用pepper时,使用一种固定形式,例如:pepper+salt+password
### 验证流程是什么?
	1. 从数据库中取出用户salt
	2. 获取用户本次校验输入的密码
	3. 用同样的算法和拼接顺序获取hash
	4. 将算出来的hash与数据库中的hash进行比较
	5. hash相同正确,不同错误
### 缺点:
	SHA-256相较而言比较快,攻击者攻击时间成本较小
# 优化:使用PBKDF2慢哈希
```C++
// 获取密码hash记录(返回记录和错误信息)
QPair<PasswordHashRecord, PasswordHashError> PasswordHasher::hashPassword(const QString& password, const PasswordHashPolicy& policy) const
{
    PasswordHashRecord record;
    
    // 校验策略是否有效
    if (!policy.isValid()) {
        return { record, PasswordHashError::InvalidPolicy };
    }

    // 校验密码是否有效

    if (password.isEmpty())
        return { record, PasswordHashError::InvalidPassword };

    // 设置记录
    record.hashName = policy.hashName;
    record.algorithmVersion = policy.algorithmVersion;
    record.iterations = policy.iterations;
    record.salt = generateSalt(policy);
    
    // 获取hash值
    record.hash = QPasswordDigestor::deriveKeyPbkdf2(QCryptographicHash::Sha256, password.toUtf8(), record.salt, record.iterations, policy.hashLength);

    return { record, record.hash.isEmpty() ? PasswordHashError::HashGenerateError : PasswordHashError::None };

}
```
## PasswordHasher模块相关知识
	1.模块的高内聚与低耦合:
		1-将密码转换为可存储的哈希记录
		2-对输入的密码进行校验
		3-判断哈希记录是否需要进行重哈希
	2.密码的校验:
		1-需要进行恒定时间(例如进行逐位异或等)比较,不能使用operator==进行比较
		2-密码长度也需要进行比较
		3-暴露的接口最终只能返回匹配与否(bool),不能返回过多的信息
		4-不能用早退出比较(例如提前做长度退出比较)
