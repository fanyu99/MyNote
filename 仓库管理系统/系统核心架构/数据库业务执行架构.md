### 整体架构:
```mermaid
flowchart TB
    UI["UI / 业务线程"]
    EX["DatabaseExecutor<br/>任务入口、FIFO、生命周期"]
    WK["DatabaseWorker<br/>SQL 执行者"]
    DB["QSqlDatabase<br/>唯一持久连接"]
    MYSQL["MariaDB / MySQL"]
    QT["QThread<br/>数据库专用线程"]

    UI -->|"① submitTask(DatabaseTask)"| EX
    EX -->|"② invokeMethod<br/>QueuedConnection"| WK
    QT -.->|"承载"| WK
    WK -->|"③ 执行 SQL"| DB
    DB <-->|"④ 查询/更新"| MYSQL
    WK -.->|"⑤ taskCompleted<br/>DatabaseResult"| EX
    EX -.->|"⑥ taskFinished<br/>DatabaseResult"| UI
```
**本质: 单数据库线程+单数据库连接+任务队列+异步结果通知**,用于保障QSqlDatabase的线程亲和性,防止一个QSqlDatabase被多个线程使用
### 三层划分
1. 值类型层 DatabaseTypes
   ***用于定义不同线程之间传递的数据格式***

|    类型    | 定义                              |
| :------: | ------------------------------- |
|  数据库配置   | DatabaseConfig                  |
| 数据库SQL语句 | DatabaseStatement,StatementType |
|  数据库任务   | DatabaseTask,DatabaseTaskType   |
|   执行结果   | DatabaseResult,StatementResult  |
|   错误信息   | DatabaseErrorCode,DatabaseError |
|  执行器的状态  | DatabaseExecutorState           |
2. 调度层DatabaseExecutor
负责:
    1). 创建工作线程
    2). 创建和移动DatabaseWorker
    3). 接收任务并提交任务到DatabaseWorker
    4). 接收任务执行结果
    5). 管理启动,运行,关闭等状态
    6). 处理任务队列  
3. 执行层DatabaseWorker
负责:
	1). 创建数据库连接 
	2). 创建QSqlQuery及其参数绑定和执行
	3). 执行查询和命令及事务
	4). 健康检查
	5). 关闭和移除数据库连接
### 事务的执行流程
```mermaid
flowchart TD
    A["database.transaction()"] --> B{"启动成功？"}
    B -- 否 --> E1["TransactionFailed"]
    B -- 是 --> C["依次执行每条语句"]
    C --> D{"某条失败？"}
    D -- 是 --> R["rollback()"]
    R --> E2["记录 failedStatementIndex"]
    D -- 否 --> M["commit()"]
    M --> N{"提交成功？"}
    N -- 否 --> R2["rollback() + TransactionFailed"]
    N -- 是 --> S["success = true"]
```
### 正常关闭流程
```mermaid
sequenceDiagram
    participant UI as 业务线程
    participant E as DatabaseExecutor
    participant W as DatabaseWorker
    participant T as QThread

    UI->>E: shutdown()
    E->>E: state = ShuttingDown
    E->>E: 拒绝新任务
    E->>E: 启动排空定时器(软超时机制)
    E->>W: 继续派发已有任务
    W-->>E: taskCompleted
    E->>W: shutdown()
    W->>W: 停止健康检查
    W->>W: close + removeDatabase
    W-->>E: shutdownCompleted
    W->>W: deleteLater
    W-->>T: destroyed
    T->>T: quit()
    T-->>E: finished
    E-->>UI: shutdownFinished()
```
