## 三者关系

```
原版计划（历史）
    │  优化决策：异步 Worker、PBKDF2、Qt Graphs、库存流水+余额、8 周纵向切片
    ▼
优化版计划（主计划：目标 + 取舍 + 八周骨架）
    │  展开：代码、DDL、目录结构、练习、陷阱、面试
    ▼
优化版详细实施计划（落地细节）
```

- **优化版计划** 是 8 节主计划，给出目标、每模块的设计取舍和八周路线骨架。
- **优化版详细实施计划** 仿照原版计划的形式，把主计划展开为可落地的代码、DDL、目录结构、知识清单、练习和验收标准；原版中仍有效的部分保留，被优化的部分替换为优化方案。
- **原版计划** 是拆分前的历史完整计划，仅用于查看早期设计，不作为执行主线。

> 执行时以「优化版计划」+「优化版详细实施计划」为准；原版计划仅供对照。
