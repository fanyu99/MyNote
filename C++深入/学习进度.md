### 2026-09-18：A1 第 1 课——对象模型与虚函数

- 状态：已完成讲解，练习已提交，基础掌握良好
- 学习内容：

  - 虚函数、虚函数表（vtable）与虚函数指针（vptr）
  - 基类指针调用派生类虚函数的过程
  - `override` 的作用
  - 多态基类的虚析构函数
  - `dynamic_cast` 与 RTTI 基础
  - 单继承、多继承下的对象布局概念
  - 构造/析构期间调用虚函数的注意事项

#### 练习反馈

1. **练习 1：正确**
   - 输出为 `Dog`
   - `p` 的静态类型为 `Animal*`
   - `p` 指向对象的动态类型为 `Dog`
   - 因为 `speak()` 是虚函数，调用时通过对象的虚函数指针和虚函数表定位到 `Dog::speak()`。

2. **练习 2：正确**
   - `run()` 不是虚函数时，不会发生运行时多态。
   - 应在基类声明为 `virtual`，并在派生类中使用 `override` 检查重写关系。

3. **练习 3：基本正确，需要补充表述**
   - 更准确的场景是：基类指针指向派生类对象，并通过该基类指针执行 `delete`。
   - 此时基类析构函数应为虚函数，才能保证先调用派生类析构函数，再调用基类析构函数。
   - 这样可以避免派生类资源未释放。

4. **练习 4：代码完成，结构正确**
   - `Shape` 是抽象基类。
   - `Circle` 与 `Rectangle` 正确重写了纯虚函数 `area()`。
   - 通过 `Shape*` 指向不同派生类对象并调用 `area()`，体现了运行时多态。
   - `Shape` 的虚析构函数保证了 `delete pC` 和 `delete pR` 的销毁过程正确。

#### 代码改进建议

- 当前 `Circle::area()` 返回 `int`，会截断圆面积的小数部分。例如半径为 10 时，结果会从约 `314.159` 截断为 `314`。如果希望保留精度，可以将返回类型统一改为 `double`。
- 现代 C++ 中，示例程序可以优先使用智能指针，避免手动 `new/delete`，例如 `std::unique_ptr<Shape>`。
- 下一步应继续通过编译和运行验证虚函数行为，并开始学习更细致的对象内存布局。

### 2026-09-19：A1 第 2 课——对象大小、内存对齐与继承布局

- 状态：已完成讲解与练习，整体掌握良好
- 学习内容：
  - `sizeof` 与 `alignof` 的基本含义
  - 空类对象为什么通常占用 1 字节
  - 非静态数据成员、普通成员函数与静态成员对对象大小的影响
  - 内存对齐、成员间填充与尾部填充
  - 成员声明顺序对对象大小的影响
  - 虚函数为对象带来的 `vptr` 空间开销
  - 单继承中的基类子对象与 `vptr` 复用
  - 多继承中的多个基类子对象、多个 `vptr` 与指针调整
  - 完整对象、基类子对象、静态类型和动态类型的区别
  - 对象布局受编译器、平台和 ABI 影响，实验结果不能完全等同于 C++ 标准保证

#### 练习反馈

1. **练习 1：基本正确**
   - 正确判断了成员偏移：`a = 0`、`b = 4`、`c = 8`，以及 `sizeof(Test) = 12`。
   - 修正了尾部填充范围：对象的有效偏移为 `0～11`，所以尾部填充是 `9～11`，不是 `9～12`。

2. **练习 2：正确**
   - 正确判断普通类 `A` 通常为 4 字节，多态类 `B` 在常见 64 位环境中通常为 16 字节。
   - 理解普通成员函数代码不保存在每个对象中，而虚函数通常使对象增加一个隐藏的 `vptr`。
   - 需要继续注意：`vptr` 为 8 字节是常见 64 位实现的结果，不是 C++ 标准规定的固定值。

3. **练习 3：正确**
   - 正确理解 `Derived` 完整对象包含 `Base` 子对象。
   - 正确理解普通单继承中派生类通常复用基类子对象中的 `vptr`。
   - 正确说明 `Base*` 指向派生类对象内部的 `Base` 子对象，并通过其中的 `vptr` 调用 `Derived::print()`。

4. **练习 4：基本正确**
   - 正确理解 `C` 对象包含 `A`、`B` 两个基类子对象，并可能存在两个 `vptr`。
   - 正确理解从 `C*` 转换为 `B*` 时可能发生地址调整，且地址变化不代表产生或指向另一个完整对象。
   - 修正了一个表述：`C*` 指向完整 `C` 对象的起始地址，而不是只指向“属于 C 自己的成员区域”；`B*` 则指向该完整对象内部的 `B` 子对象。
   - 进一步明确：指针变量具有静态类型；通过多态基类指针观察时，其所关联完整对象的动态类型仍为 `C`。
