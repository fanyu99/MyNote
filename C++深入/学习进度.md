#### 练习反馈

1. **练习 1：正确**
   - 输出为 `Dog`
   - `p` 的静态类型为 `Animal*`
   - `p` 指向对象的动态类型为 `Dog`
   - 因为 `speak()` 是虚函数，调用时通过对象的虚函数指针和虚函数表定位到 `Dog::speak()`。

2. **练习 2：正确**
   - `run()` 不是虚函数时，不会发生运行时多态。
   - 应在基类声明为 `virtual`，并在派生类中使用 `override` 检查重写关系。

3. **练习 3：基本正确，需要补充表述**
   - 更准确的场景是：基类指针指向派生类对象，并通过该基类指针执行 `delete`。
   - 此时基类析构函数应为虚函数，才能保证先调用派生类析构函数，再调用基类析构函数。
   - 这样可以避免派生类资源未释放。

4. **练习 4：代码完成，结构正确**
   - `Shape` 是抽象基类。
   - `Circle` 与 `Rectangle` 正确重写了纯虚函数 `area()`。
   - 通过 `Shape*` 指向不同派生类对象并调用 `area()`，体现了运行时多态。
   - `Shape` 的虚析构函数保证了 `delete pC` 和 `delete pR` 的销毁过程正确。

#### 代码改进建议

- 当前 `Circle::area()` 返回 `int`，会截断圆面积的小数部分。例如半径为 10 时，结果会从约 `314.159` 截断为 `314`。如果希望保留精度，可以将返回类型统一改为 `double`。
- 现代 C++ 中，示例程序可以优先使用智能指针，避免手动 `new/delete`，例如 `std::unique_ptr<Shape>`。
