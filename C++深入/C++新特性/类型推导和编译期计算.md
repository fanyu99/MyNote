# 1.`auto`推导规则
## 三条核心规则
1. 按值推导，丢掉引用，丢掉顶层的`cosnt`/`volatile`.想要保留必须显示写出
```C++
int x = 10; 
const int cx = x;
int &rx = x;

auto a = x; // int 
auto b = cx; // int,顶层的const被丢弃
auto c = x; // int，顶层的引用被丢弃
```
1. 数组和函数会退化为指针
```C++
const auto d = cx; // const int 
auto& e = rx; // int& 
const auto&f = cx; // const int&
```
1. 初始化列表有特殊规则
```C++
auto i = {1,2,3}; // auto将其推导为std::initializer_list<int>
auto j{1}; // C++17更改为int,14为std::initializeer_list<int>
auto k = 1,l = 2.5; // 编译错误，只能为同一个类型
```

>[!重点坑]
>```C++
>std::vector<bool>v{true,false};
>auto flag = v[0]; // 类型为std::vector<bool>::reference
>```
>auto+代理对象：
>这里的flag很可能变为悬空引用！


## `auto&&`万能引用
由之前的折叠规律知道，只有`&& &&`才是右值引用`&&`
```C++
auto&& a =x; // int& 左值引用
auto&& a1 = 42; // int&& 右值引用
auto&& a2 = func(); // 由func返回值决定类型
```
# 2.`decltype`查询类型
`decltype`只会报告表达式的确切类型，例如
```C++
int x =90;
const int cx  = x;
int& rx= x;

decltype(x); // int
decltype(cx); // const int
decltype(rx); // int&
decltype((x)) // int&  注意这里使用的是(x)
// (x)是左值表达式，不是左值变量，变为左值int&
```
三条规则：
1. `decltype(name)`变量名，返回的是变量声明时的类型
2. `decltype((x))`,`decltype(v[0])`左值表达式，返回类型引用`T`
3. `decltype(1+1)`,`decltype(f())`等右值，返回T

>[!注意]
>在类似`decltype((x))`中,`(x)`表示**左值表达式**而不是左值变量，因此会添加一层`&`

## `decltype(auto)`使返回值完全忠实原意
14以后新特性，专治于“完美转发返回值的场景”
例如写一个转发函数，返回值类型完全与被调用函数一致：
```C++
template <typename Container ,typename Index>
decltype(auto) get(Container&&c,Index i)
{
	return c[i];
}

std::vector<int>v{1,2,3};
get(v,0)  = 100; // 如果返回的是int&,那么合法，如果是int,那么不合法（临时变量赋值）
```

>[!记忆]
>局部变量使用auto
>需要精确保留类型（转发函数，模板库内部等）：使用`decltype(auto)`
>只需要类型名、不需要值(模板元编程)： 使用`decltype(expr)`

# 结构化绑定(C++17)
```C++
std::pair<int,std::string>p{1,"hello"};
auto [id,name] = p; // id:1,name:"hello"
```
常用于配合`if(init;condition)`表达式
例如：
```C++
if(auto ite = m.find("key");ite!=m.end()){
	use(ite->second);
}
```
