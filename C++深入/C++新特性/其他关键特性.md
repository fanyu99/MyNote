
# 1.`constexpr` 编译期常量
`constexpr`用来告诉编译器,这个值在编译阶段就已经确定(必须为字面量类型且必须立即初始化,例如标量/引用/指针/带`constexpr`构造函数的类),减少花销
## 与`const`区别
`const`表示变量在初始化之后不能被修改,但是初始值可以在运行时进行计算;
`constexpr`语义更强,要求初始值在编译器必须确定,之后不能进行修改

## `constexpr`函数
因为其上下文的不同,其执行时间不同:
```C++
constexpr int square(int x)
{
    return x * x;
}
constexpr auto add = [](int a,int b)constexpr{return a+b;}; // C++17后支持lambda表达式

// 编译期求值：参数是字面量，上下文是 constexpr 变量初始化
constexpr int kResult = square(8);  // 编译器直接把 kResult 替换为 64

// 运行时求值：参数来自运行时
int runtime_input = 42;
int result = square(runtime_input);  // 普通函数调用，在运行时执行
```

## `static_assert`和`constexpr`函数
`static_assert`是编译器断言,其第一个参数必须为常量表达式,天然与`constexpr`函数形成配合,使一些检查能够在编译器就能执行大大减少成本
例如:
```C++
constexpr int factorial(int n)
{
    return n <= 1 ? 1 : n * factorial(n - 1);
}
// 直接在编译器进行检验
static_assert(factorial(0) == 1, "factorial(0) should be 1");
static_assert(factorial(1) == 1, "factorial(1) should be 1");
static_assert(factorial(5) == 120, "factorial(5) should be 120");
static_assert(factorial(10) == 3628800, "factorial(10) should be 3628800");
```
另一个常见使用就是`if constexpr`检查
```C++
constexpr auto add = [](int a,int b )constexpr{return a+b;};
int main()
{
    if constexpr (add(1, 2) == 3) {
        std::cout<<"1+2="<<add(1,2)<<std::endl;
    }
}
```

几个标准的`constexpr`函数的差异:

|能力|C++11|C++14|C++17|
|---|---|---|---|
|局部变量|仅 `return`|允许|允许|
|循环 (`for`/`while`)|禁止|允许|允许|
|`if-else` 语句|禁止（只能用三元运算符）|允许|允许|
|成员函数修改成员|禁止（隐式 `const`）|允许|允许|
|Lambda|不支持|部分支持|正式支持|
|标准库 constexpr|极少|增多|大量增加|
### 示例: CRC-32查找表
```C++
#include <array>
#include <cstdint>

constexpr std::array<std::uint32_t, 256> make_crc32_table()
{
    std::array<std::uint32_t, 256> table{};
    constexpr std::uint32_t kPolynomial = 0xEDB88320u;

    for (std::size_t i = 0; i < 256; ++i) {
        std::uint32_t crc = static_cast<std::uint32_t>(i);
        for (int j = 0; j < 8; ++j) {
            if (crc & 1) {
                crc = (crc >> 1) ^ kPolynomial;
            } else {
                crc >>= 1;
            }
        }
        table[i] = crc;
    }
    return table;
}

// 编译期生成完整的 CRC-32 查找表
constexpr auto kCrc32Table = make_crc32_table();

// 运行时使用：只需要做查表操作
constexpr std::uint32_t crc32_compute(const std::uint8_t* data, std::size_t len)
{
    std::uint32_t crc = 0xFFFFFFFFu;
    for (std::size_t i = 0; i < len; ++i) {
        crc = (crc >> 8) ^ kCrc32Table[(crc ^ data[i]) & 0xFF];
    }
    return crc ^ 0xFFFFFFFFu;
}
```

## `constexpr`构造函数

### 什么是字面类型
字面类型:
1. 标量类型.例如指针,引用.字面量
2. 需要有`constexpr`构造函数且所有非静态数据成员本身必须是字面类型或数组,并且析构函数要么平凡的(由编译器隐式生成,不是用户手动生成的),要么在C++20之后也是`constexpr`
例如
```C++
// 这是一个字面类型
struct Point {
    float x;
    float y;

    constexpr Point(float x_, float y_) : x(x_), y(y_) {}
    // 隐式的析构函数是平凡的，满足条件
};
struct test{
	std::vector<int>vec; // 不是字面类型,vector具有不平凡的析构函数
};

constexpr Point kOrigin{0.0f, 0.0f};
static_assert(kOrigin.x == 0.0f);
static_assert(kOrigin.y == 0.0f);
```

### 示例
```C++
struct BcdDecimal {
    unsigned char bcd;
    // 带有逻辑的构造函数,其逻辑需要在constexpr允许范围内
    constexpr explicit BcdDecimal(int decimal) : bcd(0)
    {
        // 将十进制整数转换为 BCD 编码
        int remainder = decimal;
        int shift = 0;
        while (remainder > 0) {
            bcd |= (remainder % 10) << shift;
            remainder /= 10;
            shift += 4;
        }
    }

    constexpr int to_decimal() const
    {
        int result = 0;
        int multiplier = 1;
        unsigned char temp = bcd;
        while (temp > 0) {
            result += (temp & 0x0F) * multiplier;
            temp >>= 4;
            multiplier *= 10;
        }
        return result;
    }
};
constexpr BcdDecimal kDec42{42};
static_assert(kDec42.bcd == 0x42, "BCD of 42 should be 0x42");
static_assert(kDec42.to_decimal() == 42, "Round-trip conversion should work");
```
`constexpr`成员函数(C++14)的要求同上
`constexpr`析构函数(C++20)的示例:
```C++
// C++20 才支持
struct Resource {
    int* data;
    std::size_t size;

    constexpr Resource(std::size_t n) : data{}, size(n)
    {
        // C++20 允许在 constexpr 上下文中使用 new
        // 但分配的内存必须在常量求值结束前释放
    }

    // C++20: constexpr 析构函数
    constexpr ~Resource()
    {
        // 清理逻辑
    }
};
```
