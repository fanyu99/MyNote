# 第一课：从图像分类进入目标检测

> [!abstract] 本课目标
> 建立图像分类与目标检测的概念联系，理解 YOLO 要解决的问题，掌握目标检测标签的表示方式。
>
> **PyTorch 前置**：
> - [[Pytorch学习#十一、分类模型完整训练流程|分类模型完整训练流程]]——分类任务的输出 `[B, C]` 与 `CrossEntropyLoss`
> - [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|YOLO 数据格式和边界框]]——同一份边界框知识在 PyTorch 侧的代码实现

## 图像分类

一般输入一张图片后进行判断图像属于哪种类别
例如:
```
一张图片outputs -> 各类别得分,例如[1.0,2.4,2.2,1.2 ...]
然后取其中最高分(例如2.4)
对应类别1,判断图片属于类别1
```

> [!tip] 对应 PyTorch 实现
> 取最高分即 `output.argmax(dim=1)`，见 [[Pytorch学习#十一、分类模型完整训练流程|分类模型完整训练流程]]。

## YOLO目标检测

一般输入一张图片后进行检测图像中的目标,检测目标是什么并确定其位置
例如:
```
一张图片中存在1个人,1辆车,4棵树
目标检测中,检测图片中:

类别0:person
位置:0.2 0.2 0.3 0.3
置信度: 0.9

...
```

## 两种任务的核心差异

| 对比项目        | 图像分类     | 目标检测                    |
| ----------- | -------- | ----------------------- |
| 主要问题        | 图片是什么    | 图片中有什么、在哪里              |
| 一张图片的目标数量   | 通常一个主要类别 | 可以是 0 个、1 个或多个          |
| 标签          | 一个类别编号   | 多个目标的类别和边界框             |
| 模型输出        | 类别分数     | 多个候选框、类别和置信度            |
| 常见指标        | Accuracy | Precision、Recall、AP、mAP |

> [!warning] 为什么不能只改分类模型的最后一层
> 分类模型输出固定大小的 `[B, C]`，而检测模型要为一张图片预测**数量可变**的多个目标，还要额外输出边界框位置和置信度，因此标签、损失函数和评价指标都要一起改变。这一差异在第 2~3 课展开。

## YOLO目标检测中的边界框

目标检测中的数据标注经常使用:
```
class x_center y_center width height

例如: 0 0.5 0.375 0.5 0.5
0       → 类别编号
0.5     → 边界框中心点 x 
0.375   → 边界框中心点 y
0.5     → 边界框宽度
0.5     → 边界框高度
坐标和宽高皆为归一化结果,方便不同尺寸图片确定位置
```

> [!tip] 代码实现
> `xyxy ↔ yolo` 格式互转的函数实现，以及标签文件目录结构，见 [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|YOLO 目标检测数据格式和边界框]]。

## YOLO重要思想

YOLO的核心思想为
```
图像 -> 一个网络 -> 同时预测目标位置和类别
```
one_stage 模型速度快，常用于实时检测。与 OpenCV 中基于轮廓/特征的**传统目标检测**（先找轮廓、再算特征做判断）相比，YOLO 用神经网络端到端完成"定位 + 分类"，不需要手工设计特征——传统方法的思路见 [[视觉学习/OpenCV学习笔记/OpenCV第七课 轮廓检测与目标分析|轮廓检测与目标分析]]。

> [!note] 本课小结
> - 分类回答"图片是什么"，检测回答"图中有什么、在哪里、有多可信"
> - YOLO 标签 = `class x_center y_center width height`，后四项归一化到 0~1
> - YOLO 用**一次前向传播**同时预测位置和类别，属于 one-stage 检测
