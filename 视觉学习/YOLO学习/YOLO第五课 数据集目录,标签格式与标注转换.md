# 第五课：数据集目录、标签格式与标注转换

> [!abstract] 本课目标
> 掌握一份 YOLO 检测数据集由哪些部分组成、标签文件怎么写、如何从其他标注格式转换，以及如何检查图片与标签是否一一对应、坐标是否合法。

## 1. 一份检测数据到底包含什么？

常见的组织方式如下：

```
my_dataset/
├─ images/
│  ├─ train/
│  │  ├─ 000001.jpg
│  │  ├─ 000002.jpg
│  │  └─ 000003.jpg
│  │
│  ├─ val/
│  │  ├─ 000101.jpg
│  │  └─ 000102.jpg
│  │
│  └─ test/
│     ├─ 000201.jpg
│     └─ 000202.jpg
│
├─ labels/
│  ├─ train/
│  │  ├─ 000001.txt
│  │  ├─ 000002.txt
│  │  └─ 000003.txt
│  │
│  ├─ val/
│  │  ├─ 000101.txt
│  │  └─ 000102.txt
│  │
│  └─ test/
│     ├─ 000201.txt
│     └─ 000202.txt
│
└─ data.yaml
```

> [!note] 目录要点
> 1. `images/` 存放图片，`labels/` 存放标签，`data.yaml` 是数据配置文件；
> 2. 图片文件与标签文件的命名必须一一对应：例如 `000001.jpg` ↔ `000001.txt`；
> 3. `images/` 与 `labels/` 下的子目录结构保持完全一致（`train/val/test` 一一对应）。

## 2. `train` / `val` / `test`

| 数据集 | 作用 | 是否更新参数 |
| --- | --- | --- |
| 训练集 `train` | 用于训练的数据，只有训练集会直接参与模型更新 | ✅ 是 |
| 验证集 `val` | 用于训练过程中评估模型 | ❌ 否 |
| 测试集 `test` | 用于对最终模型进行相对独立的评估 | ❌ 否 |

### 重点

训练集、验证集、测试集应该尽量来自相同任务分布，但是不能包含重复或者高度相似的数据。

合理的划分方法为：

- 不同视频
- 不同日期
- 不同场景
- 不同摄像头
- 不同对象实例

> [!warning] 数据泄露"作弊"
> **数据泄露**指模型在训练的时候看到了本不该接触到的测试（验证）数据，导致在测试/验证的时候表现**虚高**，实际效果大幅下降。简单来说就是**模型作弊了**。
>
> 常见场景：
> 1. 预处理阶段使用全局的统计量（即包含测试集），例如对整个数据集计算均值后再用这个均值去归一化训练集和测试集；
> 2. 特征工程中引入未来信息：例如预测时，使用 `t+1` 时间的数据预测 `t` 的值；
> 3. **数据划分不当**：例如重复样本、连续视频帧同时出现在训练集和测试集；
> 4. 数据增强操作误用：例如对图像做随机裁剪等操作时，同时作用于测试集和训练集且共享参数。


## 3. YOLO 标签格式

一个标签文件的格式为：

```txt
class_id x_center y_center width height
```

后四个坐标一般为归一化结果，类别从 0 开始。

| 数值 | 含义 |
| --- | --- |
| `class_id` | 类别编号，从 0 开始 |
| `x_center` | 边界框中心点 x（归一化） |
| `y_center` | 边界框中心点 y（归一化） |
| `width` | 边界框宽度（归一化） |
| `height` | 边界框高度（归一化） |

例如：

```txt
0 0.300000 0.500000 0.200000 0.600000
1 0.700000 0.650000 0.300000 0.250000
2 0.500000 0.300000 0.100000 0.150000
```

一行代表图片中的一个目标，一个 `.txt` 对应一张图片。

> [!tip] 类别名称在哪里定义？
> 标签里存的只是类别编号，编号具体对应哪个类别名称由 `data.yaml` 的 `names` 决定，见第 5 节。
>
> PyTorch 中用一个 `[N, 5]` 的张量表示一张图片的全部目标，见 [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|YOLO 目标检测数据格式和边界框]]。

## 4. 从 `xyxy` 转换为 YOLO 的 `xywh`

详见 [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|边界框格式转换代码]]。总之归一化结果为：

$$
\begin{aligned}
x_{center} &= \frac{x_{min}+x_{max}}{2} \div W \\[4pt]
y_{center} &= \frac{y_{min}+y_{max}}{2} \div H \\[4pt]
width &= \frac{x_{max}-x_{min}}{W} \\[4pt]
height &= \frac{y_{max}-y_{min}}{H}
\end{aligned}
$$

> [!warning] 重点：转换时需要校验数据是否合法
> 只检查每个数是否落在 0～1 之间还不够，还应检查**完整边界是否越界**。标注转换时至少检查以下几项：
> - **类别编号越界**：`class_id` 超出 `data.yaml` 中 `names` 的范围；
> - **未归一化**：误把像素值写进标签（数值远大于 1）；
> - **负宽高**：`width` / `height` 必须大于 0；
> - **边界越界**：`x_center ± width/2` 或 `y_center ± height/2` 超出 `[0, 1]`。

## 5. `data.yaml` 数据集配置文件

主要用来告诉训练程序：

1. 数据集根目录在哪里；
2. 训练集图片在哪里；
3. 验证集图片在哪里；
4. 测试集图片在哪里；
5. 数据集有哪些类别；
6. 类别编号与类别名称如何对应。

简单示例：

```yaml
path: D:/datasets/my_dataset # 数据集根目录，后续路径以其为前缀路径

train: images/train
val: images/val
test: images/test

names: # 定义类别编号到类别名称的映射
  0: person
  1: car
  2: dog
```

> [!note] 标签只需要 `labels`，不需要在 yaml 里写
> `data.yaml` 只描述图片路径与类别表；标签文件默认与图片同名、放在与 `images/` 平级的 `labels/` 下，按第 1 节的结构自动对应，不必单独配置。

## 6. 常见的其他标注格式

### 1. Pascal VOC

通常使用 XML 文件保存标签，保存格式为：

```
xmin
ymin
xmax
ymax
```

转换到 YOLO 时，需要：

- 读取 XML；
- 获取图片宽高；
- 读取每个目标的类别名称；
- 把类别名称转换成类别编号；
- 将 `xyxy` 转换成归一化 `xywh`（见第 4 节）；
- 写入对应的 `.txt` 文件。

### 2. COCO

通常使用 JSON 文件，形式为：

```
x_min, y_min, width, height
```

> [!warning] 注意：这里是**左上角坐标**
> COCO 的 `x_min, y_min` 是**左上角**坐标，而 YOLO 的 `x_center, y_center` 是**中心点**坐标；此外 COCO 框通常是像素值，YOLO 标签通常归一化到 0～1。转换时这两点都要处理，不能直接照搬。

## 7. 核心流程

从数据到 YOLO 数据集一般流程为：

```
收集图片
    ↓
定义类别及其编号
    ↓
标注目标
    ↓
导出或转换成 YOLO 标签
    ↓
划分 train / val / test
    ↓
检查图片与标签是否一一对应
    ↓
检查类别编号和坐标范围
    ↓
把标签框画回图片进行可视化检查
    ↓
编写 data.yaml
    ↓
开始训练
```

> [!tip] 可视化检查
> 画框回图片这一步依赖 `xyxy ↔ yolo` 转换与 OpenCV 绘图，代码见 [[Pytorch学习#十七、在图片上绘制和检查边界框|在图片上绘制和检查边界框]]，几何变换（缩放/裁剪）见 [[视觉学习/OpenCV学习笔记/OpenCV第三课 图像几何操作|OpenCV 图像几何操作]]。

> [!note] 本课小结
> - 一份检测数据集 = `images/` + `labels/` + `data.yaml`，图片与标签**同名对应**，子目录结构一致
> - `train` 更新参数，`val` / `test` 只做评估；划分要按视频/场景/日期分组，避免**数据泄露**
> - 标签格式 `class x_center y_center w h`，后四项归一化，类别从 0 开始
> - `xyxy → yolo` 转换后要校验：类别越界、未归一化、负宽高、边界越界
> - `data.yaml` 负责图片路径与类别编号到名称的映射
> - 常见外部格式：Pascal VOC 用 XML 的 `xyxy`，COCO 用 JSON 的**左上角** `xywh`
> - 完整流程：收集 → 定义类别 → 标注 → 转换 → 划分 → 检查对应/坐标 → 可视化 → 写 `data.yaml` → 训练
