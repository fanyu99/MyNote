## 一、深度学习的概念

### 1. 从"写规则"到"学规则"

先看两种做事方式的区别：

| 方式 | 谁定规则 | 例子 |
| --- | --- | --- |
| **传统编程** | **人**写死规则 | `if 像素满足条件 → 这是猫` |
| **机器学习** | **数据**里自动找规则 | 给一万张猫图，让它自己总结 |

传统编程遇到"识别猫"这种任务会崩溃——因为**很难用人手写出"猫的规则"**（毛色？耳朵？姿态？遮挡？）。机器学习换了个思路：

> **不给规则，只给"输入 + 正确答案"的大量例子，让机器自己找出从输入到输出的映射。**

深度学习，就是机器学习里**用"多层神经网络"来做这件事**的那一类方法。

### 2. 什么是"模型"：一个带参数的函数

一切从一句话开始：

> **模型 = 一个函数 $f$，输入 $x$，输出预测 $\hat{y}$，而函数里有一些"可调旋钮"叫参数。**

最简单的一个模型（单变量线性模型）：

$$
\hat{y} = f(x;\,w,b) = w\,x + b
$$

- $x$：输入（比如一个像素、一个特征）
- $w$：**权重（weight）**——旋钮一
- $b$：**偏置（bias）**——旋钮二
- $\hat{y}$：预测结果

**训练（学习）的本质，就是自动把 $w$ 和 $b$ 调到合适的值。**

> [!note] 关键认知
> 参数**不是人写的**，是**数据"逼"出来的**。你要做的就是设计函数形状、准备数据、给它一个"努力方向"（损失），剩下的交给优化过程。

### 3. 为什么叫"深度"

单个线性模型 $wx+b$ 太弱：几层线性叠起来，数学上**仍等价于一层线性**，表达不了复杂规律。

于是引入两样东西：

1. **堆很多层**（层数多 → "深"）
2. **层间插非线性激活函数** $\sigma$（如 ReLU、SiLU）

一个两层的小网络：

$$
h = \sigma(W_1 x + b_1) \qquad \hat{y} = W_2 h + b_2
$$

有了非线性，多层叠加就能**逼近非常复杂的函数**。这就是"深度"的意义：

> **深度 = 用很多层、从小到大逐级地把简单特征组合成复杂特征。**

- 浅层学到：边缘、颜色、纹理
- 中层学到：形状、部件（眼睛、轮子）
- 深层学到：整体概念（猫、车、犀牛）

这和 [[Pytorch学习#八、卷积层 Conv2d|卷积层]]、[[YOLO第三课 YOLO整体网络结构|YOLO 的 Backbone]] 做的事是同一回事。

### 4. 它和传统方法的关系

在图像领域，传统做法是**人工设计特征**：人想好"先找边缘 → 再找轮廓 → 再匹配形状"，比如 OpenCV 里的 [[视觉学习/OpenCV学习笔记/OpenCV第八课 Canny边缘检测|Canny 边缘检测]]、[[视觉学习/OpenCV学习笔记/OpenCV第七课 轮廓检测与目标分析|轮廓检测]]。

深度学习的最大不同：**特征也由模型自己学**，不用人设计。人只管"给数据和网络结构"。

### 5. 深度学习能做哪几类任务

| 任务类型 | 输出是什么 | 例子 |
| --- | --- | --- |
| **分类** | 一个类别 | 这是猫还是狗 |
| **回归** | 一个数值 | 预测房价、框的中心坐标 |
| **检测** | 多个"框 + 类别" | 图里有 3 只牛、2 只斑马 → [[YOLO第一课 从图像分类进入目标检测\|YOLO 第一课]] |
| **分割 / 关键点** | 每个像素/点 | 抠图、姿态估计 |

它们的**训练方式几乎一样**，区别只在"输出长什么样"和"用什么损失"。

## 二、深度学习是怎么进行的（核心）

> 这一节是全篇重点。用一个**最小例子**贯穿：已知数据 $x=1$ 时正确结果 $y=2$，我们想让模型 $\hat{y}=wx$ 学会它（正确答案是 $w=2$）。

### 1. 总体框架：四步循环

训练就是反复做这四件事：

```
        ┌──────────────────────────────────────────────────┐
        │                                                  │
        ▼                                                  │
  ① 前向传播           ② 计算损失          ③ 反向传播          ④ 更新参数
  用当前参数做预测  →   给预测打分(差多远)  →  算梯度(往哪改)  →  挪一小步参数
  ŷ = f(x; w)          L = loss(ŷ, y)       ∂L/∂w            w ← w − η·∂L/∂w
        │                                                  │
        └──────────── 重复成千上万次，直到损失足够小 ─────────┘
```

一句话概括：

> **猜一个结果 → 看看错多少 → 找出错该往哪边改 → 改一点点 → 再猜……循环到足够准。**

这和 [[Pytorch学习#四、损失函数与优化器|PyTorch 第4章的训练循环]]、[[Pytorch学习#十一、分类模型完整训练流程|分类训练六步]]是**完全同一套流程**。

下面逐步拆开。

### 2. 第一步：前向传播 = 用当前参数做预测

把输入喂进模型，得到预测值，这叫**前向传播（forward）**。

$$
x=1,\quad w \text{ 现为 } 1 \;\Rightarrow\; \hat{y} = w\cdot x = 1
$$

网络版就是把"$wx$"换成多层嵌套：

$$
\hat{y} = f_{\text{out}}(\cdots f_2(f_1(x)))
$$

> [!tip] 前向传播不改任何参数
> 它只是"算一遍结果"。真正的学习发生在后面三步。代码里就是 `output = model(x)`——见 [[Pytorch学习#三、第一个神经网络与 nn.Module|nn.Module.forward]]。

### 3. 第二步：计算损失 = 给预测打分

我们需要一个数字来衡量"预测有多差"，这就是**损失函数（loss function）**。

直觉：**损失 = 预测与真值的距离**。距离越大越差。

这个例子里用最简单的**均方误差 MSE**：

$$
L = (\hat{y} - y)^2 = (1 - 2)^2 = 1
$$

模型越准，损失越小。**训练的目标就是让损失尽量小。**

常见的两种损失：

| 任务 | 损失函数 | 基本形式 |
| --- | --- | --- |
| 回归（预测数值） | **MSE 均方误差** | $L=\dfrac{1}{n}\sum_i(\hat{y}_i-y_i)^2$ |
| 分类（预测类别） | **交叉熵** | $L=-\sum_i y_i\log \hat{y}_i$（$y$ 为 one-hot）|

> [!note] 交叉熵的直觉
> 模型对正确类别的**预测概率越自信**（越接近 1），$-\log(\text{概率})$ 越小，损失越低；预测错了或没信心，损失就大。这就逼模型"答对且要自信"。
>
> 具体用法见 [[Pytorch学习#十一、分类模型完整训练流程|PyTorch 分类流程]]；YOLO 的 `box/cls` 损失见 [[常见训练参数及问题汇总]]。

### 4. 第三步：反向传播 = 梯度告诉往哪改

现在知道损失是 1，但**该往哪个方向调 $w$ 才能让损失变小？** 答案靠**梯度**。

> **梯度 = 损失对参数的导数 = "参数往正方向动一点，损失会怎么变"。**
> 它是损失下降**最陡**的方向信息的来源。

本例的梯度：

$$
L = (\hat{y}-y)^2 = (wx-y)^2
\;\Rightarrow\;
\frac{\partial L}{\partial w} = 2(\hat{y}-y)\cdot x
= 2(1-2)\cdot 1 = -2
$$

梯度是**负数** $-2$，意思是：**把 $w$ 调大，损失会下降**。（因为我们想找最低点，所以要往**梯度的反方向**走。）

> [!tip] 直观类比：下山
> 把损失想象成一座山的高度，参数是你在山上的位置。梯度 = 你脚下最陡的下坡方向的"反向"。**顺着梯度的反方向走一小步，高度就降低一点。**

**反向传播（backpropagation）** 就是把梯度从输出层一层层往回流：

> 用**链式法则**，从最后的损失出发，逐层往回算"每个参数对损失的贡献"。
>
> 网络有几十上百层，人工求导不现实——所以框架用**自动求导**完成。原理与代码见 [[Pytorch学习#二、自动求导 Autograd|PyTorch 第2章 autograd]]。

> [!note] 这里不深入的原因
> 链式法则的完整推导属于"算法细节"。**现阶段记住一件事就够了**：反向传播 = 自动、高效地算出每个参数的梯度。**你不需要手推，框架会算。**

### 5. 第四步：更新参数 = 梯度下降

有了梯度，就挪一小步：

$$
w \leftarrow w - \eta\,\frac{\partial L}{\partial w}
$$

- $\eta$（eta）就是**学习率（learning rate）**：步子迈多大。
- 负号：因为要往梯度**反方向**（下山）走。

本例代入（取学习率 $\eta=0.1$）：

$$
w \leftarrow 1 - 0.1\times(-2) = 1.2
$$

$w$ 从 1 变成了 **1.2**，更接近正确答案 2 了！再走几步看看：

| 轮次 | $w$ | 预测 $\hat{y}=wx$ | 损失 $(\hat{y}-2)^2$ | 梯度 $\partial L/\partial w$ | 更新后 $w$ |
| --- | --- | --- | --- | --- | --- |
| 0 | 1.00 | 1.00 | 1.0000 | −2.00 | 1.20 |
| 1 | 1.20 | 1.20 | 0.6400 | −1.60 | 1.36 |
| 2 | 1.36 | 1.36 | 0.4096 | −1.28 | 1.488 |
| … | … | … | ↓ 越来越小 | … | … → 2 |

**损失一路下降、$w$ 一路逼近 2**——这就是"学习"的全过程。

> [!example] 亲手跑一遍
> 这段逻辑的完整可运行代码见 [[Pytorch学习#二、自动求导 Autograd|PyTorch 第2章"动手试试"]]——它用 `loss.backward()` 自动算梯度、用 `w.data -= lr * w.grad` 更新，正是本表的手算版。

### 6. 学习率：步子大小的旋钮

$$
w \leftarrow w - \eta\,\frac{\partial L}{\partial w}
$$

- $\eta$ **太小**：每步挪一点点，收敛慢、训练很久；
- $\eta$ **太大**：一步迈过头，损失震荡甚至发散（变 NaN）；
- 实践中：先用大学习率快速下降，后期用小学习率精细收敛（学习率**调度**）。

调参细节（`lr0`/`lrf`/warmup/余弦退火）见 [[常见训练参数及问题汇总#★ 学习率调度：`cos_lr` / warmup 的真正作用|训练参数：学习率调度]]。

### 7. 一次迭代 vs 一个 epoch

| 术语 | 含义 |
| --- | --- |
| **batch（批）** | 一次同时送进模型的若干条样本 |
| **一次迭代（iteration）** | 处理完一个 batch，走一次"四步循环" |
| **epoch（轮）** | 把所有训练数据**完整看过一遍** |

比如 1000 张图、`batch=10`：一个 epoch 有 100 次迭代。
概念与代码见 [[Pytorch学习#五、Epoch / Batch / DataLoader|PyTorch 第5章]]，参数含义见 [[YOLO第六课 YOLO训练实战|YOLO 第六课]]。

### 8. 训练 vs 推理

学完参数后，用模型做预测叫**推理（inference）**，它和训练有两点关键区别：

| | 训练 | 推理 |
| --- | --- | --- |
| 要不要算梯度 | 要（才能更新参数） | 不要 |
| 代码 | `model.train()` | `model.eval()` + `torch.no_grad()` |

推理**不改参数**，只前向传播一次。忘了 `eval()`/`no_grad()` 会导致结果不稳、显存翻倍——见 [[Pytorch学习#六、训练模式 / 预测模式 / no_grad|PyTorch 第6章]]。

### 9. 一句话总结"怎么进行"

> **准备数据 → 定义模型(带参数) → 定义损失(衡量差距) → 循环{预测 → 算损失 → 算梯度 → 更新参数} → 损失够小、验证够好就停。**

## 三、深度学习做了什么（能力与本质）

### 1. 本质一：自动学习特征（表示学习）

这是深度学习最核心的贡献。

| | 传统方法 | 深度学习 |
| --- | --- | --- |
| 特征 | **人工设计**（Canny、SIFT、轮廓） | **模型自己学** |
| 人的工作 | 设计并串联多个特征算子 | 提供数据和网络结构 |
| 上限 | 受限于人的经验 | 随数据和算力提升 |

网络内部每一层都在做一次"特征变换"：像素 → 边缘 → 形状 → 物体。**"学习"在很大程度上就是"学出一套好用的特征"。**

### 2. 本质二：拟合一个"输入→输出"的映射

从数学上看，训练就是**在高维空间里找一个函数 $f$**，让它在训练数据上输出尽量接近真值，并且**对没见过的数据也成立**。后一点（泛化）才是关键。

### 3. 泛化：为什么模型会对"没见过的图"也有效

把数据分成三份：

| 数据集 | 用途 |
| --- | --- |
| **训练集** | 真正用来更新参数（模型"做题"） |
| **验证集** | 训练中调参/早停、判断有没有学歪 |
| **测试集** | 最后评估真实水平（只测一次） |

模型能泛化，是因为它学到的是**规律**（"牛大致长这样"），而不是**死记**训练图。但这两者很容易搞混：

- **过拟合**：训练集很好、验证集差 → 记住了噪声，没学到规律；
- **欠拟合**：两边都差 → 模型太弱或没训练够。

判断方法、现象与优化方向见 [[Pytorch学习#如何判断模型训练情况|PyTorch 判断训练情况]]、[[YOLO第八课 训练结果分析,错误诊断与优化|YOLO 第八课]]，参数层面的解法见 [[常见训练参数及问题汇总#2. 训练损失下降、验证损失不降反升 → **过拟合**|训练参数：过拟合]]。

### 4. 它擅长什么、不擅长什么

| 擅长 | 不擅长 |
| --- | --- |
| 高维、非线性的感知任务（图像、语音、文本） | 需要严格逻辑/推理的问题 |
| 有大量标注数据的场景 | 小样本、无数据场景 |
| 从原始信号直接端到端学习 | 强可解释性要求（"为什么这么判") |

> [!warning] 三个别指望
> - 数据不行，模型再大也白搭（**数据 > 模型 > 超参**，见 [[常见训练参数及问题汇总#五、训练优化优先级（结论）|优化优先级]]）；
> - 它学到的是"统计规律"，不是"真懂道理"；
> - 它高度依赖**数据分布**，换场景（领域偏移）常会掉点。

## 五、常见误解与学习建议

### 常见误解

| 误解 | 真相 |
| --- | --- |
| "深度学习很神秘/像大脑" | 数学上就是**高维函数拟合 + 梯度下降**，不神秘 |
| "参数是人调出来的" | 参数是**数据学出来的**；人调的是"结构、损失、学习率"这类**超参** |
| "层数越多越好" | 更深更强但更难训、更容易过拟合、更吃算力——要权衡 |
| "指标高就是好模型" | 可能是**数据泄漏**或**验证集不独立**，上线会掉（见 [[常见训练参数及问题汇总#12. 验证集指标好、上线却差 → **领域偏移 / 数据泄漏** ★\|数据泄漏]]） |
| "损失降到 0 最好" | 降到 0 往往是**过拟合**，要看验证集 |

### 学习建议

> [!tip] 怎么用这篇笔记
> 1. **先建立主干**：记住"四步循环 + 数据→模型→损失→优化"，细节往后填；
> 2. **动手验证**：把 [§2.5 的手算表](#5-第四步更新参数--梯度下降) 用 [[Pytorch学习|PyTorch]] 跑一遍，亲手看损失下降；
> 3. **连起来看**：学 PyTorch 时随时回来对 [§四 对照表](#四概念--代码--应用-对照表)；
> 4. **不纠结推导**：链式法则、梯度细节现阶段跳过没关系，**会用、能排错**才是目标。

> [!note] 小结
> - **概念**：模型 = 带参数的函数；深度 = 多层 + 非线性，逐级学特征
> - **怎么进行**：`前向传播 → 计算损失 → 反向传播(梯度) → 更新参数`，循环到损失够小
> - **更新公式**：$w \leftarrow w - \eta\,\partial L/\partial w$；学习率控制步子大小
> - **做了什么**：自动学特征 + 拟合输入输出映射 + 泛化到新数据
> - **边界**：数据 > 模型 > 超参；依赖数据分布，可解释性弱
