# 第一课：从图像分类进入目标检测

> [!abstract] 本课目标
> 建立图像分类与目标检测的概念联系，理解 YOLO 要解决的问题，掌握目标检测标签的表示方式。
>
> **PyTorch 前置**：
> - [[Pytorch学习#十一、分类模型完整训练流程|分类模型完整训练流程]]——分类任务的输出 `[B, C]` 与 `CrossEntropyLoss`
> - [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|YOLO 数据格式和边界框]]——同一份边界框知识在 PyTorch 侧的代码实现

## 图像分类

一般输入一张图片后进行判断图像属于哪种类别
例如:
```
一张图片outputs -> 各类别得分,例如[1.0,2.4,2.2,1.2 ...]
然后取其中最高分(例如2.4)
对应类别1,判断图片属于类别1
```

> [!tip] 对应 PyTorch 实现
> 取最高分即 `output.argmax(dim=1)`，见 [[Pytorch学习#十一、分类模型完整训练流程|分类模型完整训练流程]]。

## YOLO目标检测

一般输入一张图片后进行检测图像中的目标,检测目标是什么并确定其位置
例如:
```
一张图片中存在1个人,1辆车,4棵树
目标检测中,检测图片中:

类别0:person
位置:0.2 0.2 0.3 0.3
置信度: 0.9

...
```

## 两种任务的核心差异

| 对比项目        | 图像分类     | 目标检测                    |
| ----------- | -------- | ----------------------- |
| 主要问题        | 图片是什么    | 图片中有什么、在哪里              |
| 一张图片的目标数量   | 通常一个主要类别 | 可以是 0 个、1 个或多个          |
| 标签          | 一个类别编号   | 多个目标的类别和边界框             |
| 模型输出        | 类别分数     | 多个候选框、类别和置信度            |
| 常见指标        | Accuracy | Precision、Recall、AP、mAP |

> [!warning] 为什么不能只改分类模型的最后一层
> 分类模型输出固定大小的 `[B, C]`，而检测模型要为一张图片预测**数量可变**的多个目标，还要额外输出边界框位置和置信度，因此标签、损失函数和评价指标都要一起改变。这一差异在第 2~3 课展开。

## YOLO目标检测中的边界框

目标检测中的数据标注经常使用:
```
class x_center y_center width height

例如: 0 0.5 0.375 0.5 0.5
0       → 类别编号
0.5     → 边界框中心点 x 
0.375   → 边界框中心点 y
0.5     → 边界框宽度
0.5     → 边界框高度
坐标和宽高皆为归一化结果,方便不同尺寸图片确定位置
```

> [!tip] 代码实现
> `xyxy ↔ yolo` 格式互转的函数实现，以及标签文件目录结构，见 [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|YOLO 目标检测数据格式和边界框]]。

## YOLO重要思想

YOLO的核心思想为
```
图像 -> 一个网络 -> 同时预测目标位置和类别
```
one_stage 模型速度快，常用于实时检测。与 OpenCV 中基于轮廓/特征的**传统目标检测**（先找轮廓、再算特征做判断）相比，YOLO 用神经网络端到端完成"定位 + 分类"，不需要手工设计特征——传统方法的思路见 [[视觉学习/OpenCV学习笔记/OpenCV第七课 轮廓检测与目标分析|轮廓检测与目标分析]]。

> [!note] 本课小结
> - 分类回答"图片是什么"，检测回答"图中有什么、在哪里、有多可信"
> - YOLO 标签 = `class x_center y_center width height`，后四项归一化到 0~1
> - YOLO 用**一次前向传播**同时预测位置和类别，属于 one-stage 检测

# 第二课：IoU、Precision、Recall、AP、mAP

> [!abstract] 本课目标
> 理解模型预测框如何与真实框匹配，以及如何评价检测结果的好坏。
>
> **PyTorch 前置 / 对应实现**：
> - [[Pytorch学习#十八、IoU、NMS 与检测指标|IoU、NMS 与检测指标]]——本课概念的代码与公式汇总

## IoU 交并比

公式为
$$
IoU  = 交集面积 / 并集面积
$$

用于判断:
- 预测框和真实框是否匹配
- 计算目标检测指标
- 参与 YOLO 损失函数

## TP、FP、FN

TP : True Positive 即真实的目标被检测,正确检测
例如:
```
真实目标: 猫
检测目标: 猫,且位置正确(大于阈值)
```
FP : False Positive 即非真实目标被检测,错检
例如:
```
真实目标: 狗
检测目标: 其他,但是位置重叠程度高
```
FN : False Negative  即真实目标未被检测,漏检
例如:
```
真实目标: 狗
检测目标: 无
例如有3条狗,但是仅检测到2条
```

> [!warning] 类别正确 ≠ TP
> 即使类别预测正确，如果预测框与真实框的 IoU 低于阈值（如 0.5），这条预测仍然不能算 TP，通常计为 FP，同时对应的真实目标会形成 FN。

## 精确度 Precision

$$
Precision = TP / (TP + FP)
$$
回答的问题就是: 检测出来的目标,有多少是真正正确的?
例如:
```
检测出来10个目标,但是有2个目标并不存在或错误
即: TP = 8 ; FP = 2
Precision = 80%
```

## 召回率 Recall

$$
Recall = TP / (TP + FN)
$$
回答的问题就是: 真实存在的目标到底有多少被找到了
例如:
```
真正存在目标共10个,真实检测到了8个,但是没有检查到2个
即: TP = 8 ; FN = 2
Recall = 80%
```

## Precision 和 Recall 的区别

举个例子来说:
搜索嫌疑人
Precision就是你抓的嫌疑人中真正的嫌疑人的占比
Recall就是你抓了的真正嫌疑人占所有的真正嫌疑人的比例

## 置信度阈值

YOLO为每个预测结果一个置信度,例如:
```
猫：0.95
狗：0.82
汽车：0.61
人：0.38
```
如果置信度为0.8,那么仅猫狗能够被保留,检测更加严谨
如果置信度为0.5,猫狗汽车都能被保留,检测更加广泛(目标更多)

> [!tip] 阈值与 Precision / Recall 的关系
> 降低置信度阈值通常会保留更多预测框：Recall 可能提高，但误报也可能增加，Precision 可能下降。反之提高阈值更严谨，但容易漏检。

## 平均精度 AP

AP是针对某个目标的某个类别由 `Precision` 和 `Recall` 曲线计算出来的面积
过程为:
- 按照置信度从高到低排列所有预测框；
- 逐步增加保留的预测框；
- 每增加一部分预测框，就计算一次 Precision 和 Recall；
- 得到一条 Precision-Recall 曲线；
- 计算这条曲线下面的面积；
- 这个面积就是 AP。
例如:
```
AP_person = 0.80
AP_car    = 0.92
AP_dog    = 0.65
```

## 平均精度均值 mAP

即为同一个目标的各个类别的AP均值
例如:
```
AP_person = 0.80
AP_car    = 0.92
AP_dog    = 0.65
mAP = (0.8 + 0.92 + 0.65 ) / 3 = 0.79
```

**通常用来综合评价模型的检测能力**

### mAP@0.5
表示:
```
IoU 阈值固定为 0.5 时的mAP
```

### mAP@0.5:0.95

表示取从0.5-0.95中的各个IoU阈值计算mAP后再取均值

### 注意问题:
例如:
```
mAP@0.5 = 0.9
mAP@0.5:0.95 = 0.6
```
很有可能是由于模型的目标识别能力可以,但是边界框的回归能力弱(不能很准确地框住目标)

## YOLO训练中的各种指标

|指标|主要反映|
|---|---|
|Precision|预测结果是否容易误报|
|Recall|是否容易漏检|
|AP|某一个类别的综合检测表现|
|mAP|所有类别的平均检测表现|
|IoU|预测框和真实框的位置重叠程度|
|confidence|模型对单个预测结果的信心|

## 非极大值抑制 NMS

在检测中,一个目标附近可能会出现多个预测框,其中不断取置信度高的预测框,然后比较其他预测框与其的IoU,删除IoU过高的框(相似的),即非极大值抑制
基本步骤:
- 选择置信度最高的框；
- 删除与它 IoU 过高的其他框；
- 在剩余框中继续选择最高置信度框；
- 重复执行。

> [!note] 待深入
> 本节只记录 NMS 的直觉。**NMS 的实现原理**属于第五课之后的内容（第四课：检测输出解码与 NMS 实现原理），届时再补充代码细节。
> 在 PyTorch 侧的对应整理见 [[Pytorch学习#十八、IoU、NMS 与检测指标|IoU、NMS 与检测指标]]。

> [!note] 本课小结
> - IoU 衡量两个框的重叠程度，是判断"预测是否命中"的基础
> - Precision 看"误报"，Recall 看"漏检"，二者通常此消彼长
> - 置信度阈值是把这种权衡调到合适位置的手段
> - AP 是单类别的 P-R 曲线面积，mAP 是所有类别 AP 的均值
> - mAP@0.5 宽松、mAP@0.5:0.95 严格；两者差距大说明**框不准**而非**认不出**
> - NMS 用置信度排序 + IoU 去重，得到最终检测结果

# 第三课：YOLO 整体网络结构

> [!abstract] 本课目标
> 理解 Backbone / Neck / Head 三部分的职责，以及多尺度特征对小目标、大目标检测的意义。
>
> **PyTorch 前置**：
> - [[Pytorch学习#八、卷积层 Conv2d|卷积层 Conv2d]]——backbone 的基本单元
> - [[Pytorch学习#九、批归一化 BatchNorm2d|批归一化 BatchNorm2d]]——Conv + BN + 激活的标准组合
> - [[Pytorch学习#十、完整 CNN：卷积 → 池化 → 展平 → 全连接|完整 CNN]]——backbone 与分类网络的异同

## YOLO 整体网络结构

YOLO网络通常分为**3**个主要部分:
```
Backbone 主干网络
Neck 特征融合网络
Head 检测头
```

## Backbone: 主干网络

Backbone主要作用为: 从原始图片中提取特征

### Backbone学习的特征

1. 浅层网络中,通常学习比较简单的特征,例如:
   ```
   边缘
   颜色
   线条
   纹理
   ```
   浅层的特征: 保留细节,适合小目标
2. 深层网络中,通常学习复杂的特征,例如:
   ```
   眼睛
   车轮
   人身体
   汽车形状
   ```
   深层的特征: 语义丰富,适合大目标

### Backbone的下采样

通过卷积步长 stride 或者其他下采样方式逐渐降低图尺寸（`stride` 的用法见 [[Pytorch学习#八、卷积层 Conv2d|卷积层 Conv2d]]）
例如:
```
640 × 640
    ↓
320 × 320
    ↓
160 × 160
    ↓
80 × 80
    ↓
40 × 40
    ↓
20 × 20
```

#### 下采样的目的
1. 减少计算量
2. 扩大感受野(特征图中一个像素对应的原图的区域),可以理解更大的目标和复杂的结构

> [!warning] backbone 与分类网络的关键差别
> YOLO 的 backbone（如 CSPDarknet）本质上是大量"卷积 + 归一化 + 激活"的堆叠，但**去掉了传统分类网络末尾的全连接层**，改为输出多尺度特征图交给检测头。对比 [[Pytorch学习#十、完整 CNN：卷积 → 池化 → 展平 → 全连接|完整 CNN]] 中"卷积 → 池化 → 展平 → 全连接"的结构即可看出差异。

## Neck: 特征融合网络

主要作用为 融合深层和浅层特征,不同尺寸的特征

### 上采样和跳跃连接

为了融合不同层次的特征，通常需要对深层的特征进行上采样（本质是插值放大，插值方法见 [[视觉学习/OpenCV学习笔记/OpenCV第十课 图像几何变换#三、插值方法|图像几何变换 · 三、插值方法]]），
例如:
```
20 × 20
    ↓ 上采样
40 × 40
```
然后再和浅层的特征进行拼接,使融合的特征具有细节和语义信息

## Head: 检测头

主要作用为 根据融合后的特征,预测目标检测结果
对于每个侯选位置,Head可能预测:
```
边界框位置
目标置信度
类别概率

即
[
x_center,y_center,width,height;
objectness;
class_1,class_2...class_n
]
```
一个位置的主要预测值有 4+1+C 个
```
4: 位置
1: 目标置信度
C: 类别预测
```

> [!note] 本课小结
> - Backbone 提取特征（浅层顾细节/小目标，深层顾语义/大目标）
> - 下采样同时减少计算量、扩大感受野
> - Neck 通过上采样 + 跳跃连接融合多尺度特征
> - Head 在每个候选位置输出 `4 + 1 + C` 个值（位置 + 目标置信度 + 各类别）
> - 完整链路：图片 → Backbone → Neck → Head → 置信度筛选 → NMS → 结果

# 第四课：YOLO 检测输出、边界框解码与 NMS

> [!abstract] 本课目标
> 理解检测头如何产生大量候选预测，如何把原始输出**解码**为原图上的边界框，以及如何用**置信度阈值 + NMS** 得到最终的少量目标。
>
> **PyTorch 前置 / 对应实现**：
> - [[Pytorch学习#十八、IoU、NMS 与检测指标|IoU、NMS 与检测指标]]——NMS 与检测指标的代码实现
> - [[Pytorch学习#十七、在图片上绘制和检查边界框|在图片上绘制和检查边界框]]——后处理结果的可视化

## 检测头的预测原理
```
大致的流程为
1 检测头产生大量的原始预测
2 边界框解码
3 计算类别置信度
4 置信度阈值筛选
5 NMS去除重复框
6 输出最终检测结果
```
## 为什么不固定目标数量?
不同图片的目标数量并不确定
但是神经网络中的张量通常需要固定的形状
YOLO的预测方式为:
    `先生成固定数量的大量候选预测,再使用置信度筛选和NMS得到数量可变的最终目标`

## stride 深入
由前面的学习可以知道，stride 可以理解为在特征图中移动一个位置，相当于在原始图片中移动了多少像素（卷积中 `stride` 的定义见 [[Pytorch学习#八、卷积层 Conv2d|卷积层 Conv2d]]）。
比如:
```
原图
640 * 640
特征图
80 * 80

```
那么stride就为640/80=8
注意:
**由于深层卷积具有较大的感受野,一个特征图的点实际上能看到的比按stride计算的范围大**

## 检测头的输出是什么?
### 1.通用的表示方法
```python
[
x_center, # 中心x
y_center, # 中心y
w, # 宽度
h, # 高度
objectness, # 目标置信度
class_1,class_2...class_n # 各类别的置信度
]
```
### 2.早期YOLO Anchor-Based
原始预测通常为:
```
tx,
ty,
tw,
th,
objectness,
class scores
```
但仅靠这些并不能直接当作图片的像素坐标
还要结合
```
网格位置
stride
预设Anchor宽高
激活函数
```
才能得到最终的边界框

### 3. YOLOv8 等现代 Anchor-Free 检测头

现代的UltralyticsYOLO不在依赖预设宽高锚框,而是基于特征图参考点预测边界框
检测头通常分为两个分支:
```
特征图
|--- 边界框回归分支box branch: 框在哪里
|--- 类别预测分支class branch: 什么类别
```
这就是**解耦检测头**
一般的推理输出可以抽象为:
```
4个边界坐标 + C个类别坐标
```
而不是所有版本都固定包含一个独立的objectness通道
所以注意:
`4+1+C`是一个很有用的通用的教学模型,但不是所有现代YOLO的原始检测头都严格采用这个输出格式

## 什么是边界框解码

> [!tip] 格式背景
> 标签本身的 `class x_center y_center w h`（归一化）格式与其 `xyxy ↔ yolo` 互转实现，见 [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|YOLO 目标检测数据格式和边界框]]。本节讲的解码是它的**逆过程**：把模型输出还原成原图上的 `xyxy`。

### 1.为什么要解码?
模型的输出不一定就是直接的 xyxy，可能会输出`相对于某个特征图参考点的偏移量`或者`参考点到边界框四边的距离`
因此需要将这些预测参数变为原图中的真正的坐标
即
	`Bounding Box Decoding` 边界框解码
一般的解码流程为
```
模型原始输出
    +
特征图位置
    +
stride
    ↓
原图上的边界框坐标
```
### 2. 现代的 Anchor-Free
现在的Ahchor-Free检测器可以基于一个参考点进行预测:
```
l：参考点到框左边的距离
t：参考点到框上边的距离
r：参考点到框右边的距离
b：参考点到框下边的距离
示例:
          框的上边
     ┌──────────────┐
     │       ↑ t    │
     │       │      │
左边  │← l ──●── r  →│ 右边
     │       │      │
     │       ↓ b    │
     └──────────────┘
          框的下边

● 表示特征图参考点
```

获取到参考点的坐标以及四个距离,就能得到边界框的位置信息

#### 1-如果预测距离位于特征图尺度
例如:stride = 8
模型获取的距离参数为
```
l = 5
t = 4
r = 7
b = 6
```
转换为原图的像素距离就是
```
left_distance   = 5 × 8 = 40
top_distance    = 4 × 8 = 32
right_distance  = 7 × 8 = 56
bottom_distance = 6 × 8 = 48
```
如果参考点为:
```
anchor_x = 200 
anchor_y = 160
```
那么
```
x_min = 200 - 40 = 160
y_min = 160 - 32 = 128
x_max = 200 + 56 = 256
y_max = 160 + 48 = 208
```
注意:**使用的是图像坐标系x右正,y下正!!!**
最后得到的边界框就为
```
[160,128,256,208]
```

`Ultralytics`的核心逻辑就是现根据参考点解码边界框,再乘以对应尺度的stride后,将特征图尺度映射回输入的图片尺度

### DFL
YOLOv8 不是简单地预测一个边界框距离，而是先预测距离的概率分布，再将分布根据权重变为最终的距离
例如:
```
距离值：  0    1    2    3    4    5
概率： 0.01 0.03 0.10 0.50 0.30 0.06
模型认定距离最有可能在3附近,然后通过分布的加权期望得到距离
距离 = 0×0.01
     + 1×0.03
     + 2×0.10
     + 3×0.50
     + 4×0.30
     + 5×0.06
     = 3.23
```

## 预测类别和置信度筛选
### 1.类别分数
假设模型要识别三个类别
某个候选框的类别为
```
person = 0.10
car = 0.85
dog = 0.05
```
取最高的 car 作为该候选框的类别（`argmax` 的用法见 [[Pytorch学习#十一、分类模型完整训练流程|分类模型完整训练流程]]）
置信度就为0.85
即
```
person 0.85
```
pytorch中表示为
```python
class_scores = torch.tensor([0.10, 0.85, 0.05])

confidence, class_id = class_scores.max(dim=0) # 纵向比较,因为tensor默认为列*行

print(confidence)  # tensor(0.8500)
print(class_id)    # tensor(1)
```
### 2.objectness与类别概率
在带有独立的`objectness`的YOLO中,最终类别的置信度为:
```
最终置信度 = objectness * 类别概率
例如objectness = 0.4 ,P(car | 存在目标) = 0.85
最终置信度 = 0.4* 0.85 = 0.36 
```
表达含义为
```
模型有0.4概率认为有目标
然后存在目标的情况下,为car的概率为0.85,
最终,置信度为0.36
即由一个条件概率得到
```
但是,**对于现代的YOLO来说,不是单独的乘以一个objectness就能得到准确的结果,其类别分数需要直接参与后续的筛选!**

### 3.置信度阈值
针对于**候选框**
例如将阈值设置为0.25
其候选结果为:

| 候选框 | 置信度  | 是否保留 |
| --- | ---- | ---- |
| A   | 0.91 | 保留   |
| B   | 0.73 | 保留   |
| C   | 0.30 | 保留   |
| D   | 0.24 | 删除   |
| E   | 0.05 | 删除   |
置信度阈值筛选的作用就是筛选掉一眼看去就不可靠的预测
1- 降低置信度阈值,会造成候选框筛选更广,那么FN(漏检)情况就可能减少,Recall就可能会升高,相对应的,错检情况可能会增加,Precision可能会下降
2- 提高置信度阈值与之相反
这就是前面学习的结论
### 4.NMS在做什么?
前面所学可知:
NMS 就是在一组高度重合的**同类框**中，保留分数最高的框，剔除其他的重复框。IoU 的计算与 NMS 的完整代码见 [[Pytorch学习#十八、IoU、NMS 与检测指标|IoU、NMS 与检测指标]]。

*伪代码就是*
```
输入：
    boxes：候选框
    scores：置信度
    iou_threshold：NMS 阈值

1. 按置信度从高到低排序
2. 取出置信度最高的框，加入最终结果
3. 计算该框与剩余框的 IoU
4. 删除 IoU 大于阈值的重复框
5. 对剩下的框重复第 2～4 步
6. 没有剩余框时结束
```
根据前面所学,
NMS阈值较低时,去重的能力更强,但是最终保留的框更少,靠的近的同类真实目标会被误删
例如检测`人群`中的人时,两个很近的人可能其中一个会被误删
NMS阈值较高时,去重能力弱,保留的框更多,但是可能导致同一个目标会被保留多个重复框
即
```
NMS 阈值降低：
    删除更激进
    框更少
    更容易误删相邻目标

NMS 阈值提高：
    删除更保守
    框更多
    更容易保留重复框
```

#### 手写一个简单的NMS
```python
import torch
# 计算IoU
def box_iou_one_to_many(box, boxes):
    """
    计算一个框与多个框之间的 IoU。

    参数：
        box:   [4]，格式为 [x1, y1, x2, y2]
        boxes: [N, 4]

    返回：
        ious: [N]
    """

    # 计算交集区域的左上角
    inter_x1 = torch.maximum(box[0], boxes[:, 0])
    inter_y1 = torch.maximum(box[1], boxes[:, 1])

    # 计算交集区域的右下角
    inter_x2 = torch.minimum(box[2], boxes[:, 2])
    inter_y2 = torch.minimum(box[3], boxes[:, 3])

    # 不相交时，宽高可能为负数，因此限制最小为 0
    inter_w = (inter_x2 - inter_x1).clamp(min=0)
    inter_h = (inter_y2 - inter_y1).clamp(min=0)

    inter_area = inter_w * inter_h

    # 当前框的面积
    box_area = (
        (box[2] - box[0]) *
        (box[3] - box[1])
    )

    # 其他框的面积
    boxes_area = (
        (boxes[:, 2] - boxes[:, 0]) *
        (boxes[:, 3] - boxes[:, 1])
    )

    # 并集 = A面积 + B面积 - 交集面积
    union_area = box_area + boxes_area - inter_area

    return inter_area / union_area.clamp(min=1e-6)
    
# NMS
def simple_nms(boxes, scores, iou_threshold=0.5):
    """
    单类别 NMS。

    参数：
        boxes:  [N, 4]，格式为 [x1, y1, x2, y2]
        scores: [N]
        iou_threshold: IoU 阈值

    返回：
        保留下来的框的索引
    """

    # 按照置信度从高到低排列
    order = scores.argsort(descending=True)

    keep = []

    while order.numel() > 0:
        # 当前置信度最高框的索引
        current = order[0].item()

        # 把它加入最终结果
        keep.append(current)

        # 如果已经没有其他框，结束循环
        if order.numel() == 1:
            break

        # 剩余框的索引
        remaining = order[1:]

        # 计算最高分框与所有剩余框之间的 IoU
        ious = box_iou_one_to_many(
            boxes[current],
            boxes[remaining]
        )

        # 只保留 IoU 不超过阈值的框
        remaining = remaining[ious <= iou_threshold]

        order = remaining

    return torch.tensor(keep, dtype=torch.long)
```


**实际使用的API: nms(boxes,scores,iou_threshold)**
```python
from torchvision.ops import nms
keep = nms(
	boxes,
	scores,
	iou_threshold
)
```

### 重点注意: 置信度阈值和NMS阈值不是一回事!
置信度阈值判断的是模型是否足够相信这个候选框,低于阈值的会直接删除,避免检测到严重不可信的目标
NMS阈值判断的是候选框重合程度,IoU高于阈值,将会直接被舍弃(高度重合),避免检测到重复的同类目标

|阈值|比较对象|解决的问题|
|---|---|---|
|置信度阈值|单个预测框的置信度|删除不可信预测|
|NMS IoU 阈值|两个预测框的重叠程度|删除重复预测|
### 不要混淆三种IoU阈值

1. 评估时的IoU阈值:
	例如
   ```
   mAP@0.5
   ```
用于判断预测框是否成功命中真实框,评判TP
2. NMS的IoU阈值
	例如
```
iou = 0.6
```
用于删除重复的同类目标预测框,避免重复检测一个目标
3. 训练匹配相关的阈值或规则
训练中还需要决定:
```
哪个预测位置负责哪个真实目标
```
其中会涉及IoU后续会讲

## 完整的YOLO后处理流程
假设模型输入为
```
[1,3,640,640]
```
经过模型后:
```
输入图片
   ↓
Backbone 提取多层特征
   ↓
Neck 融合多尺度特征
   ↓
Head 生成多个尺度的原始预测
```
之后进入*后处理*
### 1. 整理多个尺度的预测
```
80*80
40*40
20*20
```
整理为大量的侯选位置
### 2.解码边界框
使用
```
参考点
预测距离
stride
```
转换为
```
[x_min,y_min,x_max,y_max]
```

### 3.得到类别和置信度
每个候选框中,选择置信度最高的类别分数及其置信度:
`class_id,confidence`

### 4.置信度筛选
设置置信度阈值后,剔除比阈值低的候选框

### 5.NMS非极大值抑制
对同类别高重合的框:
```
保留高分的框,删除低分的重复框
```
### 6.恢复到原始图片的尺寸
得到的检测框还需要从模型输入尺寸映射为原图的尺寸（缩放/插值见 [[视觉学习/OpenCV学习笔记/OpenCV第三课 图像几何操作|图像几何操作]]）
例如
```
原图1920*1080
模型输入640*640
```
最后要恢复到原始图像的尺寸大小,**将检测框画在原图上**
### 7.生成最终结果
最终目标可以表示为
```
[x_min,y_min,x_max,y_max,confidence,class_id]
例如
[120,80,350,500,0.8,0]
```

总结整个过程:
```
第一步： 获得大量的原始预测
在图片的许多位置提出大量猜测 

第二步： 边界框解码
把猜测转换成真正的矩形框

第三步：置信度筛选
删除自己都不相信的猜测

第四步：分类别NMS
把针对同一个目标的重复猜测合并

第五步：最终检测框
输出最终检测结果
```

## YOLO完成流程线

```
原始图片
    ↓
Backbone
    ↓
提取浅层和深层特征
    ↓
Neck
    ↓
融合多尺度特征
    ↓
Head
    ↓
预测多个边界框、置信度和类别
    ↓
置信度筛选
    ↓
NMS
    ↓
最终检测结果
```

> [!note] 本课小结（第四课）
> - 检测头在多个尺度上**生成固定数量的大量候选预测**，因此不要求目标数量固定
> - 解码：用**参考点 + 预测距离 + stride** 把原始输出换算成原图上的 `xyxy`（现代 Anchor-Free 用 `l/t/r/b`，YOLOv8 用 DFL 的加权期望）
> - 置信度阈值负责**删除不可信的候选框**；分类别 NMS 负责**删除同一目标上的重复框**——两者不是一回事
> - 完整链路：图片 → Backbone → Neck → Head → 多尺度解码 → 置信度筛选 → NMS → 映射回原图 → 最终结果
