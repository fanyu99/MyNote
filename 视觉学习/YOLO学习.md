# 第一课：从图像分类进入目标检测

> [!abstract] 本课目标
> 建立图像分类与目标检测的概念联系，理解 YOLO 要解决的问题，掌握目标检测标签的表示方式。
>
> **PyTorch 前置**：
> - [[Pytorch学习#十一、分类模型完整训练流程|分类模型完整训练流程]]——分类任务的输出 `[B, C]` 与 `CrossEntropyLoss`
> - [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|YOLO 数据格式和边界框]]——同一份边界框知识在 PyTorch 侧的代码实现

## 图像分类

一般输入一张图片后进行判断图像属于哪种类别
例如:
```
一张图片outputs -> 各类别得分,例如[1.0,2.4,2.2,1.2 ...]
然后取其中最高分(例如2.4)
对应类别1,判断图片属于类别1
```

> [!tip] 对应 PyTorch 实现
> 取最高分即 `output.argmax(dim=1)`，见 [[Pytorch学习#十一、分类模型完整训练流程|分类模型完整训练流程]]。

## YOLO目标检测

一般输入一张图片后进行检测图像中的目标,检测目标是什么并确定其位置
例如:
```
一张图片中存在1个人,1辆车,4棵树
目标检测中,检测图片中:

类别0:person
位置:0.2 0.2 0.3 0.3
置信度: 0.9

...
```

## 两种任务的核心差异

| 对比项目        | 图像分类     | 目标检测                    |
| ----------- | -------- | ----------------------- |
| 主要问题        | 图片是什么    | 图片中有什么、在哪里              |
| 一张图片的目标数量   | 通常一个主要类别 | 可以是 0 个、1 个或多个          |
| 标签          | 一个类别编号   | 多个目标的类别和边界框             |
| 模型输出        | 类别分数     | 多个候选框、类别和置信度            |
| 常见指标        | Accuracy | Precision、Recall、AP、mAP |

> [!warning] 为什么不能只改分类模型的最后一层
> 分类模型输出固定大小的 `[B, C]`，而检测模型要为一张图片预测**数量可变**的多个目标，还要额外输出边界框位置和置信度，因此标签、损失函数和评价指标都要一起改变。这一差异在第 2~3 课展开。

## YOLO目标检测中的边界框

目标检测中的数据标注经常使用:
```
class x_center y_center width height

例如: 0 0.5 0.375 0.5 0.5
0       → 类别编号
0.5     → 边界框中心点 x 
0.375   → 边界框中心点 y
0.5     → 边界框宽度
0.5     → 边界框高度
坐标和宽高皆为归一化结果,方便不同尺寸图片确定位置
```

> [!tip] 代码实现
> `xyxy ↔ yolo` 格式互转的函数实现，以及标签文件目录结构，见 [[Pytorch学习#十六、YOLO 目标检测数据格式和边界框|YOLO 目标检测数据格式和边界框]]。

## YOLO重要思想

YOLO的核心思想为
```
图像 -> 一个网络 -> 同时预测目标位置和类别
```
one_stage模型速度快,常用于实时检测

> [!note] 本课小结
> - 分类回答"图片是什么"，检测回答"图中有什么、在哪里、有多可信"
> - YOLO 标签 = `class x_center y_center width height`，后四项归一化到 0~1
> - YOLO 用**一次前向传播**同时预测位置和类别，属于 one-stage 检测

# 第二课：IoU、Precision、Recall、AP、mAP

> [!abstract] 本课目标
> 理解模型预测框如何与真实框匹配，以及如何评价检测结果的好坏。
>
> **PyTorch 前置 / 对应实现**：
> - [[Pytorch学习#十八、IoU、NMS 与检测指标|IoU、NMS 与检测指标]]——本课概念的代码与公式汇总

## IoU 交并比

公式为
$$
IoU  = 交集面积 / 并集面积
$$

用于判断:
- 预测框和真实框是否匹配
- 计算目标检测指标
- 参与 YOLO 损失函数

## TP、FP、FN

TP : True Positive 即真实的目标被检测,正确检测
例如:
```
真实目标: 猫
检测目标: 猫,且位置正确(大于阈值)
```
FP : False Positive 即非真实目标被检测,错检
例如:
```
真实目标: 狗
检测目标: 其他,但是位置重叠程度高
```
FN : False Negative  即真实目标未被检测,漏检
例如:
```
真实目标: 狗
检测目标: 无
例如有3条狗,但是仅检测到2条
```

> [!warning] 类别正确 ≠ TP
> 即使类别预测正确，如果预测框与真实框的 IoU 低于阈值（如 0.5），这条预测仍然不能算 TP，通常计为 FP，同时对应的真实目标会形成 FN。

## 精确度 Precision

$$
Precision = TP / (TP + FP)
$$
回答的问题就是: 检测出来的目标,有多少是真正正确的?
例如:
```
检测出来10个目标,但是有2个目标并不存在或错误
即: TP = 8 ; FP = 2
Precision = 80%
```

## 召回率 Recall

$$
Recall = TP / (TP + FN)
$$
回答的问题就是: 真实存在的目标到底有多少被找到了
例如:
```
真正存在目标共10个,真实检测到了8个,但是没有检查到2个
即: TP = 8 ; FN = 2
Recall = 80%
```

## Precision 和 Recall 的区别

举个例子来说:
搜索嫌疑人
Precision就是你抓的嫌疑人中真正的嫌疑人的占比
Recall就是你抓了的真正嫌疑人占所有的真正嫌疑人的比例

## 置信度阈值

YOLO为每个预测结果一个置信度,例如:
```
猫：0.95
狗：0.82
汽车：0.61
人：0.38
```
如果置信度为0.8,那么仅猫狗能够被保留,检测更加严谨
如果置信度为0.5,猫狗汽车都能被保留,检测更加广泛(目标更多)

> [!tip] 阈值与 Precision / Recall 的关系
> 降低置信度阈值通常会保留更多预测框：Recall 可能提高，但误报也可能增加，Precision 可能下降。反之提高阈值更严谨，但容易漏检。

## 平均精度 AP

AP是针对某个目标的某个类别由 `Precision` 和 `Recall` 曲线计算出来的面积
过程为:
- 按照置信度从高到低排列所有预测框；
- 逐步增加保留的预测框；
- 每增加一部分预测框，就计算一次 Precision 和 Recall；
- 得到一条 Precision-Recall 曲线；
- 计算这条曲线下面的面积；
- 这个面积就是 AP。
例如:
```
AP_person = 0.80
AP_car    = 0.92
AP_dog    = 0.65
```

## 平均精度均值 mAP

即为同一个目标的各个类别的AP均值
例如:
```
AP_person = 0.80
AP_car    = 0.92
AP_dog    = 0.65
mAP = (0.8 + 0.92 + 0.65 ) / 3 = 0.79
```

**通常用来综合评价模型的检测能力**

### mAP@0.5
表示:
```
IoU 阈值固定为 0.5 时的mAP
```

### mAP@ 0.5:0.95

表示取从0.5-0.95中的各个IoU阈值计算mAP后再取均值

### 注意问题:
例如:
```
mAP@0.5 = 0.9
mAP@0.5:0.95 = 0.6
```
很有可能是由于模型的目标识别能力可以,但是边界框的回归能力弱(不能很准确地框住目标)

## YOLO训练中的各种指标

|指标|主要反映|
|---|---|
|Precision|预测结果是否容易误报|
|Recall|是否容易漏检|
|AP|某一个类别的综合检测表现|
|mAP|所有类别的平均检测表现|
|IoU|预测框和真实框的位置重叠程度|
|confidence|模型对单个预测结果的信心|

## 非极大值抑制 NMS

在检测中,一个目标附近可能会出现多个预测框,其中不断取置信度高的预测框,然后比较其他预测框与其的IoU,删除IoU过高的框(相似的),即非极大值抑制
基本步骤:
- 选择置信度最高的框；
- 删除与它 IoU 过高的其他框；
- 在剩余框中继续选择最高置信度框；
- 重复执行。

> [!note] 待深入
> 本节只记录 NMS 的直觉。**NMS 的实现原理**属于第五课之后的内容（第四课：检测输出解码与 NMS 实现原理），届时再补充代码细节。
> 在 PyTorch 侧的对应整理见 [[Pytorch学习#十八、IoU、NMS 与检测指标|IoU、NMS 与检测指标]]。

> [!note] 本课小结
> - IoU 衡量两个框的重叠程度，是判断"预测是否命中"的基础
> - Precision 看"误报"，Recall 看"漏检"，二者通常此消彼长
> - 置信度阈值是把这种权衡调到合适位置的手段
> - AP 是单类别的 P-R 曲线面积，mAP 是所有类别 AP 的均值
> - mAP@0.5 宽松、mAP@0.5:0.95 严格；两者差距大说明**框不准**而非**认不出**
> - NMS 用置信度排序 + IoU 去重，得到最终检测结果

# 第三课：YOLO 整体网络结构

> [!abstract] 本课目标
> 理解 Backbone / Neck / Head 三部分的职责，以及多尺度特征对小目标、大目标检测的意义。
>
> **PyTorch 前置**：
> - [[Pytorch学习#八、卷积层 Conv2d|卷积层 Conv2d]]——backbone 的基本单元
> - [[Pytorch学习#九、批归一化 BatchNorm2d|批归一化 BatchNorm2d]]——Conv + BN + 激活的标准组合
> - [[Pytorch学习#十、完整 CNN：卷积 → 池化 → 展平 → 全连接|完整 CNN]]——backbone 与分类网络的异同

## YOLO 整体网络结构

YOLO网络通常分为**3**个主要部分:
```
Backbone 主干网络
Neck 特征融合网络
Head 检测头
```

## Backbone: 主干网络

Backbone主要作用为: 从原始图片中提取特征

### Backbone学习的特征

1. 浅层网络中,通常学习比较简单的特征,例如:
   ```
   边缘
   颜色
   线条
   纹理
   ```
   浅层的特征: 保留细节,适合小目标
2. 深层网络中,通常学习复杂的特征,例如:
   ```
   眼睛
   车轮
   人身体
   汽车形状
   ```
   深层的特征: 语义丰富,适合大目标

### Backbone的下采样

通过卷积步长stride或者其他下采样方式逐渐降低图尺寸
例如:
```
640 × 640
    ↓
320 × 320
    ↓
160 × 160
    ↓
80 × 80
    ↓
40 × 40
    ↓
20 × 20
```

#### 下采样的目的
1. 减少计算量
2. 扩大感受野(特征图中一个像素对应的原图的区域),可以理解更大的目标和复杂的结构

> [!warning] backbone 与分类网络的关键差别
> YOLO 的 backbone（如 CSPDarknet）本质上是大量"卷积 + 归一化 + 激活"的堆叠，但**去掉了传统分类网络末尾的全连接层**，改为输出多尺度特征图交给检测头。对比 [[Pytorch学习#十、完整 CNN：卷积 → 池化 → 展平 → 全连接|完整 CNN]] 中"卷积 → 池化 → 展平 → 全连接"的结构即可看出差异。

## Neck: 特征融合网络

主要作用为 融合深层和浅层特征,不同尺寸的特征

### 上采样和跳跃连接

为了融合不同层次的特征,通常需要对深层的特征进行上采样,
例如:
```
20 × 20
    ↓ 上采样
40 × 40
```
然后再和浅层的特征进行拼接,使融合的特征具有细节和语义信息

## Head: 检测头

主要作用为 根据融合后的特征,预测目标检测结果
对于每个侯选位置,Head可能预测:
```
边界框位置
目标置信度
类别概率

即
[
x_center,y_center,width,height;
objectness;
class_1,class_2...class_n
]
```
一个位置的主要预测值有 4+1+C 个
```
4: 位置
1: 目标置信度
C: 类别预测
```

## YOLO完成流程线

```
原始图片
    ↓
Backbone
    ↓
提取浅层和深层特征
    ↓
Neck
    ↓
融合多尺度特征
    ↓
Head
    ↓
预测多个边界框、置信度和类别
    ↓
置信度筛选
    ↓
NMS
    ↓
最终检测结果
```

> [!note] 本课小结
> - Backbone 提取特征（浅层顾细节/小目标，深层顾语义/大目标）
> - 下采样同时减少计算量、扩大感受野
> - Neck 通过上采样 + 跳跃连接融合多尺度特征
> - Head 在每个候选位置输出 `4 + 1 + C` 个值
> - 完整链路：图片 → Backbone → Neck → Head → 置信度筛选 → NMS → 结果
