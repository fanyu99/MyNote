# 图像基础与色彩空间（主题模块）

> 归纳：图像的本质、颜色顺序、色彩空间及其转换。

---

## 一、核心概念

### 图像的本质

一张图片本质上是**一块内存**：

- 大小为 **宽度 × 高度**
- 值为**像素值**（灰度图存灰度值，彩色图存各通道亮度）

### BGR 颜色顺序

- OpenCV 使用 **BGR**（蓝绿红），与常规 **RGB** 不同。
- 例：纯红色在 OpenCV 中为 `cv::Scalar(0, 0, 255)`。

---

## 二、关键 API / 函数

| 函数 | 作用 | 备注 |
| --- | --- | --- |
| `cv::cvtColor()` | 色彩空间转换 | 如 `COLOR_BGR2RGB` |

---

## 三、色彩空间对照

| 颜色顺序 | 适用场景 |
| --- | --- |
| **BGR** | OpenCV 默认 |
| **RGB** | Qt 显示、常规图片 |

> 与 Qt 集成时需用 `cv::cvtColor` 做 BGR → RGB 转换，否则**红蓝互换**。

---

## 四、易错点 / 注意事项

- OpenCV 是 BGR 不是 RGB，直接显示会颜色错乱。
- 灰度图取值范围：8 位无符号整数 **0 ~ 255**。
