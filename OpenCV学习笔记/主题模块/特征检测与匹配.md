# 特征检测与匹配（主题模块）

> 归纳：边缘检测、角点检测、特征描述子与匹配。

---

## 一、核心概念

### 边缘检测（第八课已学）

- **边缘** = 像素灰度变化较快的位置，可用**梯度强度**衡量：`G = sqrt(Gx²+Gy²)`（L2）或 `G = |Gx|+|Gy|`（L1）。
- **Sobel**（一阶）：分 x / y 方向检测；`dx` 强变化→垂直边缘，`dy` 强变化→水平边缘；结果可能为负，需 `CV_16S` 保存。
- **Scharr**（一阶）：专为 `3×3` 核设计，比 Sobel 更精确。
- **Laplacian**（二阶）：一次检测多方向，但对噪声敏感，使用前需高斯滤波。
- **Canny**（多阶段）：高斯去噪 → 梯度 → 非极大值抑制 → 双阈值 → 滞后边缘连接；输出**二值边缘图**，可直接供 `findContours` 使用。

### 霍夫变换（第九课已学）

- **核心思想**：把"图像空间找直线/圆"转化为"参数空间累加器投票"，票数超过阈值即判定存在目标。
- **直线表示**：极坐标 `ρ = xcosθ + ysinθ`；输入为**二值边缘图**（Canny 输出）。
- **`HoughLines()`**：输出 `Vec2f(rho, theta)`（无限直线，需自行换算两点绘制）。
- **`HoughLinesP()`**：输出 `Vec4i(x1,y1,x2,y2)`（真实线段，直接得端点），工程中更常用、更快。
- **`HoughCircles()`**：内部自动调用 Canny，输出 `Vec3f(cx, cy, radius)`；对遮挡容忍度较强。

（角点检测、特征描述子与匹配待后续课程归纳。）

## 二、关键 API / 函数

| 函数 | 作用 | 参数 | 备注 |
| --- | --- | --- | --- |
| `cv::Canny` | 边缘检测 | `(image, edges, threshold1, threshold2)` | 输出二值边缘图，供 Hough / findContours 使用 |
| `cv::HoughLines` | 霍夫直线检测 | `(image, lines, rho, theta, threshold)` | 输出 `Vec2f`，无限直线 |
| `cv::HoughLinesP` | 概率霍夫直线检测 | `(image, lines, rho, theta, threshold, minLineLength, maxLineGap)` | 输出 `Vec4i`，真实线段，更常用 |
| `cv::HoughCircles` | 霍夫圆检测 | `(image, circles, method, dp, minDist, param1, param2, minRadius, maxRadius)` | 内部自动 Canny，输出 `Vec3f` |
