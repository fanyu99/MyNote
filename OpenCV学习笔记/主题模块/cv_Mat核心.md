# cv::Mat 核心（主题模块）

> 归纳：OpenCV 核心类 `cv::Mat` 的结构、数据类型与像素访问。

---

## 一、核心概念

### 什么是 cv::Mat

`cv::Mat` 表示一个**矩阵**，可承载图片、视频帧、灰度/彩色/二值/深度数据、算法中间结果。

比普通二维数组更强，额外管理：

- 数据类型、通道数量、行数/列数
- 内存空间、引用计数、数据共享、ROI 区域

---

## 二、关键 API / 函数

| 函数/属性 | 作用 |
| --- | --- |
| `mat.cols` / `mat.rows` | 宽 / 高 |
| `mat.channels()` | 通道数 |
| `mat.at<uchar>(y, x)` | 灰度像素访问 |
| `mat.at<cv::Vec3b>(y, x)` | 彩色像素访问（返回 BGR） |

> Python 中用 `image.shape`：`[0]`高度、`[1]`宽度、`[2]`通道；`image[y, x]` 为 **行, 列**。

---

## 三、数据类型速查

| 类型 | 含义 | 对应关系 |
| --- | --- | --- |
| `CV_8UC1` | 8 位无符号整数，1 通道 | 灰度图 |
| `CV_8UC3` | 8 位无符号整数，3 通道 | BGR 彩图 |
| `CV_8UC4` | 8 位无符号整数，4 通道 | BGRA 彩图 |
| `CV_32FC1` | 32 位浮点数，1 通道 | — |

> 格式：`CV_<位数><类型><通道数>`；`CV_8U` 范围 **0 ~ 255**。

---

## 四、易错点 / 注意事项

- 访问像素是 `image[y, x]`（行, 列），不是 `[x, y]`。
- 彩色访问返回顺序为 **BGR**。
