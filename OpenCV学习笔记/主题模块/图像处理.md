# 图像处理（主题模块）

> 归纳：滤波、阈值、形态学、几何变换等图像处理知识。

---

## 一、核心概念

### 几何变换（第三课已学）

- **坐标体系**：x 右正、y 下正，原点在左上角；`cv::Size` 顺序为**宽、高**。
- **缩放**：`cv::resize`，`dsize` 与 `(fx, fy)` 二选一；缩小用 `INTER_AREA`，放大用 `INTER_LINEAR / INTER_CUBIC`。
- **保持比例**：`targetHeight = targetWidth * rows / cols`。
- **裁剪 ROI**：`cv::Rect(x, y, w, h)`，默认浅拷贝，独立需 `.clone()`。
- **翻转**：`cv::flip(src, dst, flipCode)`，1 左右 / 0 上下 / -1 上下左右。
- **旋转 90°**：`cv::rotate`；任意角度用 `getRotationMatrix2D` + `warpAffine`。
- **平移**：2×3 仿射矩阵 + `warpAffine`。

（滤波、阈值、形态学等待后续课程归纳。）

---

## 二、关键 API / 函数

| 函数 | 作用 | 参数 | 备注 |
| --- | --- | --- | --- |
| `cv::resize` | 缩放图像 | `(src, dst, dsize, fx, fy, interpolation)` | `dsize` 与 `(fx,fy)` 二选一 |
| `cv::flip` | 翻转 | `(src, dst, flipCode)` | 1 左右 / 0 上下 / -1 两者 |
| `cv::rotate` | 旋转 90° 整数倍 | `(src, dst, ROTATE_*)` | 90° 旋转会互换宽高 |
| `cv::getRotationMatrix2D` | 生成旋转仿射矩阵 | `(center, angle, scale)` | 正值逆时针 |
| `cv::warpAffine` | 仿射变换（旋转/平移） | `(src, dst, M, dsize)` | 任意角度核心 |

---

## 三、代码示例

```cpp
cv::Mat resized;
cv::resize(image, resized, cv::Size(400, 300));

cv::Mat rotated30;
cv::Mat M = cv::getRotationMatrix2D(
    cv::Point2f(image.cols / 2.0F, image.rows / 2.0F), 30.0, 1.0);
cv::warpAffine(image, rotated30, M, image.size());
```

```python
resized = cv2.resize(image, (400, 300))
M = cv2.getRotationMatrix2D((w // 2, h // 2), 30, 1.0)
rotated30 = cv2.warpAffine(image, M, (w, h))
```

---

## 四、易错点 / 注意事项

- `cv::Size` 与坐标是**宽、高**顺序，容易与 `(y, x)` 混淆写反。
- ROI 默认**浅拷贝**；ROI 不能超出图像范围。
- 90° 旋转会**互换宽高**。
- 任意角度旋转保持原尺寸时，边缘会被裁切，需计算包围盒调整输出尺寸。
