# 图像处理（主题模块）

> 归纳：滤波、阈值、形态学、几何变换等图像处理知识。

---

## 一、核心概念

### 几何变换（第三课已学）

- **坐标体系**：x 右正、y 下正，原点在左上角；`cv::Size` 顺序为**宽、高**。
- **缩放**：`cv::resize`，`dsize` 与 `(fx, fy)` 二选一；缩小用 `INTER_AREA`，放大用 `INTER_LINEAR / INTER_CUBIC`。
- **保持比例**：`targetHeight = targetWidth * rows / cols`。
- **裁剪 ROI**：`cv::Rect(x, y, w, h)`，默认浅拷贝，独立需 `.clone()`。
- **翻转**：`cv::flip(src, dst, flipCode)`，1 左右 / 0 上下 / -1 上下左右。
- **旋转 90°**：`cv::rotate`；任意角度用 `getRotationMatrix2D` + `warpAffine`。
- **平移**：2×3 仿射矩阵 + `warpAffine`。

### 滤波（第五课已学）

- **基本思想**：用**卷积核**（小窗口）逐像素滑动，用窗口内像素计算中心新值；核通常为**奇数 × 奇数**，核越大平滑越强、细节损失越多。
- **均值滤波**：邻域求平均（`blur` / `boxFilter`），简单快，但会同时模糊噪声与边缘。
- **高斯滤波**：按距中心距离加权平均（`GaussianBlur`），去噪自然，常用于 Canny 预处理。
- **中值滤波**：取邻域中位数（`medianBlur`），抗椒盐噪声最佳，更保护边缘。
- **双边滤波**：同时考虑空间距离与像素值差异（`bilateralFilter`），保边去噪最好但最慢。
- **选型**：椒盐 → 中值；普通去噪 → 高斯；人像保边 → 双边。

### 形态学（第六课已学）

- **基本概念**：结构元素（Kernel）为**矩形 / 椭圆 / 十字形**；作用于**二值图像**，前景白（255）、背景黑（0）。
- **腐蚀** = 取局部最小（`erode`）：白色收缩，去小白点、分离粘连目标。
- **膨胀** = 取局部最大（`dilate`）：白色扩张，填补间隙、连接断裂目标。
- **开运算**（先腐后膨）：去小白点 / 粘连物；**闭运算**（先膨后腐）：填黑洞 / 连断裂。
- **形态学梯度**（膨胀 − 腐蚀）：提取目标轮廓。
- **顶帽**（原图 − 开）提取亮区；**黑帽**（闭 − 原图）提取暗区。
- ⚠️ 结构元素尺寸**不要大于处理目标**，否则目标会被直接腐蚀掉。

（阈值等待后续课程归纳。）

### 轮廓检测（第七课已学）

- **预处理**：先二值化 / Canny 边缘检测（见 [[OpenCV第八课 Canny边缘检测]]），一般为**白色目标、黑色背景**。
- **`findContours`** 会修改输入图像，保护原图用 `.clone()`；常用 `RETR_EXTERNAL`（只取最外层）+ `CHAIN_APPROX_SIMPLE`（压缩点）。
- **轮廓特征**：面积 `contourArea`、周长 `arcLength(contour, true)`、外接矩形 `boundingRect`、中心点 `moments`（**需判断 `m00` 是否为 0**）、最小外接圆 `minEnclosingCircle`、轮廓近似 `approxPolyDP`、填充程度 `extent`。
- **形状判断**：`approxPolyDP` 顶点数量可辅助判断，但不绝对可靠，需综合面积 / 周长 / 宽高比 / 圆度 / 凸性。
- **轮廓数量 ≠ 目标数量**：需结合**面积过滤**与**形态学处理**去除噪声。

## 二、关键 API / 函数

| 函数 | 作用 | 参数 | 备注 |
| --- | --- | --- | --- |
| `cv::resize` | 缩放图像 | `(src, dst, dsize, fx, fy, interpolation)` | `dsize` 与 `(fx,fy)` 二选一 |
| `cv::flip` | 翻转 | `(src, dst, flipCode)` | 1 左右 / 0 上下 / -1 两者 |
| `cv::rotate` | 旋转 90° 整数倍 | `(src, dst, ROTATE_*)` | 90° 旋转会互换宽高 |
| `cv::getRotationMatrix2D` | 生成旋转仿射矩阵 | `(center, angle, scale)` | 正值逆时针 |
| `cv::warpAffine` | 仿射变换（旋转/平移） | `(src, dst, M, dsize)` | 任意角度核心 |
| `cv::blur` | 均值滤波 | `(src, dst, Size)` | 邻域求平均 |
| `cv::GaussianBlur` | 高斯滤波 | `(src, dst, Size, sigmaX, sigmaY)` | 加权平均，去噪更自然 |
| `cv::medianBlur` | 中值滤波 | `(src, dst, ksize)` | 抗椒盐噪声最佳，`ksize` 为奇数 |
| `cv::bilateralFilter` | 双边滤波 | `(src, dst, d, sigmaColor, sigmaSpace)` | 保边去噪，速度慢 |
| `cv::getStructuringElement` | 创建结构元素 | `(shape, ksize)` | shape: RECT/ELLIPSE/CROSS |
| `cv::erode` | 腐蚀 | `(src, dst, kernel, anchor, iterations)` | 取局部最小，白色收缩 |
| `cv::dilate` | 膨胀 | `(src, dst, kernel, anchor, iterations)` | 取局部最大，白色扩张 |
| `cv::morphologyEx` | 形态学组合运算 | `(src, dst, op, kernel)` | op: OPEN/CLOSE/GRADIENT/TOPHAT/BLACKHAT |

## 三、代码示例

```cpp
cv::Mat resized;
cv::resize(image, resized, cv::Size(400, 300));

cv::Mat rotated30;
cv::Mat M = cv::getRotationMatrix2D(
    cv::Point2f(image.cols / 2.0F, image.rows / 2.0F), 30.0, 1.0);
cv::warpAffine(image, rotated30, M, image.size());

// 四种滤波
cv::Mat blurred, gaussian, median, bilateral;
cv::blur(image, blurred, cv::Size(5, 5));                          // 均值
cv::GaussianBlur(image, gaussian, cv::Size(5, 5), 0);              // 高斯
cv::medianBlur(image, median, 5);                                  // 中值
cv::bilateralFilter(image, bilateral, 9, 75, 75);                  // 双边

// 形态学（结构元素 + 组合运算）
cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT, cv::Size(5, 5));
cv::Mat eroded, opened, gradient;
cv::erode(binary, eroded, kernel);                                // 腐蚀
cv::morphologyEx(binary, opened, cv::MORPH_OPEN, kernel);         // 开运算
cv::morphologyEx(binary, gradient, cv::MORPH_GRADIENT, kernel);   // 梯度
```

```python
resized = cv2.resize(image, (400, 300))  # -> np.ndarray
M = cv2.getRotationMatrix2D((w // 2, h // 2), 30, 1.0)  # -> np.ndarray (2×3)
rotated30 = cv2.warpAffine(image, M, (w, h))  # -> np.ndarray

# 四种滤波
blurred   = cv2.blur(image, (5, 5))                       # 均值   -> np.ndarray
gaussian  = cv2.GaussianBlur(image, (5, 5), 0)            # 高斯   -> np.ndarray
median    = cv2.medianBlur(image, 5)                      # 中值   -> np.ndarray
bilateral = cv2.bilateralFilter(image, 9, 75, 75)         # 双边   -> np.ndarray

# 形态学
kernel   = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))   # -> np.ndarray
eroded   = cv2.erode(binary, kernel)                      # 腐蚀   -> np.ndarray
opened   = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)     # -> np.ndarray
gradient = cv2.morphologyEx(binary, cv2.MORPH_GRADIENT, kernel) # -> np.ndarray
```

## 四、易错点 / 注意事项

- `cv::Size` 与坐标是**宽、高**顺序，容易与 `(y, x)` 混淆写反。
- ROI 默认**浅拷贝**；ROI 不能超出图像范围。
- 90° 旋转会**互换宽高**。
- 任意角度旋转保持原尺寸时，边缘会被裁切，需计算包围盒调整输出尺寸。
