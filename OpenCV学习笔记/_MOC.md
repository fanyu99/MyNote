## 🧭 四、学习路线（建议）

1. **基础入门**：图像本质 → cv::Mat → 数据类型 → 读写/显示 → 像素访问（← 第一课）
2. **图像处理**：滤波 → 阈值 → 形态学 → 几何变换
3. **特征检测**：边缘检测 → 角点 → 特征匹配
4. **进阶方向**：目标检测 / 深度学习 / 与 Qt 或 C++ 工程结合

> 每一阶段学完，回填对应[[#三、主题模块（知识归纳）|主题模块]]。
