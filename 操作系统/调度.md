# 调度

> 概述：本篇梳理**「谁来分、什么时候分、按什么规则分」**处理机这条主线：
> **调度层次（三级）→ 进程调度的时机与方式 → 评价指标 → 调度算法（FCFS / SJF / HRRN / RR / 优先级 / 多级反馈队列）→ 多处理机调度**。

---

## 一、调度的层次

按「调度的对象」和「发生的频率」分为三级，越靠下越频繁。

| 层次 | 别名 | 调度对象 | 频率 | 作用 |
| --- | --- | --- | --- | --- |
| 高级调度 | 作业调度 | **外存**中的作业 | 最低 | 决定哪些作业调入内存 |
| 中级调度 | 内存调度 | 内存 / 外存间的进程 | 居中 | 决定哪些进程可驻留内存 |
| 低级调度 | 进程调度 / 处理机调度 | **就绪队列**中的进程 | 最高 | 决定哪个进程占用处理机 |

### 1. 高级调度（作业调度）

- **作业**：某一个具体的任务（某个程序），保存在**外存**中。
- 按照某种规则从**作业队列（后备队列）**中选取一个**调入内存**，并**创建进程**。
- 每个作业**只调入一次、调出一次**：调入时创建 PCB，调出时撤销 PCB。

### 2. 中级调度（内存调度）

- 内存不够时，将某些进程的数据**调到外存（挂起队列）**中；等内存有空闲或进程需要运行时再**重新调入内存**。
- 按照某种策略决定哪一个处于**挂起状态**的进程**重新调入内存**。
- **目的**：提高**内存利用率**和系统**吞吐量**（在内存紧张时平衡资源）。

### 3. 低级调度（进程调度 / 处理机调度）

- 按照某个策略从**就绪队列**中选取一个进程，将**处理机**分配给它。
- 是**最基本**的一种调度，**频率很高**。

## 二、进程调度的时机与方式

### 1. 时机

**① 进程主动放弃**处理机：

- 进程**正常终止**；
- 进程运行中**发生异常而终止**；
- 进程**主动请求阻塞**（例如等待 I/O）。

**② 进程被动放弃**处理机：

- 进程**时间片用完**；
- 有**更加紧急的事务**要处理（如 I/O 中断）。

### 2. 不能进行进程调度和切换的情况

1. 在**处理中断**的过程中；
2. 进程在**操作系统内核程序临界区**中；
3. 在**原子操作（原语）**过程中。

> [!note] 什么是操作系统内核程序临界区？
> - **临界资源**：一个时间段内只允许一个进程使用的资源，各进程需**互斥访问**。
> - **临界区**：访问临界资源的那段代码。
> - **内核程序临界区**：一般不直接访问临界资源，而是用来访问某种**内核数据结构**（如进程的就绪队列）的代码。
>
> 注意：进程在**普通临界区**中**可以**被调度；只有在内核程序临界区中才**不能**调度。

### 3. 进程调度的方式

| 方式 | 别名 | 含义 | 触发 |
| --- | --- | --- | --- |
| 非剥夺方式 | 非抢占方式 | 只允许进程**主动放弃**处理机 | 进程自己让出 |
| 剥夺方式 | 抢占方式 | 允许**更紧急的进程**抢占当前进程的处理机 | 时间片到 / 更高优先级到达 / 更紧急事务 |

> 剥夺方式**响应快、吞吐量高**，但**切换开销大**、实现复杂。

## 三、调度算法的评价指标

| 指标 | 定义 | 公式 |
| --- | --- | --- |
| CPU 利用率 | CPU 真正执行指令的时间占比 | `忙碌时间 / 总时间` |
| 系统吞吐量 | 单位时间内完成的作业数量 | `完成作业总数 / 总时间` |
| 周转时间 | 从**作业提交**到**作业完成**的时间间隔 | `完成时间 − 提交时间 = 等待时间 + 服务时间` |
| 带权周转时间 | 周转时间与实际服务时间的比值（**≥ 1**） | `周转时间 / 实际运行时间` |
| 等待时间 | 进程 / 作业**处于等待处理机状态**的时间之和 | 见下 |
| 响应时间 | 从用户提交请求到**首次产生响应**的时间 | — |

- **平均周转时间** = 各作业周转时间之和 / 作业数。
- **平均带权周转时间** = 各作业带权周转时间之和 / 作业数。
- **等待时间**：
  - 进程：在**就绪队列**等待的时间；作业：在**后备队列**等待的时间。
  - ⚠️ **等待 I/O 的时间不计入等待时间**。对进程而言：`等待时间 = 周转时间 − 运行时间 − I/O 操作时间`；对作业而言：`等待时间 = 周转时间 − 运行时间`。

## 四、调度算法

### 1. 先来先服务 FCFS

- 按作业 / 进程**到达的先后顺序**排队服务。
- **非抢占式**，进程主动放弃时触发。
- 对**长作业有利**（有利于 CPU 繁忙型作业），对**短作业不利**（不利于 I/O 繁忙型作业）。
- **不会导致饥饿**。

### 2. 短作业优先 SJF（短进程优先 SPF）

- 每次选择**运行时间最短**的作业 / 进程服务。
- 一般为**非抢占式**；抢占式为 **SRTN（最短剩余时间优先）**：若当前进程的**剩余时间 > 新到达作业的服务时间**，则抢占。
- 在**所有作业同时到达**的前提下，**平均等待时间、平均周转时间最少**。
- 对**短作业有利**，可能导致**长作业饥饿**（一直得不到执行，甚至「饿死」）。

### 3. 高响应比优先 HRRN

- 先计算**响应比**，选择最高者：
  `响应比 = (等待时间 + 要求服务时间) / 要求服务时间 = 1 + 等待时间 / 服务时间`
- **非抢占式**，进程主动放弃时触发。
- **综合考虑**了等待时间和运行时间（短作业时看运行时间，长作业等待久后响应比升高）。
- **不会导致饥饿**。

### 4. 时间片轮转 RR

- 为各进程分发**时间片**，时间片用完后进程被**剥夺** CPU。
- **抢占式**，依靠**时钟中断**通知 CPU 时间片已到并进行剥夺。
- 时间片**过大**时退化为 **FCFS**；**过小**则进程切换过于频繁、开销大。
- **不会导致饥饿**；适用于分时系统，**响应快**。

### 5. 优先级调度

- 每个作业 / 进程有**优先级**，优先级最高者优先（相同优先级按 FCFS）。
- 分**静态优先级** / **动态优先级**；分**抢占式** / **非抢占式**。
- 可能导致**饥饿**（可用「**老化**」——随时间提高等待进程的优先级——来缓解）。

### 6. 多级反馈队列调度

- 设置**多级就绪队列**，各级队列的**优先级从高到低**、**时间片从小到大**。
- **规则**：
  1. 新进程先进入**第 1 级队列队尾**，按 FCFS 等待调度；
  2. 若某进程用完整级队列的时间片仍未结束，则移入**下一级队列队尾**；若已在最低一级，则**重新放回最低级队尾**（最低级通常用**时间片轮转**）。
  3. **只有第 k 级队列为空时，才为第 k+1 级队首进程分配时间片**。
- **抢占式**：若正在执行的进程所在队列优先级低于新到达进程的队列，则立即被抢占，被抢占进程**放回原队列队尾**。
- **不会导致饥饿**，兼顾短作业与长作业、响应与吞吐，是目前公认**较好**的一种算法。

### 7. 各算法对比总表

| 算法 | 是否可抢占 | 是否饥饿 | 特点 |
| --- | --- | --- | --- |
| FCFS | 非抢占 | 不会 | 公平、简单，利于长作业 |
| SJF / SPF | 非抢占（SRTN 抢占） | **会** | 平均周转时间最短，利于短作业 |
| HRRN | 非抢占 | 不会 | 兼顾等待时间与服务时间 |
| 时间片轮转 | 抢占 | 不会 | 响应快，适合分时系统 |
| 优先级 | 均可 | **会** | 可静态 / 动态，需防饥饿 |
| 多级反馈队列 | 抢占 | 不会 | 综合性能最好 |

## 五、多处理机调度

目标：

1. **负载均衡**：尽可能让各 CPU 同等忙碌；
2. **处理机亲和性**：尽可能让进程调度到**同一个 CPU** 执行，以利用 CPU 缓存。

两类方案：

| 方案 | 就绪队列 | 迁移策略 | 亲和性 |
| --- | --- | --- | --- |
| 方案一 | **公共**就绪队列 | 各调度程序**互斥访问**队列 | 较差 |
| 方案二 | **私有**就绪队列 | **推迁移（Push）+ 拉迁移（Pull）** 保证负载均衡 | 较好 |

## 六、易错点 / 注意事项

- **等待 I/O 的时间不计入等待时间**（周转时间包含，但等待时间不包含）。
- **带权周转时间恒 ≥ 1**，越接近 1 说明作业等待越少。
- 「进程在**内核程序临界区**」不可调度，但「进程在**普通临界区**」**可以**被调度。
- 用户态 → 内核态的切换由**中断**引发，因此**处理中断的过程中不能调度**。
- **SJF 才可能饥饿**；FCFS、HRRN、时间片轮转、多级反馈队列**均不会饥饿**。
- **多级反馈队列**的关键规则是「**只有上级队列为空才调度下级**」，且新进程总是**先进最高优先级队列**。

---

## 七、小结

- 三级调度：**高级（作业）→ 中级（内存）→ 低级（进程）**，频率依次升高。
- 进程调度时机分**主动放弃**与**被动放弃**；中断处理、内核程序临界区、原语执行时**不可调度**。
- 调度方式分**非剥夺（非抢占）** 与**剥夺（抢占）**。
- 评价指标：CPU 利用率、吞吐量、**周转时间 / 带权周转时间**、等待时间、响应时间。
- 六大算法中，**只有 SJF 和优先级调度会导致饥饿**；**多级反馈队列综合性能最好**。
- 多处理机调度关注**负载均衡**与**处理机亲和性**。
