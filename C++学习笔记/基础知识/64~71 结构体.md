# 64~71 结构体（struct）—— C 与 C++ 全面对比

> 结构体是 C/C++ 中最基础的**复合数据类型**。C++ 在 C 结构体的基础上做了重大升级，使其成为面向对象编程的基石。本文从 9 个维度逐一对比。

---

## 1. 成员访问：`.` 和 `->`

**C 和 C++ 完全一致。**

| 运算符 | 适用对象 | 示例 |
|--------|---------|------|
| `.` | 结构体**变量** | `s.id = 100` |
| `->` | 结构体**指针** | `p->id = 200` |

```cpp
// C / C++ 通用写法
struct Student {
    int id;
};

Student s;
s.id = 100;          // 变量用 .

Student *p = &s;
p->id = 200;         // 指针用 ->
```

> ✅ 这部分 C 和 C++ 没有任何区别。

---

## 2. 类型名使用：**最大语法差异**

### C 语言

结构体标签（tag）不是类型名，定义变量时**必须加 `struct` 关键字**。

想省略 `struct`，只能用 `typedef` 手动起别名：

```c
// C：定义结构体
struct Student {
    int id;
};

// 必须写 struct
struct Student s1;              // ✅ 正确

// 想简写？需要 typedef
typedef struct Student Student;
Student s2;                     // ✅ 现在可以了
```

### C++

结构体标签**自动成为类型名**，不需要 `typedef`。

```cpp
// C++：定义结构体
struct Student {
    int id;
};

Student s1;                     // ✅ 直接使用，无需 struct
struct Student s2;              // ✅ 也兼容 C 写法
```

> [!important] 核心区别
> **C：标签 ≠ 类型名，必须写 `struct`**
> **C++：标签自动成为类型名，`struct` 可省略**

---

## 3. C 结构体：纯数据容器

C 的结构体**只能包含成员变量**，不能定义成员函数。它仅仅是一块数据的集合。

```c
// ❌ C 语言中这种写法非法！
struct Student {
    int id;
    void show() {               // 编译报错：C 不允许成员函数
        printf("%d\n", id);
    }
};
```

如果想关联操作，只能在外面写**全局函数**，把结构体指针传进去：

```c
// ✅ C 的做法：外部函数 + 结构体指针
struct Student {
    int id;
    char name[32];
};

void student_show(const struct Student *s) {
    printf("id = %d, name = %s\n", s->id, s->name);
}
```

> 函数指针：C 结构体可以包含**函数指针**成员（通过指针间接调用函数），但这和真正的成员函数是两回事。

---

## 4. C++ 结构体：数据 + 操作的封装

C++ 结构体**可以直接包含成员函数（方法）**。这是最关键的升级——结构体从"数据块"进化为"封装体"。

```cpp
struct Student {
    int id;
    char name[32];

    // 成员函数：直接访问成员变量，不需要传指针
    void show() {
        printf("id = %d, name = %s\n", id, name);
    }
};

Student s{100, "Alice"};
s.show();                       // 调用成员函数
```

> 从此，结构体 = 数据 + 行为，这已经是**面向对象的雏形**。

---

## 5. 访问控制（public / private / protected）

### C 语言

没有访问控制的概念，**所有成员默认公开**，外界可以随意读写。

### C++

支持三种访问限定符：

| 限定符 | 含义 |
|--------|------|
| `public` | 任何地方都能访问 |
| `private` | 只有本类/本结构体内部可访问 |
| `protected` | 本类和派生类可访问 |

```cpp
struct Student {
    int id;                     // 默认 public
private:
    int score;                  // 私有成员，外部不能访问
protected:
    int grade;                  // 派生类可访问
};

Student s;
s.id = 10;                      // ✅ public，可以
// s.score = 90;                // ❌ private，编译错误
```

> [!warning] struct 与 class 的唯一区别
> **struct 默认访问权限是 `public`**
> **class 默认访问权限是 `private`**
>
> 除此之外，struct 和 class 在 C++ 中功能完全相同。

---

## 6. 构造函数 & 析构函数

### C 语言

没有构造/析构机制，只能**手动逐个赋值**初始化：

```c
struct Student s;
s.id = 100;
strcpy(s.name, "Alice");        // 手动初始化每个成员
```

### C++

结构体支持构造函数（创建时自动调用）和析构函数（销毁时自动调用）：

```cpp
struct Student {
    int id;
    char name[32];

    // 构造函数：同名，无返回值
    Student(int x, const char *n) {
        id = x;
        strcpy(name, n);
    }

    // 析构函数：~类型名，无参数，无返回值
    ~Student() {
        printf("%s 被销毁\n", name);
    }
};

Student s(100, "Alice");        // 构造时自动初始化
// s 离开作用域时，析构函数自动调用
```

---

## 7. 初始化方式

### C 语言

仅支持**聚合初始化**，按成员声明顺序赋值：

```c
struct Student {
    int id;
    char name[32];
};

struct Student s1 = {100, "Alice"};     // 顺序匹配
struct Student s2 = {.id = 200, .name = "Bob"};  // C99 指定初始化
```

### C++

保留 C 风格，同时支持多种初始化形式：

```cpp
Student s1 = {100, "Alice"};    // ① 兼容 C 的聚合初始化
Student s2(200, "Bob");         // ② 构造函数初始化
Student s3{300, "Charlie"};     // ③ C++11 列表初始化（推荐）
Student s4 = {300, "Charlie"};  // ④ 拷贝列表初始化
```

> [!tip] 推荐使用 `{}` 列表初始化
> C++11 的列表初始化 `Student s{...}` 更安全：不允许窄化转换（narrowing conversion），编译器会报错。

## 8. 赋值 & 内存对齐

**C 和 C++ 行为完全一致。**

```cpp
Student a, b;
a = b;                          // 同类型结构体直接整体拷贝（浅拷贝）
```

- 结构体之间的 `=` 赋值执行**逐字节拷贝**（memcpy 语义）
- 如果成员有指针，只拷贝指针值，不拷贝指向的内容（**浅拷贝**）

### 内存对齐

C 和 C++ 都遵循相同的对齐规则：成员按自身大小对齐，结构体整体按最大成员对齐。

```cpp
struct Example {
    char  c;    // 1 字节，偏移 0
    int   i;    // 4 字节，偏移 4（补齐了 3 字节空洞）
    short s;    // 2 字节，偏移 8
};              // 整体大小：12 字节（末尾补齐 2 字节）
```

## 9. 继承（C++ 独有）

### C 语言

**不支持结构体继承。**

### C++

struct 可以继承另一个 struct 或 class：

```cpp
struct Person {
    int age;
    void walk() { printf("走路\n"); }
};

struct Student : public Person {    // 继承 Person
    int id;
    void study() { printf("学习\n"); }
};

Student s;
s.age = 18;                         // 继承来的成员
s.id = 1001;
s.walk();                           // 继承来的方法
s.study();                          // 自己的方法
```

> [!note] struct 继承默认是 `public` 继承，class 继承默认是 `private` 继承——这仍然源于它们默认访问权限的不同。

# 极简总结清单

| 特性 | C struct | C++ struct |
|------|----------|------------|
| 类型名书写 | 必须写 `struct`，需 `typedef` 简写 | 可直接使用标签名 |
| 成员函数 | ❌ 不支持 | ✅ 支持 |
| 构造 / 析构 | ❌ 不支持 | ✅ 支持 |
| 访问控制 | 无，全部公开 | `public` / `private` / `protected`，默认 `public` |
| 继承 | ❌ 不支持 | ✅ 支持 |
| `.` 和 `->` 访问 | ✅ | ✅ |
| 内存对齐 | ✅ | ✅ |
| 直接赋值 `=` | ✅ | ✅ |
| 兼容性 | 原生 | 向下兼容 C 结构体语法 |

## 💡 一句话记忆

> **C struct 是数据的容器，C++ struct 是数据和行为的封装体。**
> **C++ 中 struct 和 class 唯一区别：默认访问权限不同（struct = public，class = private）。**
