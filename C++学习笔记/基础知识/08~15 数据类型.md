# 📐 08~15 数据类型

> C++ 规定：创建一个变量时，必须指定其数据类型，以便编译器分配合适的内存空间。

---

## 08 数据类型概述

### 🎯 数据类型存在的意义

> **给变量分配合适的内存空间，避免空间浪费。**

| 场景 | 用错类型的后果 |
|------|--------------|
| 存年龄（0~150） | 用 `long long` 太浪费，`short` 足够 |
| 存圆周率（高精度） | 用 `float` 精度不够，应该用 `double` |
| 存性别（男/女） | 用 `int` 浪费，`bool` 或 `char` 更合适 |

## 09 整型

> 整型用于存储**整数**，C++ 提供四种整型，区别在于占用内存大小不同。

### 📊 四种整型对比

| 数据类型 | 关键字 | 占用字节 | 取值范围 |
|---------|--------|:------:|---------|
| 短整型 | `short` | 2 | -32,768 ~ 32,767 |
| 整型 | `int` | 4 | -2.1×10⁹ ~ 2.1×10⁹ |
| 长整型 | `long` | 4（Win）/ 8（Linux） | 视平台而定 |
| 长长整型 | `long long` | 8 | -9.2×10¹⁸ ~ 9.2×10¹⁸ |

### ✍️ 代码示例

```cpp
#include <iostream>

using namespace std;

int main()
{
    short  num1 = 10;       // 短整型：2 字节
    int    num2 = 10;       // 整型：4 字节（最常用）
    long   num3 = 10;       // 长整型
    long long num4 = 10;    // 长长整型：8 字节（超大整数）

    cout << "short: " << num1 << endl;
    cout << "int: " << num2 << endl;
    cout << "long: " << num3 << endl;
    cout << "long long: " << num4 << endl;

    return 0;
}
```

## 10 sizeof 关键字

> `sizeof` 可以**统计数据类型占用的内存大小**（单位：字节）。

### 📐 语法

```cpp
sizeof(数据类型)
sizeof(变量名)
```

### ✍️ 代码示例

```cpp
#include <iostream>

using namespace std;

int main()
{
    short num1 = 10;

    cout << "short 占用: " << sizeof(short) << " 字节" << endl;   // 2
    cout << "int 占用: " << sizeof(int) << " 字节" << endl;       // 4
    cout << "long 占用: " << sizeof(long) << " 字节" << endl;     // 4 或 8
    cout << "long long 占用: " << sizeof(long long) << " 字节" << endl; // 8

    cout << "变量 num1 占用: " << sizeof(num1) << " 字节" << endl;

    return 0;
}
```

### 🔑 巧记

```
short  <  int  ≤  long  ≤  long long
  2        4      4/8          8
```

## 11 实型（浮点型）

> 实型用于存储**小数**。分为单精度 `float` 和双精度 `double`。

![[Pasted image 20260728105731.png]]

### 📊 float vs double

| 数据类型 | 关键字 | 占用字节 | 有效数字位数 | 精度 |
|---------|--------|:------:|:----------:|------|
| 单精度 | `float` | 4 | **7 位** | 一般 |
| 双精度 | `double` | 8 | **15 ~ 16 位** | 更高 |

### ✍️ 代码示例

```cpp
#include <iostream>

using namespace std;

int main()
{
    // 默认情况下，小数会被当作 double 类型
    float  f1 = 3.1415926f;   // 加 f 后缀表示 float
    double d1 = 3.1415926;

    cout << "float: " << f1 << endl;     // 输出: 3.14159（精度有限）
    cout << "double: " << d1 << endl;    // 输出: 3.14159（更精确）

    // 查看占用字节
    cout << "float 字节: " << sizeof(float) << endl;   // 4
    cout << "double 字节: " << sizeof(double) << endl;  // 8

    return 0;
}
```

### 🧪 科学计数法

```cpp
float f2 = 3e2;   // 3 × 10² = 300
float f3 = 3e-2;  // 3 × 10⁻² = 0.03
```

| 写法 | 含义 | 结果 |
|------|------|:--:|
| `3e2` | 3 × 10² | 300 |
| `3e-2` | 3 × 10⁻² | 0.03 |
| `1.5e3` | 1.5 × 10³ | 1500 |

## 12 字符型 char

> `char` 用于存储**单个字符**。字符在底层存的是 ASCII 码（整数）。

### 📐 语法

```cpp
char 变量名 = '字符';   // 注意：用单引号！
```

| 属性 | 值 |
|------|-----|
| 占用空间 | **1 字节** |
| 范围 | 0 ~ 255（ASCII 码） |
| 引号 | **单引号** `'A'` |

### ✍️ 代码示例

```cpp
#include <iostream>

using namespace std;

int main()
{
    char ch = 'a';   // 存入的是 'a' 对应的 ASCII 码 97

    cout << "字符: " << ch << endl;        // 输出: a
    cout << "ASCII 码: " << (int)ch << endl; // 输出: 97（强转成整数）

    // 打印 A-Z 的 ASCII 码
    cout << "A 的 ASCII: " << (int)'A' << endl;  // 65
    cout << "Z 的 ASCII: " << (int)'Z' << endl;  // 90

    return 0;
}
```

### 🔤 常用 ASCII 码速查

| 字符 | ASCII 码 |
|:----:|:--------:|
| `'0'` | 48 |
| `'A'` | 65 |
| `'a'` | 97 |
| 空格 | 32 |
| 回车 | 13 |

### 🔤 转义字符

| 转义字符 | 含义 | 作用 |
|:--------:|------|------|
| `\n` | 换行符 | 光标移到下一行开头 |
| `\t` | 水平制表符 | 跳到下一个 Tab 位置（8 个空格宽度，用于对齐） |
| `\\` | 反斜杠 | 输出一个 `\` |
| `\'` | 单引号 | 输出一个 `'` |
| `\"` | 双引号 | 输出一个 `"` |

```cpp
cout << "Hello\nWorld" << endl;     // Hello 和 World 分两行
cout << "Name:\tTom" << endl;       // 中间有 Tab 间距
cout << "路径: C:\\data\\file" << endl;  // 输出: C:\data\file
```

## 14 字符串型

> 存储**一串字符**。C++ 有两种风格的字符串。

### 📊 两种风格对比

| 风格 | 语法 | 头文件 | 本质 |
|------|------|--------|------|
| **C 风格** | `char 变量名[] = "字符串"` | 无 | 字符数组 |
| **C++ 风格** | `string 变量名 = "字符串"` | `#include <string>` | string 类对象 |

### ✍️ 代码示例

```cpp
#include <iostream>
#include <string>    // C++风格需要这个头文件！

using namespace std;

int main()
{
    // C 风格字符串 —— 本质是字符数组
    char str1[] = "Hello World";
    cout << "C 风格: " << str1 << endl;

    // C++ 风格字符串 —— 更推荐，功能更强大
    string str2 = "Hello World";
    cout << "C++风格: " << str2 << endl;

    // C++ string 支持的操作
    string name = "张三";
    string msg = "你好，" + name;    // 字符串拼接
    cout << msg << endl;              // 输出: 你好，张三

    return 0;
}
```

### 💡 推荐

> **优先使用 C++ 风格 `string`**，操作更方便，功能更强大。

## 15 布尔类型 bool

> `bool` 只有两个值：**真** 或 **假**，用于逻辑判断。

### 📐 语法

```cpp
bool 变量名 = true;   // 或 false
```

| 属性 | 值 |
|------|-----|
| 占用空间 | **1 字节** |
| 取值 | `true`（1）或 `false`（0） |

### ✍️ 代码示例

```cpp
#include <iostream>

using namespace std;

int main()
{
    bool flag1 = true;   // 真，本质是 1
    bool flag2 = false;  // 假，本质是 0

    cout << "true = " << flag1 << endl;    // 输出: 1
    cout << "false = " << flag2 << endl;   // 输出: 0

    // 非零值都视为 true
    bool flag3 = 100;   // 非零 → true
    bool flag4 = -5;    // 非零 → true
    bool flag5 = 0;     // 零 → false

    cout << "100 → " << flag3 << endl;  // 输出: 1
    cout << "-5 → " << flag4 << endl;   // 输出: 1
    cout << "0 → " << flag5 << endl;    // 输出: 0

    // 比较运算产生 bool 值
    bool result = (10 > 5);
    cout << "10 > 5 ? " << result << endl;  // 输出: 1 (true)

    return 0;
}
```

> **记忆口诀**：非 0 即真，0 即假

## ⌨️ 数据的输入 cin

> `cin` 用于从键盘接收用户输入，与 `cout`（输出）相对。

### 📐 语法

```cpp
cin >> 变量名;
```

### ✍️ 代码示例

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    // 整数输入
    int age = 0;
    cout << "请输入你的年龄：";
    cin >> age;
    cout << "你的年龄是：" << age << " 岁" << endl;

    // 浮点数输入
    double score = 0;
    cout << "请输入你的分数：";
    cin >> score;
    cout << "你的分数是：" << score << endl;

    // 字符串输入
    string name;
    cout << "请输入你的姓名：";
    cin >> name;
    cout << "你好，" << name << "！" << endl;

    return 0;
}
```

### ⚠️ 注意事项

| 问题 | 说明 |
|------|------|
| `cin >>` 遇空格停止 | 输入 "Zhang San" 只会读到 "Zhang" |
| 类型要匹配 | 给 `int` 变量输入字母会导致错误 |
| 使用前要初始化 | `int a = 0;` 好习惯，避免脏数据 |
