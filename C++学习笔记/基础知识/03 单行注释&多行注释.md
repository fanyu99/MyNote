# 📝 单行注释 & 多行注释

> 注释是写给程序员看的文字，编译器会完全忽略它们。写好注释是编程的好习惯！

---

## 1️⃣ 单行注释

**语法：** `// 注释内容`

从 `//` 开始到该行末尾的内容都会被当作注释。

```cpp
#include <iostream>

using namespace std;

int main()
{
    // 向屏幕输出一句话
    cout << "hello world" << endl;  // 这行后面也可以写注释

    return 0;  // 程序正常结束
}
```

> **快捷键（VS Code）：** `Ctrl + /` 快速切换单行注释

---

## 2️⃣ 多行注释

**语法：** `/* 注释内容 */`

在 `/*` 和 `*/` 之间的所有内容都会被编译器忽略，可以跨越多行。

```cpp
#include <iostream>

using namespace std;

/*
 * 这是一个多行注释
 * 可以写很多行
 * 编译器会完全忽略这段内容
 */

int main()
{
    /*
    cout << "这行代码不会执行" << endl;
    cout << "因为被注释掉了" << endl;
    */
    
    cout << "这行才会执行哦" << endl;

    return 0;
}
```

> **快捷键（VS Code）：** `Alt + Shift + A` 快速切换多行注释

---

## 📊 对比总结

| 注释类型 | 语法 | 适用场景 |
|---------|------|---------|
| 单行注释 | `//` | 简短说明、行尾注释、快速调试 |
| 多行注释 | `/* */` | 函数/类说明、大段注释、临时屏蔽代码 |

---

## 💡 注释的最佳实践

1. **解释"为什么"而不是"是什么"** —— 代码本身说清楚做了什么，注释要解释为什么这样做
2. **保持注释与代码同步** —— 修改代码时别忘了修改对应的注释
3. **不要过度注释** —— 显而易见的代码不需要注释
   ```cpp
   // ❌ 废话注释
   int age = 18;  // 定义变量 age 并赋值为 18

   // ✅ 有意义的注释
   int age = 18;  // 法定成年年龄，用于判断是否能注册账号
   ```
