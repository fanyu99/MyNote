# 🔒 常量

> 常量是程序中**不可修改**的数据。一旦定义，其值在整个程序运行期间都不会改变。

---

## 定义常量的两种方式

### 1️⃣ `#define` 宏常量

```
#define 常量名 常量值
```

- 写在文件顶部（`#include` 之后）
- ⚠️ 语句末尾**不加分号**
- 属于**预处理指令**，编译前做文本替换

```cpp
#include <iostream>

#define DAY 7          // 一周有 7 天，没有分号！
#define PI 3.14159     // 圆周率

using namespace std;

int main()
{
    cout << "一周有 " << DAY << " 天" << endl;
    cout << "PI = " << PI << endl;

    return 0;
}
```

---

### 2️⃣ `const` 修饰常量

```
const 数据类型 常量名 = 常量值;
```

- 写在函数体内或全局位置
- ✅ 语句末尾**必须加分号**
- 有数据类型检查，**更安全**

```cpp
#include <iostream>

using namespace std;

int main()
{
    const int DAY = 7;          // 一周有 7 天
    const double PI = 3.14159;  // 圆周率

    cout << "一周有 " << DAY << " 天" << endl;
    cout << "PI = " << PI << endl;

    // DAY = 8;  ← ❌ 错误！常量不可修改

    return 0;
}
```

---

## 📊 `#define` vs `const`

| 对比维度 | `#define` | `const` |
|---------|-----------|---------|
| 语法 | `#define 名 值` | `const 类型 名 = 值;` |
| 分号 | ❌ 不加分号 | ✅ 要加分号 |
| 类型检查 | 无，纯文本替换 | 有，编译器检查类型 |
| 作用域 | 全局生效 | 受作用域限制 |
| 调试 | 调试器看不到宏名 | 调试器可以看到 |
| 推荐度 | ⭐⭐ | ⭐⭐⭐ **推荐** |

## 💡 为什么用常量？

```cpp
// ❌ 魔法数字：不知道 7 是什么意思
for (int i = 0; i < 7; i++) { ... }

// ✅ 使用常量：一目了然
const int DAYS_IN_WEEK = 7;
for (int i = 0; i < DAYS_IN_WEEK; i++) { ... }
```

| 好处 | 说明 |
|------|------|
| **可读性** | 看到 `MAX_SIZE` 比看到 `100` 更清晰 |
| **易维护** | 改一处，所有引用的地方都生效 |
| **防误改** | 编译器阻止对常量的意外修改 |

---

## ⚠️ 注意事项

1. `#define` 定义的常量名通常用**全大写**（如 `MAX_SIZE`）
2. 变量一旦被 `const` 修饰，就不能再修改其值
3. C++ 中更推荐使用 `const` 而非 `#define`
