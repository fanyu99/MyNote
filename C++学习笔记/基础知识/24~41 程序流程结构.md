# 程序流程结构

C/C++ 支持最基本的三种程序运行结构：**顺序结构**、**选择结构**、**循环结构**。

- **顺序结构**：程序按代码编写的先后顺序，一行一行执行，不发生跳转。
- **选择结构**：依据条件是否满足，有选择地执行相应代码。
- **循环结构**：依据条件是否满足，循环多次执行某段代码。

## 一、选择结构

### 1. if 条件判断语句

#### 1.1 单行格式 if

```cpp
if (条件)
{
    条件为 true 时执行的语句;
}
```

**示例：**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int score = 85;

    if (score >= 60)
    {
        cout << "成绩及格！" << endl;
    }

    return 0;
}
```

> **注意**：如果 `if` 后只有一条语句，可以省略花括号 `{}`，但不建议这样做，容易引发歧义。

```cpp
if (条件)
{
    条件为 true 时执行的语句;

    条件为 false 时执行的语句;

    }
```

```cpp
}
```

#### 1.3 多条件格式 if-else if-else

```cpp
if (条件1)
{
    条件1为 true 时执行;
}
else if (条件2)
{
    条件1为 false 且条件2为 true 时执行;
}
else
{
    以上条件都不满足时执行;
}
```

**示例：**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int score = 85;

    if (score >= 90)
    {
        cout << "优秀" << endl;
    }
    else if (score >= 80)
    {
        cout << "良好" << endl;
    }
    else if (score >= 70)
    {
        cout << "中等" << endl;
    }
    else if (score >= 60)
    {
        cout << "及格" << endl;
    }
    else
    {
        cout << "不及格" << endl;
    }

    return 0;
}
```

#### 1.4 if 嵌套

在一个 `if` 语句的代码块中再嵌套另一个 `if` 语句，实现更精细的条件判断。

```cpp
if (外层条件)
{
    if (内层条件1)
    {
        // ...
    }
    else
    {
        // ...
    }
}
else
{
    // ...
}
```

**示例：判断闰年**

> 闰年规则：能被 4 整除但不能被 100 整除，**或者** 能被 400 整除。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int year = 2024;

    if (year % 4 == 0)
    {
        if (year % 100 == 0)
        {
            if (year % 400 == 0)
            {
                cout << year << " 是闰年" << endl;  // 能被400整除
            }
            else
            {
                cout << year << " 不是闰年" << endl; // 能被100整除但不能被400整除
            }
        }
        else
        {
            cout << year << " 是闰年" << endl;       // 能被4整除但不能被100整除
        }
    }
    else
    {
        cout << year << " 不是闰年" << endl;         // 不能被4整除
    }

    return 0;
}
```

**示例：三个数找最大值（嵌套写法）**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10, b = 20, c = 15;

    if (a > b)
    {
        if (a > c)
        {
            cout << "最大值是 a = " << a << endl;
        }
        else
        {
            cout << "最大值是 c = " << c << endl;
        }
    }
    else
    {
        if (b > c)
        {
            cout << "最大值是 b = " << b << endl;
        }
        else
        {
            cout << "最大值是 c = " << c << endl;
        }
    }

    return 0;
}
```

### 2. 三目运算符

**作用**：通过三目运算符实现简单的条件判断，是 `if-else` 的简写形式。

**语法**：

```cpp
变量 = 条件 ? 表达式1 : 表达式2;
```

- 条件为 `true` → 返回 `表达式1` 的结果
- 条件为 `false` → 返回 `表达式2` 的结果

**示例：**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 20;
    int c = 0;

    // 取较大值
    c = a > b ? a : b;
    cout << "a 和 b 中较大的是：" << c << endl;  // 输出 20

    // 三目运算符也可以嵌套
    int d = 15;
    int max = (a > b ? a : b) > d ? (a > b ? a : b) : d;
    cout << "三个数中最大的是：" << max << endl;

    // 三目运算符返回的是变量，可以对其赋值（C++中）
    (a > b ? a : b) = 100;
    cout << "a = " << a << ", b = " << b << endl;  // b 被赋值为 100

    return 0;
}
```

> **注意**：三目运算符适合简单的条件判断，复杂逻辑优先使用 `if-else`，可读性更好。

### 3. switch 语句

**作用**：对多个分支进行等值判断，比多重 `if-else if` 更清晰。

**语法：**

```cpp
switch (表达式)  // 表达式必须是整型或枚举类型
{
    case 值1:
        执行语句;
        break;
    case 值2:
        执行语句;
        break;
    ...
    default:
        以上都不匹配时执行;
        break;
}
```

> **关键点**：
> - `switch` 的表达式类型只能是 **整型**（`int`、`char`、`short`、`long` 等）或 **枚举类型**，**不能是浮点型或字符串**。
> - 每个 `case` 后通常要加 `break`，否则会继续执行后续 `case`（称为"**穿透**"）。
> - `default` 是可选的，放在最后。

**示例：根据数字输出星期**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int day = 3;

    switch (day)
    {
        case 1:
            cout << "星期一" << endl;
            break;
        case 2:
            cout << "星期二" << endl;
            break;
        case 3:
            cout << "星期三" << endl;
            break;
        case 4:
            cout << "星期四" << endl;
            break;
        case 5:
            cout << "星期五" << endl;
            break;
        case 6:
            cout << "星期六" << endl;
            break;
        case 7:
            cout << "星期日" << endl;
            break;
        default:
            cout << "输入错误" << endl;
            break;
    }

    return 0;
}
```

**示例：利用穿透特性（不加 break）**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int month = 3;
    int days = 0;

    switch (month)
    {
        case 1:
        case 3:
        case 5:
        case 7:
        case 8:
        case 10:
        case 12:
            days = 31;
            break;
        case 4:
        case 6:
        case 9:
        case 11:
            days = 30;
            break;
        case 2:
            days = 28;  // 暂不考虑闰年
            break;
        default:
            cout << "月份无效" << endl;
            break;
    }

    cout << month << " 月有 " << days << " 天" << endl;
    return 0;
}
```

## 二、循环结构

### 1. while 循环

**语法：**

```cpp
while (循环条件)
{
    循环体;
    // 在循环体中需要修改条件变量，避免死循环
}
```

> 先判断条件，条件为 `true` 才执行循环体。

**示例：打印 1 到 10**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int i = 1;

    while (i <= 10)
    {
        cout << i << " ";
        i++;  // 更新循环变量，避免死循环
    }
    cout << endl;

    return 0;
}
```

**示例：猜数字游戏**

```cpp
#include <iostream>
#include <cstdlib>   // rand(), srand()
#include <ctime>     // time()
using namespace std;

int main()
{
    // 设置随机种子
    srand((unsigned int)time(NULL));

    // 生成 1~100 的随机数
    int target = rand() % 100 + 1;
    int guess = 0;

    cout << "猜一个 1~100 之间的数字：" << endl;

    while (guess != target)
    {
        cin >> guess;

        if (guess > target)
        {
            cout << "猜大了，再试试：" << endl;
        }
        else if (guess < target)
        {
            cout << "猜小了，再试试：" << endl;
        }
        else
        {
            cout << "恭喜，猜对了！" << endl;
        }
    }

    return 0;
}
```

### 2. do-while 循环

**语法：**

```cpp
do
{
    循环体;
} while (循环条件);
```

> **注意**：与 `while` 的区别在于，`do-while` 会**先执行一次循环体**，再判断条件。因此无论条件是否满足，循环体至少执行一次。

**示例：验证至少执行一次**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int i = 100;

    // 条件一开始就不满足，但循环体仍然执行一次
    do
    {
        cout << "当前 i = " << i << endl;
        i++;
    } while (i < 10);

    cout << "循环结束，i = " << i << endl;
    // 输出：当前 i = 100，然后循环结束

    return 0;
}
```

**示例：用户输入验证（至少询问一次）**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int password = 0;

    do
    {
        cout << "请输入密码（四位数字）：";
        cin >> password;
    } while (password != 1234);

    cout << "密码正确，欢迎！" << endl;

    return 0;
}
```

### 3. for 循环

**语法：**

```cpp
for (起始表达式; 条件表达式; 更新表达式)
{
    循环体;
}
```

- **起始表达式**：循环开始前执行一次，通常用于初始化循环变量。
- **条件表达式**：每次循环开始前判断，为 `true` 则执行循环体，为 `false` 则退出。
- **更新表达式**：每次循环体执行完毕后执行，通常用于更新循环变量。

> `for` 循环结构清晰，适合**已知循环次数**的场景。

**示例：打印 1 到 10**

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 10; i++)
    {
        cout << i << " ";
    }
    cout << endl;

    return 0;
}
```

**示例：九九乘法表**

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 9; i++)
    {
        for (int j = 1; j <= i; j++)
        {
            cout << j << "×" << i << "=" << i * j << "\t";
        }
        cout << endl;
    }

    return 0;
}

// 输出：
// 1×1=1
// 1×2=2    2×2=4
// 1×3=3    2×3=6    3×3=9
// ...
// 1×9=9    2×9=18   3×9=27   4×9=36   5×9=45   6×9=54   7×9=63   8×9=72   9×9=81
```

**示例：for 循环的灵活写法**

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 写法一：循环变量定义在循环外
    int i = 0;
    for (; i < 5; i++)
    {
        cout << i << " ";
    }
    cout << endl;

    // 写法二：多个循环变量
    for (int a = 0, b = 10; a < b; a++, b--)
    {
        cout << "a = " << a << ", b = " << b << endl;
    }

    // 写法三：省略所有表达式 → 死循环（等价于 while(true)）
    // for (;;)
    // {
    //     cout << "无限循环" << endl;
    // }

    return 0;
}
```

**示例：遍历数组**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int arr[] = {10, 20, 30, 40, 50};
    int size = sizeof(arr) / sizeof(arr[0]);

    for (int i = 0; i < size; i++)
    {
        cout << "arr[" << i << "] = " << arr[i] << endl;
    }

    // C++11 范围 for 循环（range-based for）
    cout << "--- 范围 for ---" << endl;
    for (int num : arr)
    {
        cout << num << " ";
    }
    cout << endl;

    return 0;
}
```

### 4. 三种循环的对比

| 循环类型 | 特点 | 适用场景 |
|---------|------|---------|
| `while` | 先判断，后执行；可能一次都不执行 | 循环次数未知，依赖条件 |
| `do-while` | 先执行，后判断；至少执行一次 | 至少需要执行一次的操作（如菜单、输入验证） |
| `for` | 初始化、条件、更新集中在一起，结构清晰 | 已知循环次数或遍历容器 |

## 三、跳转语句

### 1. break 语句

**作用**：
- 在 `switch` 中：跳出当前 `case` 分支。
- 在循环中：**立即终止**当前所在的最内层循环，跳到循环之后继续执行。

**示例：break 在循环中使用**

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 找出 1~100 中第一个能被 7 整除的数
    for (int i = 1; i <= 100; i++)
    {
        if (i % 7 == 0)
        {
            cout << "第一个能被 7 整除的数是：" << i << endl;
            break;  // 找到后立即退出循环
        }
    }

    return 0;
}
```

**示例：嵌套循环中的 break（只跳出内层）**

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 3; i++)
    {
        for (int j = 1; j <= 5; j++)
        {
            if (j == 3)
            {
                break;  // 只跳出内层 j 循环
            }
            cout << "i=" << i << ", j=" << j << endl;
        }
        cout << "--- 内层循环结束 ---" << endl;
    }

    return 0;
}
```

### 2. continue 语句

**作用**：**跳过**当前循环中 `continue` 之后的所有语句，直接进入**下一次循环**的条件判断。

> `break` vs `continue`：
> - `break`：直接**退出整个循环**。
> - `continue`：只**跳过本次循环**的剩余部分，继续下一次循环。

**示例：只输出偶数**

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 10; i++)
    {
        if (i % 2 != 0)  // 奇数
        {
            continue;  // 跳过奇数，不输出
        }
        cout << i << " ";
    }
    cout << endl;

    // 输出：2 4 6 8 10

    return 0;
}
```

**示例：过滤无效输入**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int sum = 0;
    int num = 0;

    cout << "请输入 5 个正整数求和（负数将被跳过）：" << endl;

    for (int i = 0; i < 5; i++)
    {
        cin >> num;

        if (num < 0)
        {
            cout << "负数，已跳过！" << endl;
            continue;  // 跳过负数，不计入总和
        }

        sum += num;
    }

    cout << "有效数字之和为：" << sum << endl;

    return 0;
}
```

### 3. goto 语句

**作用**：无条件跳转到函数内指定的**标签**位置执行。

> **警告**：`goto` 会破坏程序的结构化流程，降低代码可读性和可维护性。**一般不推荐使用**，但在某些场景下（如跳出多层嵌套循环）可以简化代码。

**语法：**

```cpp
goto 标签名;
// ...
标签名:
    语句;
```

**示例：跳出多层嵌套循环**

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 5; i++)
    {
        for (int j = 1; j <= 5; j++)
        {
            for (int k = 1; k <= 5; k++)
            {
                if (i * j * k == 60)
                {
                    cout << "找到组合：i=" << i
                         << ", j=" << j
                         << ", k=" << k
                         << " → i×j×k = 60" << endl;
                    goto DONE;  // 一次性跳出三层循环
                }
            }
        }
    }

DONE:
    cout << "搜索结束" << endl;
    return 0;
}
```

**示例：错误处理（C 风格用法）**

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main()
{
    int* p1 = nullptr;
    int* p2 = nullptr;

    p1 = new (nothrow) int[1000];
    if (p1 == nullptr)
    {
        cout << "内存分配失败：p1" << endl;
        goto CLEANUP;
    }

    p2 = new (nothrow) int[1000];
    if (p2 == nullptr)
    {
        cout << "内存分配失败：p2" << endl;
        goto CLEANUP;
    }

    // 正常业务逻辑...
    cout << "两个数组都分配成功！" << endl;

CLEANUP:
    // 统一释放资源
    if (p1 != nullptr) delete[] p1;
    if (p2 != nullptr) delete[] p2;
    cout << "资源已清理" << endl;

    return 0;
}
```

> **建议**：现代 C++ 中推荐使用 RAII（资源获取即初始化）和智能指针来管理资源，避免手动编写 `goto` 清理逻辑。

## 小结

| 分类 | 关键字 | 用途 |
|------|-------|------|
| 选择结构 | `if` / `else if` / `else` | 条件判断，分支执行 |
| 选择结构 | `? :`（三目运算符） | 简单的条件赋值 |
| 选择结构 | `switch` / `case` / `default` | 多分支等值判断 |
| 循环结构 | `while` | 先判断后执行 |
| 循环结构 | `do-while` | 先执行后判断（至少一次） |
| 循环结构 | `for` | 已知次数的循环 |
| 跳转语句 | `break` | 退出当前循环或 switch |
| 跳转语句 | `continue` | 跳过本次循环剩余部分 |
| 跳转语句 | `goto` | 无条件跳转（慎用） |
