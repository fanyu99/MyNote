# 函数

**函数**是一段可重复使用的代码块，将一段经常使用的代码封装起来，减少重复代码。一个较大的程序，一般分为若干个功能模块，每个模块实现特定的功能。

> **函数的作用**：
> - **代码复用**：避免重复编写相同的逻辑。
> - **模块化**：将复杂问题拆解为若干小功能，逐一实现。
> - **易于维护**：修改某个功能只需修改对应的函数。

---

## 一、函数的定义

函数的定义包含五个部分：

1. **返回值类型**：函数返回值的类型，若没有返回值则写 `void`。
2. **函数名**：标识符，命名规则与变量相同，建议"见名知意"。
3. **参数列表**：调用时传入的数据（形参），可以为空。
4. **函数体**：花括号 `{}` 中包含的具体执行语句。
5. **return 语句**：返回计算结果，类型必须与声明的返回值类型一致（`void` 函数可省略）。

**语法：**

```cpp
返回值类型 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...)
{
    函数体;
    return 返回值;  // 如果返回值类型是 void，可以省略
}
```

**示例：定义一个加法函数**

```cpp
#include <iostream>
using namespace std;

// 定义函数：接收两个 int 参数，返回它们的和
int add(int a, int b)
{
    int result = a + b;
    return result;
}

int main()
{
    int sum = add(10, 20);
    cout << "10 + 20 = " << sum << endl;  // 输出：30

    return 0;
}
```

> **注意**：`return` 语句一旦执行，函数立即结束，`return` 之后的代码不会被执行。

## 二、函数的调用

函数定义后不会自动执行，需要被**调用**才会运行。调用函数时，实参会按顺序传递给形参。

**语法：**

```cpp
函数名(实参1, 实参2, ...);
```

**示例：多次调用同一函数**

```cpp
#include <iostream>
using namespace std;

// 定义函数：比较两个数的大小，返回较大值
int max(int a, int b)
{
    return a > b ? a : b;
}

int main()
{
    int x = 10, y = 20, z = 15;

    // 多次调用，传入不同的实参
    int m1 = max(x, y);       // 比较 10 和 20
    int m2 = max(y, z);       // 比较 20 和 15
    int m3 = max(m1, m2);     // 用返回值作为实参

    cout << x << " 和 " << y << " 中较大的是 " << m1 << endl;  // 20
    cout << y << " 和 " << z << " 中较大的是 " << m2 << endl;  // 20
    cout << "三者中最大的是 " << m3 << endl;                   // 20

    return 0;
}
```

**示例：函数调用流程图**

```cpp
#include <iostream>
using namespace std;

void sayHello()
{
    cout << "Hello!" << endl;
    cout << "这是 sayHello 函数内部" << endl;
}

int main()
{
    cout << "--- 调用前 ---" << endl;
    sayHello();  // 程序跳转到 sayHello 函数体中执行
    cout << "--- 调用后 ---" << endl;
    return 0;
}

// 输出：
// --- 调用前 ---
// Hello!
// 这是 sayHello 函数内部
// --- 调用后 ---
```

> **调用流程**：`main()` → 调用 `sayHello()` → 进入 `sayHello` 函数体 → 执行完毕后返回到 `main()` 中调用位置的下一行继续执行。

## 三、值传递

**值传递**是指函数调用时将实参的**值**拷贝一份给形参，形参在函数内部发生变化，**不会影响实参**。

```cpp
#include <iostream>
using namespace std;

// 值传递：形参 num 接受的是实参的副本
void changeValue(int num)
{
    num = 999;  // 修改形参的值
    cout << "函数内部 num = " << num << endl;
}

int main()
{
    int a = 10;
    cout << "调用前 a = " << a << endl;  // 10

    changeValue(a);
    cout << "调用后 a = " << a << endl;  // 10，没有改变！

    return 0;
}

// 输出：
// 调用前 a = 10
// 函数内部 num = 999
// 调用后 a = 10
```

> **本质**：形参是实参的**独立副本**，存储在**不同的内存空间**中。修改形参不会影响实参，因为它们是两个不同的变量。

**图解内存关系：**

| 时刻 | 实参 `a`（`main` 中） | 形参 `num`（`changeValue` 中） |
|------|----------------------|-------------------------------|
| 调用前 | `a = 10` | —（不存在） |
| 调用时（传参） | `a = 10` | `num = 10`（拷贝） |
| 函数内部修改 | `a = 10` | `num = 999`（改了副本） |
| 函数返回后 | `a = 10` | —（形参被销毁） |

## 四、函数的常见样式

根据**参数**和**返回值**的有无，函数有以下四种常见样式：

| 类型 | 有无参数 | 有无返回值 | 适用场景 |
|------|---------|-----------|---------|
| 无参无返 | 无 | 无（`void`） | 执行固定操作，如打印菜单、显示提示信息 |
| 有参无返 | 有 | 无（`void`） | 根据参数做操作但不返回结果，如打印计算结果 |
| 无参有返 | 无 | 有 | 获取某个值，如获取系统时间、读取传感器数据 |
| 有参有返 | 有 | 有 | 计算并返回结果，这是最常见的形式 |

### 1. 无参无返

```cpp
#include <iostream>
using namespace std;

// 无参数，无返回值：显示游戏菜单（做固定的事情）
void showMenu()
{
    cout << "====================" << endl;
    cout << "   1. 开始游戏" << endl;
    cout << "   2. 继续游戏" << endl;
    cout << "   3. 退出游戏" << endl;
    cout << "====================" << endl;
}

int main()
{
    showMenu();  // 直接调用，不需要传参，也不需要接收返回值
    return 0;
}
```

### 2. 有参无返

```cpp
#include <iostream>
using namespace std;

// 有参数（分数），无返回值：根据分数打印评价
void printGrade(int score)
{
    if (score >= 90)
        cout << "优秀" << endl;
    else if (score >= 60)
        cout << "及格" << endl;
    else
        cout << "不及格" << endl;
}

int main()
{
    printGrade(95);  // 输出：优秀
    printGrade(55);  // 输出：不及格
    return 0;
}
```

### 3. 无参有返

```cpp
#include <iostream>
using namespace std;

// 无参数，有返回值：获取用户输入的年龄
int getAge()
{
    int age = 0;
    cout << "请输入你的年龄：";
    cin >> age;
    return age;
}

int main()
{
    int userAge = getAge();  // 调用函数，接收返回值
    cout << "你的年龄是：" << userAge << " 岁" << endl;
    return 0;
}
```

### 4. 有参有返

```cpp
#include <iostream>
using namespace std;

// 有参数，有返回值：计算整数的 n 次方
int power(int base, int exp)
{
    int result = 1;
    for (int i = 0; i < exp; i++)
    {
        result *= base;
    }
    return result;
}

int main()
{
    cout << "2^3 = " << power(2, 3) << endl;    // 8
    cout << "5^4 = " << power(5, 4) << endl;    // 625
    cout << "10^2 = " << power(10, 2) << endl;  // 100
    return 0;
}
```

## 五、函数的声明

C/C++ 编译器是**自上而下**编译的。如果函数定义出现在调用之后，编译器会报"未声明标识符"错误。

**解决方法**：在调用之前先**声明**函数（也叫**函数原型**），告诉编译器函数的名称、参数及返回值类型。函数的具体定义可以放在后面。

```cpp
声明：返回值类型 函数名(参数类型列表);  // 只需类型，参数名可省略
定义：// 完整的函数体
```

**示例：先声明，后调用，最后定义**

```cpp
#include <iostream>
using namespace std;

// 函数声明（函数原型）—— 告诉编译器有这些函数
int add(int a, int b);          // 参数名可写
int subtract(int, int);         // 参数名也可省略
void sayHello();

int main()
{
    cout << "3 + 5 = " << add(3, 5) << endl;       // 可以正常调用
    cout << "10 - 4 = " << subtract(10, 4) << endl; // 可以正常调用
    sayHello();                                      // 可以正常调用
    return 0;
}

// ===== 以下为函数定义 =====

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

void sayHello()
{
    cout << "Hello!" << endl;
}
```

> **声明 vs 定义**：
> - **声明**：只告诉编译器"有这个函数"，不写函数体（以 `;` 结尾）。
> - **定义**：完整的函数代码，包含函数体 `{}`。
> - 声明可以出现**多次**，定义只能有**一次**。

## 六、函数的分文件编写（重要）

在实际项目中，将所有代码写在同一个文件里会非常臃肿、难以维护。函数的分文件编写可以让**代码结构更加清晰**：
- 将**声明**放在头文件（`.h`）中。
- 将**定义**放在源文件（`.cpp`）中。
- 在 `main` 函数所在的文件中 `#include` 头文件即可使用。

### 步骤

假设我们要编写一个"计算器"模块：

1. 创建 `.h` 头文件 → 写函数声明
2. 创建 `.cpp` 源文件 → 写函数定义，并 `#include` 对应的头文件
3. 在 `main.cpp` 中 `#include` 头文件 → 正常调用

### 示例

**文件结构：**

```
项目目录/
├── main.cpp          ← 主程序入口
├── calculator.h      ← 头文件（声明）
└── calculator.cpp    ← 源文件（定义）
```

**`calculator.h` — 头文件（只放声明）**

```cpp
#pragma once            // 防止头文件被重复包含（也可以用 #ifndef 方式）
#include <iostream>
using namespace std;

// 函数声明
int add(int a, int b);
int subtract(int a, int b);
int multiply(int a, int b);
double divide(int a, int b);
```

> **关于 `#pragma once`**：作用是防止头文件被多次包含。此外还有传统写法 `#ifndef` / `#define` / `#endif`，效果相同，`#pragma once` 更简洁。

**`calculator.cpp` — 源文件（写定义）**

```cpp
#include "calculator.h"

// 加法
int add(int a, int b)
{
    return a + b;
}

// 减法
int subtract(int a, int b)
{
    return a - b;
}

// 乘法
int multiply(int a, int b)
{
    return a * b;
}

// 除法
double divide(int a, int b)
{
    if (b == 0)
    {
        cout << "错误：除数不能为 0！" << endl;
        return 0;
    }
    return (double)a / b;
}
```

**`main.cpp` — 主程序**

```cpp
#include <iostream>
#include "calculator.h"  // 引入自定义头文件（用双引号，不用尖括号）
using namespace std;

int main()
{
    int x = 20, y = 5;

    cout << "加法：" << x << " + " << y << " = " << add(x, y) << endl;
    cout << "减法：" << x << " - " << y << " = " << subtract(x, y) << endl;
    cout << "乘法：" << x << " × " << y << " = " << multiply(x, y) << endl;
    cout << "除法：" << x << " ÷ " << y << " = " << divide(x, y) << endl;

    // 测试除数为 0
    cout << "除法：" << x << " ÷ 0 = " << divide(x, 0) << endl;

    return 0;
}
```

**运行结果：**

```
加法：20 + 5 = 25
减法：20 - 5 = 15
乘法：20 × 5 = 100
除法：20 ÷ 5 = 4
错误：除数不能为 0！
除法：20 ÷ 0 = 0
```

> **`#include` 规则**：
> - `< >` 尖括号 → 系统头文件（如 `<iostream>`）
> - `" "` 双引号 → 自定义头文件（如 `"calculator.h"`），编译器会先在当前目录查找

### 为什么要用 `#pragma once`？

如果没有保护机制，头文件被重复包含会导致**重定义错误**。例如：

```cpp
// 错误示例：没有保护的头文件
// calculator.h（没有 #pragma once）

// 如果在多个 .cpp 中都 #include "calculator.h"
// 链接时会出现："函数重复定义"的错误
```

两种常见的头文件保护写法：

```cpp
// 方式一：#pragma once（推荐，简洁）
#pragma once

// 方式二：#ifndef / #define / #endif（传统写法，兼容所有编译器）
#ifndef _CALCULATOR_H_
#define _CALCULATOR_H_

// ... 声明写在这里 ...

#endif  // _CALCULATOR_H_
```

## 综合练习

### 练习 1：判断素数

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 判断一个数是否是素数（只能被 1 和自身整除）
bool isPrime(int n)
{
    if (n <= 1)
    {
        return false;  // 1 和小于 1 的数不是素数
    }

    // 只需检查到 sqrt(n) 即可
    for (int i = 2; i <= sqrt(n); i++)
    {
        if (n % i == 0)
        {
            return false;  // 找到了因子，不是素数
        }
    }
    return true;
}

int main()
{
    int num = 0;
    cout << "请输入一个整数：";
    cin >> num;

    if (isPrime(num))
    {
        cout << num << " 是素数" << endl;
    }
    else
    {
        cout << num << " 不是素数" << endl;
    }

    // 输出 1~100 之间的所有素数
    cout << "1~100 之间的素数：";
    for (int i = 1; i <= 100; i++)
    {
        if (isPrime(i))
        {
            cout << i << " ";
        }
    }
    cout << endl;

    return 0;
}
```

### 练习 2：计算阶乘

```cpp
#include <iostream>
using namespace std;

// 计算 n 的阶乘 (n! = 1 × 2 × 3 × ... × n)
// 使用 unsigned long long 以支持较大数值
unsigned long long factorial(int n)
{
    if (n < 0)
    {
        cout << "错误：负数没有阶乘" << endl;
        return 0;
    }

    unsigned long long result = 1;
    for (int i = 1; i <= n; i++)
    {
        result *= i;
    }
    return result;
}

int main()
{
    for (int i = 0; i <= 10; i++)
    {
        cout << i << "! = " << factorial(i) << endl;
    }

    // 输出：
    // 0! = 1
    // 1! = 1
    // 2! = 2
    // ...
    // 10! = 3628800

    return 0;
}
```

### 练习 3：判断闰年（函数封装）

```cpp
#include <iostream>
using namespace std;

// 判断闰年：能被 4 整除但不能被 100 整除，或者能被 400 整除
bool isLeapYear(int year)
{
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}

// 根据年份和月份返回该月的天数
int getDaysInMonth(int year, int month)
{
    switch (month)
    {
        case 1: case 3: case 5: case 7:
        case 8: case 10: case 12:
            return 31;
        case 4: case 6: case 9: case 11:
            return 30;
        case 2:
            return isLeapYear(year) ? 29 : 28;
        default:
            return 0;  // 无效月份
    }
}

int main()
{
    cout << "2000 年 2 月有 " << getDaysInMonth(2000, 2) << " 天" << endl;  // 29
    cout << "2023 年 2 月有 " << getDaysInMonth(2023, 2) << " 天" << endl;  // 28
    cout << "2024 年 7 月有 " << getDaysInMonth(2024, 7) << " 天" << endl;  // 31
    return 0;
}
```

### 练习 4：数组冒泡排序（函数封装）

将前面学过的冒泡排序封装为函数，实现排序逻辑的复用：

```cpp
#include <iostream>
using namespace std;

// 冒泡排序（升序）
// 参数：数组指针 + 数组长度
void bubbleSort(int arr[], int len)
{
    for (int i = 0; i < len - 1; i++)
    {
        for (int j = 0; j < len - 1 - i; j++)
        {
            if (arr[j] > arr[j + 1])
            {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

// 打印数组
void printArray(int arr[], int len)
{
    for (int i = 0; i < len; i++)
    {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main()
{
    int arr[] = {5, 3, 8, 1, 9, 2, 7, 4, 6};
    int len = sizeof(arr) / sizeof(arr[0]);

    cout << "排序前：";
    printArray(arr, len);

    bubbleSort(arr, len);  // 调用函数排序

    cout << "排序后：";
    printArray(arr, len);

    return 0;
}
```

> **注意**：当数组作为函数参数时，传递的是数组**首地址**（指针），函数内部对数组的修改**会直接作用于实参**！这不同于值传递，本质上是"地址传递"（后续指针章节会详细讲解）。

## 小结

| 概念 | 要点 |
|------|------|
| 函数定义 | `返回值类型 函数名(参数列表) { 函数体; return 值; }` |
| 函数调用 | `函数名(实参列表);` — 实参按顺序传给形参 |
| 值传递 | 形参是实参的**独立副本**，修改形参不影响实参 |
| 四种样式 | 无参无返 / 有参无返 / 无参有返 / 有参有返 |
| 函数声明 | 先声明（函数原型），后使用，最后定义 — 声明可多次，定义只能一次 |
| 分文件编写 | `.h` 放声明，`.cpp` 放定义；`#include "xxx.h"` 引用 |
| 头文件保护 | `#pragma once` 或 `#ifndef` / `#define` / `#endif` 防止重复包含 |
| 数组传参 | 传递的是首地址，函数内修改数组会直接影响实参！ |
