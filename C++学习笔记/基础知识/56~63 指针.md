# 指针

**指针**是 C/C++ 语言中最核心、也最灵活的特性之一。通过指针，可以直接操作内存，访问和修改内存中的数据。

> **指针的本质**：指针就是一个**变量**，但它存储的不是普通的数据值，而是另一个变量的**内存地址**。

---

## 一、指针的定义和使用

### 1. 定义指针

定义指针的语法：

```cpp
数据类型 * 指针名;
```

- `*` 表示这是一个指针变量。
- 数据类型表示这个指针指向什么类型的变量。

```cpp
int a = 10;
int * p;     // 定义一个指向 int 类型的指针（未初始化，暂时是野指针）
p = &a;      // 将变量 a 的地址赋给指针 p
```

也可以定义的同时初始化：

```cpp
int a = 10;
int * p = &a;  // 定义指针 p 并让它指向 a
```

> **`&` 取地址符**：用于获取变量的内存地址。

![[Pasted image 20260730112241.png]]

### 2. 使用指针（解引用）

通过指针访问它所指向的内存数据，需要在指针名前加 `*`，称为**解引用**（dereference）。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int * p = &a;

    cout << "变量 a 的值为：" << a << endl;          // 10
    cout << "指针 p 中存储的地址为：" << p << endl;    // 一个十六进制地址
    cout << "通过指针访问 a 的值为：" << *p << endl;   // 10（解引用）

    // 通过指针修改 a 的值
    *p = 20;
    cout << "通过指针修改后，a = " << a << endl;       // 20

    return 0;
}
```

**内存示意图：**

```
变量 a  ┌──────────┐
       │    20    │  ← 值
       │ 0x123456 │  ← 地址
       └──────────┘
            ↑
指针 p  ┌──────────┐
       │ 0x123456 │  ← p 中存储的是 a 的地址
       └──────────┘
```

> **记忆技巧**：
> - 定义时 `int * p` 中的 `*` → 表示 `p` 是一个指针。
> - 使用时 `*p` 中的 `*` → 解引用，取出指针指向的数据。

## 二、指针所占内存空间

无论指针指向何种类型的数据，指针本身存储的是一个**地址**，所以指针变量所占的内存大小只与**操作系统位数**有关。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int * p1;
    char * p2;
    double * p3;
    float * p4;
    long long * p5;

    cout << "int 指针占用：" << sizeof(p1) << " 字节" << endl;
    cout << "char 指针占用：" << sizeof(p2) << " 字节" << endl;
    cout << "double 指针占用：" << sizeof(p3) << " 字节" << endl;
    cout << "float 指针占用：" << sizeof(p4) << " 字节" << endl;
    cout << "long long 指针占用：" << sizeof(p5) << " 字节" << endl;

    return 0;
}
```

| 操作系统 | 所有类型指针的大小 |
|----------|-------------------|
| **32 位**（x86） | **4 字节** |
| **64 位**（x64） | **8 字节** |

> **原因**：指针存储的是地址，32 位系统的地址总线 32 根 → 2^32 种地址组合 → 需要 4 字节存储；64 位系统则对应 8 字节。

## 三、空指针

**空指针**是指不指向任何有效内存的指针，用 `NULL` 或 `nullptr` 表示。

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 方式一：C 语言传统写法
    int * p1 = NULL;

    // 方式二：C++11 推荐写法
    int * p2 = nullptr;

    cout << "p1 = " << p1 << endl;
    cout << "p2 = " << p2 << endl;

    return 0;
}
```

> **空指针的用途**：
> 1. 给指针变量**初始化**，避免产生野指针。
> 2. 在指针使用前做**合法性检查**：`if (p != nullptr)`。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int * p = nullptr;
    int a = 100;

    // 给指针赋有效的地址
    p = &a;

    // 使用前检查指针是否为空
    if (p != nullptr)
    {
        cout << "*p = " << *p << endl;  // 安全访问
    }
    else
    {
        cout << "指针为空，不访问" << endl;
    }

    return 0;
}
```

> **注意**：空指针**不能解引用**！`0~255` 的内存空间是系统占用的，访问空指针指向的内存会导致程序崩溃。

## 四、野指针

**野指针**是指指针变量中存储的地址是**非法、无效**的，即指向不可用的内存空间。

### 野指针的常见成因

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 情况一：指针未初始化
    int * p1;           // p1 中存的是随机值，可能指向任意内存
    // *p1 = 10;        // 危险！可能导致程序崩溃

    // 情况二：越界访问
    int arr[] = {1, 2, 3, 4, 5};
    int * p2 = arr;
    p2 += 10;           // 越界了，p2 指向了不属于数组的内存
    // *p2 = 100;       // 危险！

    // 情况三：指向已释放的内存（后续动态内存章节会讲到）
    // int * p3 = new int;
    // delete p3;        // 释放了 p3 指向的内存
    // *p3 = 100;        // 危险！访问已释放的内存，p3 成了野指针

    // 正确做法：指针不用时置空
    int * p4 = nullptr;  // 好的习惯：初始化指针
    // 或者释放后置空：
    // delete p3;
    // p3 = nullptr;

    return 0;
}
```

> **避免野指针的方法**：
> 1. 定义指针时养成**初始化**的好习惯：`int * p = nullptr;`
> 2. 释放内存后**及时置空**：`p = nullptr;`
> 3. 操作指针前**检查有效性**：`if (p != nullptr)`

## 五、const 修饰指针

`const` 修饰指针有三种情况，需要区分清楚：**指针的指向**能不能改？**指针指向的值**能不能改？

### 速查记忆法

记住一个简单判断方法：看 `const` 在 `*` 的**左边**还是**右边**。

| 写法 | 名称 | 指针指向（地址） | 指针指向的值 | 记忆口诀 |
|------|------|:---:|:---:|----------|
| `const int * p` | 常量指针 | ✅ 可改 | ❌ 不可改 | const 在 `*` 左 → **值**不能改 |
| `int * const p` | 指针常量 | ❌ 不可改 | ✅ 可改 | const 在 `*` 右 → **指向**不能改 |
| `const int * const p` | 双 const | ❌ 不可改 | ❌ 不可改 | 左右都有 → 都不能改 |

### 1. 常量指针 — `const int * p`

**const 在 `*` 左边** → 指向的**值**不能通过指针修改，但指针可以指向别处。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10, b = 20;
    const int * p = &a;  // 常量指针

    // *p = 30;          // ❌ 错误！不能通过 p 修改 a 的值
    cout << "*p = " << *p << endl;  // 可以读取：10

    p = &b;              // ✅ 正确！指针可以改为指向 b
    cout << "*p = " << *p << endl;  // 20

    return 0;
}
```

![[Pasted image 20260730142444.png]]

### 2. 指针常量 — `int * const p`

**const 在 `*` 右边** → 指针的**指向**不能改，但可以通过指针修改值。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10, b = 20;
    int * const p = &a;  // 指针常量

    *p = 30;             // ✅ 正确！可以通过 p 修改 a 的值
    cout << "a = " << a << endl;  // 30

    // p = &b;           // ❌ 错误！不能改变 p 的指向

    return 0;
}
```

![[Pasted image 20260730143125.png]]

### 3. const 既修饰指针，又修饰常量 — `const int * const p`

指针的**指向**和指向的**值**都不可修改。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    const int * const p = &a;

    // *p = 20;          // ❌ 错误！不能修改值
    // p = &b;           // ❌ 错误！不能修改指向

    cout << "*p = " << *p << endl;  // 只能读取：10

    return 0;
}
```

## 六、指针和数组

数组名就是一个指向数组首元素的**指针常量**（不可修改指向）。因此可以借助指针来访问数组元素。

### 1. 用指针遍历数组

```cpp
#include <iostream>
using namespace std;

int main()
{
    int arr[] = {10, 20, 30, 40, 50};
    int len = sizeof(arr) / sizeof(arr[0]);

    // 方式一：指针 + 下标偏移
    int * p1 = arr;  // arr 就是首元素的地址，等价于 &arr[0]
    for (int i = 0; i < len; i++)
    {
        cout << p1[i] << " ";  // p[i] 等价于 *(p + i)
    }
    cout << endl;

    // 方式二：指针算术运算（最常用）
    int * p2 = arr;
    for (int i = 0; i < len; i++)
    {
        cout << *p2 << " ";  // 先取当前指向的值
        p2++;                // 指针后移（指向下一个元素）
    }
    cout << endl;

    // 方式三：下标法（传统）
    for (int i = 0; i < len; i++)
    {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}
```

### 2. `p[i]` 与 `*(p+i)` 的等价关系

```cpp
#include <iostream>
using namespace std;

int main()
{
    int arr[] = {10, 20, 30, 40, 50};
    int * p = arr;

    // 以下四种写法完全等价
    cout << arr[2]  << endl;   // 30
    cout << p[2]    << endl;   // 30
    cout << *(arr + 2) << endl; // 30
    cout << *(p + 2) << endl;   // 30

    return 0;
}
```

> **核心公式**：`p[i]` = `*(p + i)`  
> 指针 `+i` 不是加 i 个字节，而是加 `i × sizeof(元素类型)` 个字节，编译器会自动处理偏移量。

### 3. 指针遍历数组的内存示意

```cpp
int arr[] = {10, 20, 30, 40, 50};
int * p = arr;  // p 指向 arr[0]
```

```
        arr[0]  arr[1]  arr[2]  arr[3]  arr[4]
      ┌───────┬───────┬───────┬───────┬───────┐
      │  10   │  20   │  30   │  40   │  50   │
      └───────┴───────┴───────┴───────┴───────┘
          ↑       ↑       ↑       ↑       ↑
          p      p+1     p+2     p+3     p+4
```

### 4. 冒泡排序（指针版）

用指针改写冒泡排序，对数组进行操作：

```cpp
#include <iostream>
using namespace std;

// 指针版冒泡排序
void bubbleSort(int * arr, int len)
{
    for (int i = 0; i < len - 1; i++)
    {
        for (int j = 0; j < len - 1 - i; j++)
        {
            if (*(arr + j) > *(arr + j + 1))
            {
                // 交换
                int temp = *(arr + j);
                *(arr + j) = *(arr + j + 1);
                *(arr + j + 1) = temp;
            }
        }
    }
}

void printArray(int * arr, int len)
{
    for (int i = 0; i < len; i++)
    {
        cout << *(arr + i) << " ";
    }
    cout << endl;
}

int main()
{
    int arr[] = {5, 3, 8, 1, 9, 2, 7, 4, 6};
    int len = sizeof(arr) / sizeof(arr[0]);

    cout << "排序前：";
    printArray(arr, len);

    bubbleSort(arr, len);

    cout << "排序后：";
    printArray(arr, len);

    return 0;
}
```

## 七、指针和函数 — 地址传递

### 1. 值传递 vs 地址传递

前面学过函数的值传递，实参的值拷贝给形参，修改形参**不影响**实参。但如果想在函数内部**修改外部变量**，就需要用**地址传递**（将变量的地址作为参数传给函数）。

```cpp
#include <iostream>
using namespace std;

// 值传递：不能修改实参
void swapValue(int a, int b)
{
    int temp = a;
    a = b;
    b = temp;
    cout << "swapValue 内部：a=" << a << ", b=" << b << endl;
}

// 地址传递：可以修改实参
void swapPointer(int * a, int * b)
{
    int temp = *a;   // *a 解引用，拿到 a 指向的值
    *a = *b;         // 把 b 指向的值赋给 a 指向的位置
    *b = temp;       // 把暂存的值赋给 b 指向的位置
}

int main()
{
    int x = 10, y = 20;

    // 值传递 —— 不会改变 x 和 y
    swapValue(x, y);
    cout << "值传递后：x=" << x << ", y=" << y << endl;
    // 输出：值传递后：x=10, y=20 （没有改变！）

    cout << "---" << endl;

    // 地址传递 —— 传入 x 和 y 的地址
    swapPointer(&x, &y);
    cout << "地址传递后：x=" << x << ", y=" << y << endl;
    // 输出：地址传递后：x=20, y=10 （成功交换！）

    return 0;
}
```

### 2. 地址传递的原理图解

```
【值传递 swapValue】                   【地址传递 swapPointer】

调用前：                              调用前：
  x=10  y=20                            x=10  y=20

调用时（拷贝）：                       调用时（传地址）：
  a=10  b=20 （独立副本）                a=&x  b=&y （指向x和y）

函数内交换：                           函数内通过地址交换：
  a=20  b=10 （交换了副本）             *a ↔ *b （直接操作x和y的值）

返回后：                              返回后：
  x=10  y=20  ✗ 没变                   x=20  y=10  ✓ 交换成功！
```

### 3. 实战：找出数组中的最大值和最小值

函数只能有一个返回值，但通过指针参数可以"返回"多个结果：

```cpp
#include <iostream>
using namespace std;

// 找出数组的最大值和最小值
// min 和 max 是指针参数，用于把结果"带出去"
void findMinMax(int arr[], int len, int * min, int * max)
{
    *min = arr[0];
    *max = arr[0];

    for (int i = 1; i < len; i++)
    {
        if (arr[i] < *min)
            *min = arr[i];
        if (arr[i] > *max)
            *max = arr[i];
    }
}

int main()
{
    int arr[] = {34, 12, 56, 78, 23, 90, 45, 8, 67};
    int len = sizeof(arr) / sizeof(arr[0]);
    int minVal = 0, maxVal = 0;

    // 传入 minVal 和 maxVal 的地址
    findMinMax(arr, len, &minVal, &maxVal);

    cout << "最小值：" << minVal << endl;  // 8
    cout << "最大值：" << maxVal << endl;  // 90

    return 0;
}
```

### 4. 实战：字符串长度计算

```cpp
#include <iostream>
using namespace std;

// 用指针计算字符串长度（模拟 strlen）
int myStrlen(const char * str)
{
    const char * p = str;    // 记录起始位置
    while (*p != '\0')       // 只要没遇到字符串结束符
    {
        p++;                 // 指针后移
    }
    return p - str;          // 结束位置 - 起始位置 = 字符个数
}

int main()
{
    char str[] = "Hello World";
    cout << "\"" << str << "\" 的长度为：" << myStrlen(str) << endl;  // 11

    return 0;
}
```

> **为什么参数用 `const char *`**：因为我们只读取字符串的内容，不修改它。加 `const` 既可以防止误修改，也让调用者放心。

## 小结

| 概念 | 要点 |
|------|------|
| 指针定义 | `int * p = &a;` — 存储变量地址的变量 |
| 解引用 | `*p` — 通过指针访问/修改指向的数据 |
| 指针大小 | 32 位系统 4 字节，64 位系统 8 字节，**与指向类型无关** |
| 空指针 | `nullptr`（C++11 推荐）或 `NULL`，不能解引用 |
| 野指针 | 指向非法内存的指针，**必须避免** |
| 常量指针 | `const int * p` — 值不可改，指向可改 |
| 指针常量 | `int * const p` — 指向不可改，值可改 |
| 双 const | `const int * const p` — 值和指向都不可改 |
| 指针与数组 | `p[i]` = `*(p + i)`，指针 `+1` 按元素大小自动偏移 |
| 地址传递 | 传地址给函数 → 函数内可修改外部变量；实现"多返回值"效果 |
| const 与指针口诀 | const 在 `*` 左 → 值不可改；const 在 `*` 右 → 指向不可改 |
