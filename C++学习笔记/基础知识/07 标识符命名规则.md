# 🏷️ 标识符命名规则

> **标识符**就是程序员给变量、常量、函数等起的名字。C++ 对命名有一套严格的规则。

---

## 📏 四大核心规则

### 规则 1：不能是关键字

关键字已被 C++ 语言占用，不可再使用。

```cpp
int return = 0;   // ❌ return 是关键字
int if = 10;      // ❌ if 是关键字
int class = 5;    // ❌ class 是关键字
```

### 规则 2：只能由字母、数字、下划线组成

不能包含空格、特殊符号、中文等。

```cpp
int my_age = 10;    // ✅ 下划线可以
int age2 = 20;      // ✅ 数字可以（但不能在开头）
int my age = 30;    // ❌ 有空格
int my-age = 40;    // ❌ 有减号（会被当成减法）
int 我 = 50;        // ❌ 中文（某些编译器支持但不推荐）
```

### 规则 3：第一个字符必须是字母或下划线

数字不能放在开头。

```cpp
int age = 10;       // ✅ 字母开头
int _count = 20;    // ✅ 下划线开头（但不推荐随意用）
int 1stPlace = 1;   // ❌ 数字开头
int 2num = 2;       // ❌ 数字开头
```

### 规则 4：标识符区分大小写

大写和小写被认为是不同的名字。

```cpp
int Age = 10;
int age = 20;
int AGE = 30;

// 这三个是完全不同的三个变量！
cout << Age << endl;  // 输出 10
cout << age << endl;  // 输出 20
cout << AGE << endl;  // 输出 30
```

---

## ✅❌ 合法 vs 非法示例

| 标识符 | 是否合法 | 原因 |
|--------|---------|------|
| `studentName` | ✅ | 字母组成 |
| `_temp` | ✅ | 下划线开头允许 |
| `count123` | ✅ | 数字不在开头 |
| `123abc` | ❌ | 数字开头 |
| `my-name` | ❌ | 含减号 `-` |
| `hello world` | ❌ | 含空格 |
| `class` | ❌ | 是关键字 |
| `return` | ❌ | 是关键字 |

---

## 🎨 命名风格建议

虽然不是强制规定，但养成良好的命名风格很重要！

| 命名风格 | 示例 | 适用场景 |
|---------|------|---------|
| **小驼峰** camelCase | `studentName`、`myAge` | 变量名（常见） |
| **大驼峰** PascalCase | `StudentName`、`MyClass` | 类名 |
| **下划线** snake_case | `student_name`、`my_age` | 变量名（也常见） |
| **全大写+下划线** | `MAX_SIZE`、`PI` | 常量、宏定义 |

---

## 💡 好名字 vs 坏名字

```cpp
// ❌ 坏名字 —— 看不懂含义
int a = 25;
int b = 8000;
float x = 3.14;

// ✅ 好名字 —— 见名知意
int age = 25;
int salary = 8000;
float pi = 3.14;
```

> **黄金法则：变量名应该回答"它是什么"，而不是"它是什么类型"**

---

## 🔁 回顾：与 [[06 关键字|关键字]] 的联系

标识符（你起的名） ≠ 关键字（系统保留的名）。起名时只要避开关键字、遵守四大规则，想怎么起就怎么起！
