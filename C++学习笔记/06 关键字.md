# 🔑 关键字（Keywords）

> 关键字是 C++ 语言**预先保留**的单词，每个关键字都有特殊的含义，**不能**用作变量名或常量名。

---

## ⚠️ 核心规则

> **定义变量或常量时，不要使用关键字作为名称！**

## 📋 C++ 常用关键字一览

### 数据类型关键字

| 关键字 | 用途 |
|--------|------|
| `int` | 整数类型 |
| `float` | 单精度浮点型 |
| `double` | 双精度浮点型 |
| `char` | 字符类型 |
| `bool` | 布尔类型（`true` / `false`） |
| `void` | 无类型（常用于函数返回值） |
| `short` | 短整型 |
| `long` | 长整型 |
| `struct` | 结构体 |
| `class` | 类 |
| `enum` | 枚举 |

### 流程控制关键字

| 关键字 | 用途 |
|--------|------|
| `if` / `else` | 条件分支 |
| `switch` / `case` | 多路分支 |
| `for` / `while` / `do` | 循环 |
| `break` | 跳出循环 |
| `continue` | 跳过本次循环 |
| `return` | 函数返回 |

### 修饰符关键字

| 关键字 | 用途 |
|--------|------|
| `const` | 定义常量 |
| `static` | 静态变量 |
| `unsigned` | 无符号类型 |
| `signed` | 有符号类型 |

---

## ❌ 错误示例

```cpp
// 这些都会编译失败！因为关键字不能做变量名

int int = 10;        // ❌ int 是关键字
float float = 3.14;  // ❌ float 是关键字
char return = 'A';   // ❌ return 是关键字
bool if = true;      // ❌ if 是关键字
```

---

## ✅ 正确示例

```cpp
// 接近关键字但合法的命名（但也不推荐，容易混淆）

int intValue = 10;    // ✅ 加了后缀，合法
float price = 3.14;   // ✅ 用有意义的名称
char grade = 'A';     // ✅ 用有意义的名称
bool isPassed = true; // ✅ 用有意义的名称
```

## 💡 记忆技巧

- **IDE 会帮你区分**：关键字通常有**颜色高亮**（VS Code 中一般是蓝色）
- 如果不确定一个词是不是关键字，试着用它做变量名，看编译器报不报错
- 随着学习深入，你会自然而然地记住这些关键字
