# 📦 变量的意义

> 变量就是程序中用来**存储数据**的容器，就像数学中的 `x`、`y`，方便我们管理和操作数据。

---

## 📐 变量定义语法

```
数据类型 变量名 = 变量初始值;
```

```cpp
int age = 18;           // 整数类型
float price = 9.99;     // 单精度浮点型
double pi = 3.14159;    // 双精度浮点型
char grade = 'A';       // 字符类型
string name = "张三";    // 字符串类型
bool isPass = true;     // 布尔类型
```

---

## 🔢 常用数据类型

| 数据类型 | 关键字 | 占用空间 | 范围 | 示例 |
|---------|--------|---------|------|------|
| 整型 | `int` | 4 字节 | -2^31 ~ 2^31-1 | `int a = 100;` |
| 短整型 | `short` | 2 字节 | -32768 ~ 32767 | `short b = 10;` |
| 长整型 | `long` | 4/8 字节 | 视平台而定 | `long c = 99999;` |
| 单精度 | `float` | 4 字节 | ~7 位有效数字 | `float pi = 3.14f;` |
| 双精度 | `double` | 8 字节 | ~15 位有效数字 | `double pi = 3.14159;` |
| 字符 | `char` | 1 字节 | 0 ~ 255（ASCII） | `char ch = 'A';` |
| 字符串 | `string` | 可变 | — | `string s = "hello";` |
| 布尔 | `bool` | 1 字节 | `true` / `false` | `bool ok = true;` |

---

## 💡 变量的三个要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **数据类型** | 决定变量能存什么类型的数据 | `int`只能存整数 |
| **变量名** | 程序访问变量的标识 | `age`、`price` |
| **值** | 变量中实际存储的数据 | `18`、`9.99` |

---

## ✍️ 完整示例

```cpp
#include <iostream>

using namespace std;

int main()
{
    // 定义变量
    int age = 25;
    double salary = 8000.50;
    char grade = 'A';
    string name = "小明";

    // 使用变量
    cout << "姓名：" << name << endl;
    cout << "年龄：" << age << " 岁" << endl;
    cout << "薪资：" << salary << " 元" << endl;
    cout << "等级：" << grade << endl;

    return 0;
}
```

**输出结果：**
```
姓名：小明
年龄：25 岁
薪资：8000.5 元
等级：A
```

---

## ⚠️ 注意事项

1. **必须先声明再使用** —— 变量不存在于定义之前
2. **赋值类型要匹配** —— `int a = 3.14;` 会丢失小数部分（变成 `3`）
3. **变量可以重新赋值** —— `age = 26;` 会覆盖原来的值
4. **C++ 区分大小写** —— `Age` 和 `age` 是两个不同的变量
