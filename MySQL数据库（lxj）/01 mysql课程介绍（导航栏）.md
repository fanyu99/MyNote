# 📘 MySQL 数据库学习笔记

> 个人 MySQL 学习知识体系，涵盖从基础入门到生产运维的完整学习路径。

---

## 🗺️ 课程总览

本课程分为**三大篇章**，建议按顺序循序渐进学习：

| 篇章 | 定位 | 核心内容 |
|:---|:---|:---|
| 🏗️ [[基础篇/00 基础篇概览\|基础篇]] | 打好地基 | SQL 语法、数据类型、函数、约束、多表查询、事务 |
| 🚀 [[进阶篇/00 进阶篇概览\|进阶篇]] | 深入内核 | 存储引擎、索引、SQL 优化、锁机制、MVCC、InnoDB |
| 🔧 [[运维篇/00 运维篇概览\|运维篇]] | 生产实战 | 安装部署、主从复制、分库分表、备份恢复、性能调优 |
