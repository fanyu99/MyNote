# 📐 MySQL 函数

> MySQL 提供了丰富的内置函数，方便在查询时对数据进行处理和计算。主要分为四类：**字符串函数**、**数值函数**、**日期函数**、**流程函数**。

---

## 一、字符串函数

![[Pasted image 20260806111702.png]]

### 1.1 常用字符串函数速查

| 函数 | 语法 | 功能 | 示例 |
|:-----|:-----|:-----|:-----|
| `CONCAT` | `CONCAT(s1, s2, ...)` | 拼接字符串 | `CONCAT('Hello', 'World')` → `HelloWorld` |
| `LOWER` | `LOWER(str)` | 转为小写 | `LOWER('ABC')` → `abc` |
| `UPPER` | `UPPER(str)` | 转为大写 | `UPPER('abc')` → `ABC` |
| `LPAD` | `LPAD(str, n, pad)` | 左侧填充 | `LPAD('1', 3, '0')` → `001` |
| `RPAD` | `RPAD(str, n, pad)` | 右侧填充 | `RPAD('A', 3, '-')` → `A--` |
| `TRIM` | `TRIM(str)` | 去除首尾空格 | `TRIM('  abc  ')` → `abc` |
| `SUBSTRING` | `SUBSTRING(str, start, len)` | 截取子串 | `SUBSTRING('Hello', 1, 3)` → `Hel` |
| `LENGTH` | `LENGTH(str)` | 返回字节长度 | `LENGTH('abc')` → `3` |
| `REPLACE` | `REPLACE(str, from, to)` | 替换字符串 | `REPLACE('abcab', 'a', 'x')` → `xbcxb` |
| `INSTR` | `INSTR(str, substr)` | 子串首次出现位置 | `INSTR('hello', 'l')` → `3` |

### 1.2 实操示例

```sql
-- ==================== 字符串函数示例 ====================

-- 1. CONCAT：拼接字符串
SELECT CONCAT('Hello', ' ', 'World') AS 拼接结果;         -- Hello World

-- 应用场景：拼接员工姓名和工号
SELECT CONCAT(name, ' (', work_no, ')') AS 员工信息 FROM employee;

-- 2. LOWER / UPPER：大小写转换
SELECT LOWER('MySQL') AS 小写, UPPER('mysql') AS 大写;

-- 应用场景：对用户输入的姓名做大小写统一处理
SELECT * FROM employee WHERE UPPER(name) = UPPER('zhangsan');

-- 3. LPAD / RPAD：填充
SELECT LPAD('5', 3, '0') AS 左填充;    -- 005（工号补零）
SELECT RPAD('A', 5, '-') AS 右填充;    -- A----

-- 应用场景：员工编号格式化（不足 4 位前面补零）
SELECT LPAD(id, 4, '0') AS 编号 FROM employee;

-- 4. TRIM：去除首尾空格
SELECT TRIM('   张三   ') AS 去空格;    -- 张三

-- 5. SUBSTRING：截取字符串
SELECT SUBSTRING('HelloWorld', 1, 5) AS 截取;    -- Hello（索引从 1 开始！）
SELECT SUBSTRING('HelloWorld', 6) AS 从第6位开始; -- World

-- 应用场景：从身份证号中提取出生日期
SELECT
    name,
    id_card,
    SUBSTRING(id_card, 7, 8) AS 出生日期   -- 110101199901011234 → 19990101
FROM employee;

-- 6. REPLACE：替换
SELECT REPLACE('010-1234-5678', '-', '') AS 去横线;  -- 01012345678

-- 7. INSTR：查找位置
SELECT INSTR('hello@company.com', '@') AS at符号位置;  -- 6

-- 综合应用：提取邮箱中的用户名和域名
SELECT
    email,
    SUBSTRING(email, 1, INSTR(email, '@') - 1) AS 用户名,
    SUBSTRING(email, INSTR(email, '@') + 1) AS 域名
FROM (SELECT 'zhangsan@company.com' AS email) AS tmp;
```

## 二、数值函数

![[Pasted image 20260806113617.png]]

### 2.1 常用数值函数速查

| 函数 | 功能 | 示例 | 结果 |
|:-----|:-----|:-----|:----:|
| `CEIL(x)` | 向上取整 | `CEIL(3.1)` | `4` |
| `FLOOR(x)` | 向下取整 | `FLOOR(3.9)` | `3` |
| `MOD(x, y)` | 取模（求余） | `MOD(10, 3)` | `1` |
| `RAND()` | 0~1 之间的随机数 | `RAND()` | `0.372...` |
| `ROUND(x, d)` | 四舍五入，保留 d 位小数 | `ROUND(3.1415, 2)` | `3.14` |
| `ABS(x)` | 绝对值 | `ABS(-10)` | `10` |
| `POW(x, y)` | x 的 y 次方 | `POW(2, 3)` | `8` |
| `SQRT(x)` | 平方根 | `SQRT(16)` | `4` |
| `TRUNCATE(x, d)` | 截断到 d 位小数（不四舍五入） | `TRUNCATE(3.149, 2)` | `3.14` |

### 2.2 实操示例

```sql
-- ==================== 数值函数示例 ====================

-- 1. CEIL / FLOOR：取整
SELECT CEIL(2.1) AS 向上取整;   -- 3
SELECT FLOOR(2.9) AS 向下取整;  -- 2

-- 2. MOD：取模
SELECT MOD(10, 3) AS 取余;      -- 1

-- 应用场景：判断奇偶（MOD(id, 2) = 0 为偶数）
SELECT id, name, CASE WHEN MOD(id, 2) = 0 THEN '偶数' ELSE '奇数' END AS 奇偶
FROM employee;

-- 3. RAND：随机数
SELECT RAND() AS 随机数;

-- 应用场景：随机抽取 1 条数据（抽奖）
SELECT name FROM employee ORDER BY RAND() LIMIT 1;

-- 4. ROUND：四舍五入
SELECT ROUND(3.14159, 2) AS 四舍五入;  -- 3.14
SELECT ROUND(3.14159, 0) AS 取整;      -- 3

-- 应用场景：计算员工平均年龄并保留 1 位小数
SELECT ROUND(AVG(age), 1) AS 平均年龄 FROM employee;

-- 5. TRUNCATE：截断
SELECT TRUNCATE(3.149, 2) AS 截断;     -- 3.14（不是 3.15！）
SELECT ROUND(3.149, 2) AS 四舍五入;     -- 3.15（对比）

-- 6. ABS / POW / SQRT
SELECT ABS(-10) AS 绝对值;              -- 10
SELECT POW(2, 8) AS 2的8次方;           -- 256
SELECT SQRT(25) AS 平方根;              -- 5
```

## 三、日期函数

![[Pasted image 20260806114243.png]]

### 3.1 常用日期函数速查

| 函数 | 功能 | 示例 | 结果 |
|:-----|:-----|:-----|:-----|
| `CURDATE()` | 当前日期 | `CURDATE()` | `2024-09-01` |
| `CURTIME()` | 当前时间 | `CURTIME()` | `14:30:00` |
| `NOW()` | 当前日期+时间 | `NOW()` | `2024-09-01 14:30:00` |
| `YEAR(date)` | 提取年份 | `YEAR('2024-09-01')` | `2024` |
| `MONTH(date)` | 提取月份 | `MONTH('2024-09-01')` | `9` |
| `DAY(date)` | 提取天数 | `DAY('2024-09-01')` | `1` |
| `DATE_ADD(date, INTERVAL n unit)` | 日期加运算 | `DATE_ADD('2024-01-01', INTERVAL 70 DAY)` | `2024-03-11` |
| `DATE_SUB(date, INTERVAL n unit)` | 日期减运算 | `DATE_SUB('2024-01-01', INTERVAL 30 DAY)` | `2023-12-02` |
| `DATEDIFF(date1, date2)` | 日期差（天数） | `DATEDIFF('2024-09-01', '2024-08-01')` | `31` |

> [!note] INTERVAL 单位
> `DAY`、`WEEK`、`MONTH`、`YEAR`、`HOUR`、`MINUTE`、`SECOND`

### 3.2 实操示例

```sql
-- ==================== 日期函数示例 ====================

-- 1. 获取当前日期、时间、日期时间
SELECT CURDATE() AS 今天日期;
SELECT CURTIME() AS 当前时间;
SELECT NOW() AS 当前日期时间;

-- 2. YEAR / MONTH / DAY：提取日期各部分
SELECT
    name,
    entry_date,
    YEAR(entry_date) AS 入职年份,
    MONTH(entry_date) AS 入职月份,
    DAY(entry_date) AS 入职日
FROM employee;

-- 3. DATE_ADD：日期运算
-- 入职 70 天后的日期
SELECT name, entry_date, DATE_ADD(entry_date, INTERVAL 70 DAY) AS 入职70天后的日期
FROM employee;

-- 70 天后是什么日期？
SELECT DATE_ADD(NOW(), INTERVAL 70 DAY) AS 70天后的日期;

-- 一个月前的日期
SELECT DATE_SUB(NOW(), INTERVAL 1 MONTH) AS 一个月前;

-- 4. DATEDIFF：日期差值
-- 统计每位员工的入职天数
SELECT
    name,
    entry_date,
    DATEDIFF(CURDATE(), entry_date) AS 入职天数
FROM employee;

-- 入职满 5 年（1825 天以上）的员工
SELECT name, entry_date, DATEDIFF(CURDATE(), entry_date) AS 入职天数
FROM employee
WHERE DATEDIFF(CURDATE(), entry_date) > 1825;
```

## 四、流程函数

![[Pasted image 20260806121258.png]]

> 流程函数实现了 SQL 中的 **if-else 逻辑**，是条件查询中最常用的函数。

### 4.1 IF

```sql
-- 语法
IF(条件, 条件为真时的返回值, 条件为假时的返回值)

-- ==================== 示例 ====================

-- 判断员工年龄是否 >= 30
SELECT name, age, IF(age >= 30, '中年', '青年') AS 年龄段
FROM employee;
```

### 4.2 IFNULL

```sql
-- 语法
IFNULL(字段, 默认值)   -- 如果字段为 NULL，则返回默认值

-- ==================== 示例 ====================

-- 没有地址的员工显示"未知"
SELECT name, work_address, IFNULL(work_address, '未知') AS 地址
FROM employee;
```

> [!tip] 区别
> `IFNULL` 只处理 NULL，相当于 `IF(expr IS NULL, default, expr)`。

![[Pasted image 20260806122121.png]]

### 4.3 CASE WHEN（重点）

```sql
-- 语法 1：等值判断
CASE 字段
    WHEN 值1 THEN 结果1
    WHEN 值2 THEN 结果2
    ...
    ELSE 结果N
END

-- 语法 2：范围判断
CASE
    WHEN 条件1 THEN 结果1
    WHEN 条件2 THEN 结果2
    ...
    ELSE 结果N
END
```

![[Pasted image 20260806121743.png]]

```sql
-- ==================== CASE WHEN 示例 ====================

-- 示例 1：等值判断（工作地址 → 地区）
SELECT
    name,
    work_address,
    CASE work_address
        WHEN '北京' THEN '华北'
        WHEN '上海' THEN '华东'
        WHEN '广州' THEN '华南'
        WHEN '深圳' THEN '华南'
        WHEN '杭州' THEN '华东'
        ELSE '其他'
    END AS 地区
FROM employee;

-- 示例 2：范围判断（年龄分段）
SELECT
    name,
    age,
    CASE
        WHEN age < 25 THEN '青年'
        WHEN age >= 25 AND age < 30 THEN '青壮年'
        WHEN age >= 30 AND age < 35 THEN '壮年'
        WHEN age >= 35 THEN '中年'
    END AS 年龄段
FROM employee;

-- 示例 3：聚合统计中做分类汇总
-- 统计各地区的人数
SELECT
    CASE work_address
        WHEN '北京' THEN '华北'
        WHEN '上海' THEN '华东'
        WHEN '广州' THEN '华南'
        WHEN '深圳' THEN '华南'
        WHEN '杭州' THEN '华东'
        ELSE '其他'
    END AS 地区,
    COUNT(*) AS 人数
FROM employee
GROUP BY 地区
ORDER BY 人数 DESC;

-- 示例 4：行转列（统计男女员工人数）
SELECT
    COUNT(CASE WHEN gender = '男' THEN 1 END) AS 男员工人数,
    COUNT(CASE WHEN gender = '女' THEN 1 END) AS 女员工人数
FROM employee;

-- 示例 5：多重条件判断
-- 入职年限分级
SELECT
    name,
    entry_date,
    CASE
        WHEN DATEDIFF(CURDATE(), entry_date) < 365 THEN '不到1年'
        WHEN DATEDIFF(CURDATE(), entry_date) < 1095 THEN '1~3年'
        WHEN DATEDIFF(CURDATE(), entry_date) < 1825 THEN '3~5年'
        WHEN DATEDIFF(CURDATE(), entry_date) < 3650 THEN '5~10年'
        ELSE '10年以上'
    END AS 工龄
FROM employee;
```

## 📊 函数速查总览

| 分类 | 核心函数 | 最常用场景 |
|:-----|:---------|:-----------|
| 字符串 | `CONCAT` `SUBSTRING` `TRIM` `LPAD` `UPPER` | 拼接显示、格式化输出、统一大小写 |
| 数值 | `ROUND` `CEIL` `FLOOR` `MOD` `RAND` | 精度控制、奇偶判断、随机抽取 |
| 日期 | `NOW` `YEAR` `DATEDIFF` `DATE_ADD` | 日期运算、计算天差、年龄/工龄统计 |
| 流程 | `IF` `IFNULL` `CASE WHEN` | 条件判断、空值处理、分类汇总、行转列 |
