# 🔒 约束（Constraint）

> **约束**是作用于表中字段上的规则，用于**限制存储在表中的数据**，保证数据库中数据的正确性、有效性和完整性。

---

## 约束分类总览

| 约束 | 关键字 | 作用 |
|:-----|:------|:-----|
| 非空约束 | `NOT NULL` | 该字段不能为 NULL |
| 唯一约束 | `UNIQUE` | 该字段所有值不能重复 |
| 主键约束 | `PRIMARY KEY` | 非空 + 唯一，每表只能有一个 |
| 默认约束 | `DEFAULT` | 插入时未指定值则使用默认值 |
| 检查约束 | `CHECK`（MySQL 8.0+） | 保证值满足指定条件 |
| 外键约束 | `FOREIGN KEY` | 建立两张表之间的关联 |
| 自增 | `AUTO_INCREMENT` | 自动递增生成序列值 |

## 一、基本约束演示

![[../图片/Pasted image 20260807145249.png]]

### 1.1 创建表时添加约束

```sql
CREATE TABLE user (
    id     INT PRIMARY KEY AUTO_INCREMENT  COMMENT '主键ID',
    name   VARCHAR(20) NOT NULL UNIQUE     COMMENT '姓名（不能为空，不能重复）',
    age    INT CHECK (age > 0 AND age < 120) COMMENT '年龄（0~120之间）',
    status CHAR(1) DEFAULT '1'            COMMENT '状态（默认为1）',
    gender CHAR(1)                         COMMENT '性别'
) COMMENT '用户表';
```

### 1.2 各约束详解

#### NOT NULL（非空约束）

```sql
-- 建表时指定
CREATE TABLE student (
    id   INT,
    name VARCHAR(20) NOT NULL   -- 姓名不能为空
);

-- 测试
INSERT INTO student (id, name) VALUES (1, '张三');   -- ✅ 成功
INSERT INTO student (id, name) VALUES (2, NULL);     -- ❌ 报错！
```

#### UNIQUE（唯一约束）

```sql
-- 建表时指定
CREATE TABLE student (
    id     INT,
    phone  VARCHAR(11) UNIQUE   -- 手机号不能重复
);

-- 测试
INSERT INTO student VALUES (1, '13800138000');  -- ✅ 成功
INSERT INTO student VALUES (2, '13800138000');  -- ❌ 报错！手机号重复
INSERT INTO student VALUES (3, NULL);           -- ✅ NULL 可以（NULL != NULL）
```

> [!note] UNIQUE 与 NULL
> `UNIQUE` 约束允许有多个 `NULL` 值，因为 `NULL` 与任何值（包括另一个 `NULL`）比较都不相等。

#### PRIMARY KEY（主键约束）

```sql
-- 方式 1：直接在字段后写
CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(20)
);

-- 方式 2：在所有字段后统一声明（推荐，可定义联合主键）
CREATE TABLE student (
    id   INT,
    name VARCHAR(20),
    PRIMARY KEY (id)
);

-- 方式 3：修改表时添加
ALTER TABLE student ADD PRIMARY KEY (id);
```

| 特性 | `PRIMARY KEY` | `UNIQUE` |
|:-----|:-------------:|:--------:|
| 是否允许 NULL | ❌ 不允许 | ✅ **允许**（可以有多个 NULL） |
| 每表可定义的个数 | **1 个** | 多个 |
| 默认是否创建索引 | ✅ 聚簇索引 | ✅ 辅助索引 |
| 是否自动 NOT NULL | ✅ 是 | ❌ 否 |

#### DEFAULT（默认约束）

```sql
CREATE TABLE student (
    id     INT,
    name   VARCHAR(20),
    status CHAR(1) DEFAULT '1'   -- 不传时默认为 '1'
);

-- 测试
INSERT INTO student (id, name) VALUES (1, '张三');          -- status 自动为 '1'
INSERT INTO student (id, name, status) VALUES (2, '李四', '0');  -- status = '0'
```

#### CHECK（检查约束）— MySQL 8.0+

```sql
CREATE TABLE student (
    id   INT,
    name VARCHAR(20),
    age  INT CHECK (age >= 0 AND age <= 120),   -- 年龄范围
    gender CHAR(1) CHECK (gender IN ('男', '女')) -- 性别只能是男或女
);

-- 测试
INSERT INTO student VALUES (1, '张三', 25, '男');    -- ✅ 成功
INSERT INTO student VALUES (2, '李四', 150, '男');   -- ❌ 报错！年龄超出范围
INSERT INTO student VALUES (3, '王五', 20, 'M');     -- ❌ 报错！性别不在允许值中
```

#### AUTO_INCREMENT（自动增长）

![[../图片/Pasted image 20260807145249.png]]

```sql
CREATE TABLE student (
    id   INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20)
);

-- 插入数据（id 由系统自动生成：1, 2, 3, ...）
INSERT INTO student (name) VALUES ('张三');
INSERT INTO student (name) VALUES ('李四');
INSERT INTO student (name) VALUES ('王五');
INSERT INTO student (name) VALUES ('赵六');

SELECT * FROM student;
-- | id | name |
-- |----|------|
-- | 1  | 张三 |
-- | 2  | 李四 |
-- | 3  | 王五 |
-- | 4  | 赵六 |

-- 删除 id=4 后，自增序列不会回退
DELETE FROM student WHERE id = 4;
INSERT INTO student (name) VALUES ('孙七');  -- id 从 5 开始，不会复用 4
```

> [!tip] AUTO_INCREMENT 注意事项
> - 必须配合**键**（主键或唯一键）一起使用
> - 一张表只能有**一个**自增字段
> - 删除数据后，自增序列**不会回退**（除非 TRUNCATE 表）

### 1.3 建表后添加/删除约束

```sql
-- ==================== 添加约束 ====================

-- 添加非空约束
ALTER TABLE student MODIFY name VARCHAR(20) NOT NULL;

-- 添加唯一约束
ALTER TABLE student ADD UNIQUE (phone);

-- 添加主键
ALTER TABLE student ADD PRIMARY KEY (id);

-- 添加默认值
ALTER TABLE student ALTER COLUMN status SET DEFAULT '1';

-- 添加外键
ALTER TABLE student ADD CONSTRAINT fk_dept FOREIGN KEY (dept_id) REFERENCES dept(id);

-- ==================== 删除约束 ====================

-- 删除非空
ALTER TABLE student MODIFY name VARCHAR(20) NULL;  -- 或去掉 NOT NULL

-- 删除唯一约束
ALTER TABLE student DROP INDEX phone;

-- 删除主键
ALTER TABLE student DROP PRIMARY KEY;

-- 删除默认值
ALTER TABLE student ALTER COLUMN status DROP DEFAULT;

-- 删除外键
ALTER TABLE student DROP FOREIGN KEY fk_dept;
```

## 二、外键约束（FOREIGN KEY）

![[../图片/Pasted image 20260807154428.png]]

> 外键用来建立**两张表之间的关联**，确保数据的参照完整性。一张表的外键值必须在另一张表的主键中存在。

### 2.1 为什么需要外键？

```sql
-- 没有外键约束时可能出现的问题
CREATE TABLE dept (
    id   INT PRIMARY KEY,
    name VARCHAR(20)
) COMMENT '部门表';

CREATE TABLE employee (
    id      INT PRIMARY KEY,
    name    VARCHAR(20),
    dept_id INT                    -- 部门 ID（没有外键约束）
) COMMENT '员工表';

-- ⚠️ 问题 1：可以插入不存在的部门
INSERT INTO employee VALUES (1, '张三', 999);  -- 部门 999 根本不存在！

-- ⚠️ 问题 2：删除部门后员工变成"孤儿"
DELETE FROM dept WHERE id = 1;    -- 部门删了，但员工还指向这个部门！
```

> 外键约束就是用来**防止以上问题**的保障机制。

### 2.2 添加外键的两种方式

![[../图片/Pasted image 20260807154818.png]]

#### 方式一：创建表时添加

```sql
-- 语法
CONSTRAINT 外键名 FOREIGN KEY (本表字段) REFERENCES 主表(主表字段)

-- ==================== 完整示例 ====================

-- 1. 先创建主表（部门表）
CREATE TABLE dept (
    id   INT PRIMARY KEY AUTO_INCREMENT COMMENT '部门ID',
    name VARCHAR(20) NOT NULL COMMENT '部门名称'
) COMMENT '部门表';

-- 2. 创建子表（员工表）时添加外键
CREATE TABLE employee (
    id      INT PRIMARY KEY AUTO_INCREMENT COMMENT '员工ID',
    name    VARCHAR(20) NOT NULL COMMENT '姓名',
    dept_id INT COMMENT '所属部门',
    CONSTRAINT fk_emp_dept FOREIGN KEY (dept_id) REFERENCES dept(id)
) COMMENT '员工表';
```

#### 方式二：建表后添加

![[../图片/Pasted image 20260807155550.png]]

```sql
-- 语法
ALTER TABLE 子表名 ADD CONSTRAINT 外键名 FOREIGN KEY (子表字段) REFERENCES 主表(主表字段);

-- 示例
ALTER TABLE employee
ADD CONSTRAINT fk_emp_dept FOREIGN KEY (dept_id) REFERENCES dept(id);
```

### 2.3 验证外键约束

```sql
-- 插入测试数据
INSERT INTO dept VALUES (1, '研发部'), (2, '市场部'), (3, '财务部');

-- ✅ 正常插入：部门存在
INSERT INTO employee VALUES (1, '张三', 1);   -- 研发部，OK

-- ❌ 报错：外键约束阻止插入（部门 99 不存在）
INSERT INTO employee VALUES (2, '李四', 99);
-- Error: Cannot add or update a child row: a foreign key constraint fails

-- ❌ 报错：外键约束阻止删除主表数据（该部门还有员工）
DELETE FROM dept WHERE id = 1;
-- Error: Cannot delete or update a parent row: a foreign key constraint fails
```

### 2.4 外键的删除/更新行为

![[../图片/Pasted image 20260807161747.png]]

当主表数据被删除或更新时，子表的外键值该如何处理？通过 `ON DELETE` / `ON UPDATE` 指定：

| 行为 | 关键字 | 效果 |
|:-----|:------|:-----|
| **级联** | `CASCADE` | 主表删除/更新时，子表也跟着删除/更新 |
| **置空** | `SET NULL` | 主表删除/更新时，子表外键字段设为 `NULL` |
| **限制** | `RESTRICT` | 默认行为，如果子表有对应记录，则禁止删除/更新主表 |
| **无动作** | `NO ACTION` | 与 RESTRICT 类似 |

```sql
-- ==================== CASCADE 示例 ====================
CREATE TABLE employee_cascade (
    id      INT PRIMARY KEY AUTO_INCREMENT,
    name    VARCHAR(20),
    dept_id INT,
    CONSTRAINT fk_cascade FOREIGN KEY (dept_id)
        REFERENCES dept(id)
        ON UPDATE CASCADE    -- 部门 ID 变了，员工也跟着变
        ON DELETE CASCADE    -- 部门删了，员工也跟着删
);

-- 插入测试数据
INSERT INTO employee_cascade VALUES (1, '张三', 1), (2, '李四', 1), (3, '王五', 2);

-- 删除研发部 → 张三、李四也被删除！
DELETE FROM dept WHERE id = 1;  -- employee_cascade 中 dept_id=1 的记录全部被删除

-- 修改部门 ID → 员工的 dept_id 也跟着更新
UPDATE dept SET id = 10 WHERE id = 2;  -- 王五的 dept_id 自动变为 10


-- ==================== SET NULL 示例 ====================
CREATE TABLE employee_setnull (
    id      INT PRIMARY KEY AUTO_INCREMENT,
    name    VARCHAR(20),
    dept_id INT,
    CONSTRAINT fk_setnull FOREIGN KEY (dept_id)
        REFERENCES dept(id)
        ON UPDATE CASCADE
        ON DELETE SET NULL     -- 部门删了，员工 dept_id 改为 NULL
);

-- 删除部门 → 该部门下员工的 dept_id 变为 NULL
DELETE FROM dept WHERE id = 1;
```

> [!warning] SET NULL 的前提
> 使用 `SET NULL` 时，子表的外键字段**必须允许为 NULL**（不能有 `NOT NULL` 约束）。

## 三、外键约束完整实战

```sql
-- ==================== 实战：电商订单系统 ====================

-- 1. 用户表（主表）
CREATE TABLE tb_user (
    id       INT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    username VARCHAR(20) NOT NULL UNIQUE COMMENT '用户名',
    phone    CHAR(11) NOT NULL COMMENT '手机号'
) COMMENT '用户表';

-- 2. 商品表（主表）
CREATE TABLE tb_product (
    id    INT PRIMARY KEY AUTO_INCREMENT COMMENT '商品ID',
    name  VARCHAR(100) NOT NULL COMMENT '商品名称',
    price DECIMAL(10, 2) NOT NULL COMMENT '价格',
    stock INT DEFAULT 0 COMMENT '库存'
) COMMENT '商品表';

-- 3. 订单表（子表，关联用户）
CREATE TABLE tb_order (
    id        INT PRIMARY KEY AUTO_INCREMENT COMMENT '订单ID',
    user_id   INT NOT NULL COMMENT '下单用户',
    total     DECIMAL(10, 2) COMMENT '订单总价',
    create_time DATETIME DEFAULT NOW() COMMENT '下单时间',
    CONSTRAINT fk_order_user FOREIGN KEY (user_id)
        REFERENCES tb_user(id)
        ON DELETE RESTRICT    -- 有订单的用户不能直接删除
        ON UPDATE CASCADE     -- 用户ID变更时订单跟着变
) COMMENT '订单表';

-- 4. 订单明细表（子表，关联订单和商品）
CREATE TABLE tb_order_item (
    id         INT PRIMARY KEY AUTO_INCREMENT COMMENT '明细ID',
    order_id   INT NOT NULL COMMENT '订单ID',
    product_id INT NOT NULL COMMENT '商品ID',
    quantity   INT NOT NULL DEFAULT 1 COMMENT '购买数量',
    CONSTRAINT fk_item_order FOREIGN KEY (order_id)
        REFERENCES tb_order(id)
        ON DELETE CASCADE,                               -- 订单删除 → 明细也删除
    CONSTRAINT fk_item_product FOREIGN KEY (product_id)
        REFERENCES tb_product(id)
        ON DELETE RESTRICT                               -- 有订单的商品不能删除
) COMMENT '订单明细表';

-- 查看表结构
DESC tb_order_item;
SHOW CREATE TABLE tb_order_item;
```

## 📊 约束速查总览

| 约束 | 关键字 | 建表时写法 | 修改表时添加 | 删除 |
|:-----|:------|:-----|:-----|:-----|
| 非空 | `NOT NULL` | `字段 类型 NOT NULL` | `MODIFY 字段 类型 NOT NULL` | `MODIFY 字段 类型 NULL` |
| 唯一 | `UNIQUE` | `字段 类型 UNIQUE` | `ADD UNIQUE(字段)` | `DROP INDEX 字段` |
| 主键 | `PRIMARY KEY` | `字段 类型 PRIMARY KEY` 或 `PRIMARY KEY(字段)` | `ADD PRIMARY KEY(字段)` | `DROP PRIMARY KEY` |
| 默认 | `DEFAULT` | `字段 类型 DEFAULT 值` | `ALTER COLUMN 字段 SET DEFAULT 值` | `ALTER COLUMN 字段 DROP DEFAULT` |
| 检查 | `CHECK` | `字段 类型 CHECK(条件)` | `ADD CONSTRAINT 名 CHECK(条件)` | `DROP CHECK 名` |
| 外键 | `FOREIGN KEY` | `FOREIGN KEY(字段) REFERENCES 主表(主字段)` | `ADD CONSTRAINT 名 FOREIGN KEY...` | `DROP FOREIGN KEY 名` |
| 自增 | `AUTO_INCREMENT` | `字段 INT AUTO_INCREMENT` | `MODIFY 字段 INT AUTO_INCREMENT` | `MODIFY 字段 INT` |
