## 📚 知识点

### 1. SQL 基础语法
- DDL（数据定义语言）：`CREATE` / `ALTER` / `DROP`
- DML（数据操作语言）：`INSERT` / `UPDATE` / `DELETE`
- DQL（数据查询语言）：`SELECT`
- DCL（数据控制语言）：`GRANT` / `REVOKE`

### 2. 数据类型
- 数值类型（INT、DECIMAL 等）
- 字符串类型（CHAR、VARCHAR、TEXT 等）
- 日期时间类型（DATE、DATETIME、TIMESTAMP 等）

### 3. 常用函数
- 字符串函数、数值函数、日期函数、流程控制函数

### 4. 约束
- 主键、外键、唯一、非空、默认值、检查约束

### 5. 多表查询
- 内连接、外连接、自连接、子查询、联合查询

### 6. 事务
- ACID 特性、事务隔离级别、并发问题
