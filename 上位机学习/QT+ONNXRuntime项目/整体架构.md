项目整体分为以下架构:
## 1. 整体分层
```
1. 顶层UI(QML)
2. 中间层DetectionApp: 用于DetectionManager的各种结果/操作/错误与QML界面的操作以及显示
3. 中间层DetectionManager: 用于将App的任务下发给Worker,管理DetectionWorker的各种操作以及处理结果
4. 执行层DetectionWorker: 用于执行Manager下发的各种任务并返回结果/错误
5. 执行底层Detector: 用于最底层的检测任务并返回检测结果  
6. 绘画+显示ImageProvider,DetectionRenderer: 负责提供显示图和绘制检测框
 
```
## 2.数据传输分层
```
1. 底层Detector: 返回DetectionResult(结果列表,错误信息)
2. 执行层Worker: 获取DetectionResult后在工作线程绘制QImage之后拷贝传给上层Manager
3. 中间层Manager: 获取Worker的结果并上报完成进度给App
4. 中间层App: 获取Manager的各种信息(错误/结果/进度等),并交由UI进行显示   
```
