# 检测结果返回与 UI 显示

> 概述：检测任务按「是否保存文件」与「单图 / 批量」两个维度组合，决定结果如何回传与显示；UI 侧则用统一的公式计算作业进度。本页梳理检测作业分类、四种结果返回路径，以及进度条计算方式。

---

## 一、按检测作业（Job）分类

> [!note] 按检测作业（Job）进行分类
> 1. Job 含**单**图片 / 单视频 Task
> 2. Job 多图片 / 多视频 / 多图片 + 视频 Task

---

## 二、检测结果返回

| 场景 | 处理方式 |
| --- | --- |
| **不保存文件 + 单图片/视频** | 直接返回检测结果图片，交由 QML 显示 |
| **保存文件 + 单图片/视频** | 保存检测结果文件（图片/视频）到指定路径后，在显示器中显示检测图片 |
| **不保存文件 + 批量任务** | 仅保留缓冲区的最后 n 个结果并显示 |
| **保存文件 + 批量任务** | 保存到指定路径后，在 UI 的文件结果浏览面板中选择文件并预览 |

---

## 三、UI 显示：Job 进度条（非摄像头检测）

使用以下公式进行计算：

```cpp
// jobProgress       为整体的作业进度
// taskCompleted     为作业中整体完成的任务数
// taskUnitCompleted 为任务中完成子部分，例如视频完成了多少帧
// taskUnitTotal     为任务中待总完成总数，例如视频总共多少帧
jobProgress = (taskCompleted + taskUnitCompleted / taskUnitTotal) / taskTotal;
```
