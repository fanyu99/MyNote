## 🧭 三、学习路线（建议）

1. **采集层**：海康 SDK 取图流程 → GenICam 参数 → 缓冲区与生命周期（← 海康SDK 三篇）
2. **通信层**：Modbus 协议（设备通信）（← 协议）
3. **标定层**：内参标定 → 畸变校正 → 九点 / 手眼标定（← 视觉标定）
4. **原理层**：Qt 元对象系统（属性 + 信号槽）（← QT底层原理深入）
5. **实战层**：QT + ONNXRuntime 项目分层架构与 UI（← QT+ONNXRuntime项目）
