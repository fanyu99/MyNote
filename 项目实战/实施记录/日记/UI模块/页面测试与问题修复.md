# 页面测试与问题修复

> 记录「页面测试与问题修复」当天的任务、实现过程与结论。

**目标：** 先把 `ProductPage` / `InboundPage` 和对话框的测试跑起来，再根据测试结果修复实现中的边界问题。

**知识点：**

- 页面级单元测试如何覆盖异步回调和 owner 生命周期。

- Dialog 数据回显、动态刷新和失败路径的验证方法。

- Qt 测试中如何验证按钮状态、模型状态和提示消息。

**重点任务：**

- 为 `ProductPage` / `InboundPage` / `ProductEditDialog` / `InboundEditDialog` 补齐或更新单元测试。

- 验证异步基础数据加载、checkbox 动态刷新、编辑回显和失败路径。

- 检查真实链路下的页面状态更新、按钮启用禁用和 owner 生命周期保护。

- 根据测试结果修复残留问题。

**验收标准：**

- 关键页面测试通过。

- 异步加载、回显和刷新逻辑没有明显回归。

- 页面层错误提示和状态变化符合预期。
