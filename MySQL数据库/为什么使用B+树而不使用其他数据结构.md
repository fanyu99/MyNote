# 为什么使用 B+ 树而不使用其他数据结构

## B+ 树 vs B 树

| 对比维度 | B 树 | B+ 树 |
|---------|------|-------|
| 数据存储 | 每个节点都存储键值及其数据 | 非叶子节点仅存储键值，叶子节点存储键值及其对应的数据 |
| 范围查询 | 复杂，需要回溯父节点（中序遍历）进行查询 | 仅需查询叶子节点的有序链表即可 |
| 查询效率 | 命中节点，效率不稳定 | 在叶子节点的有序链表中进行，效率稳定 |
| 存储容量 | 相同容量限制下，存储的数据量较小 | 非叶子节点能存储更多键值（分支），所存储的数据量更大 |

## B+ 树 vs 红黑树

红黑树是二叉树，相同的大数据量下，红黑树的层数比 B+ 树多很多，查询效率较 B+ 树低。

## B+ 树 vs 哈希表

哈希表仅适用于等值查询，且当哈希冲突严重时效率低。
