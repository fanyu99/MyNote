# 视图

一张**虚拟表**，其对应的原表是**基表**。

- 不存储数据，仅保存查询语句的逻辑
- 使用与普通表相同
- **优点**：安全、便捷

## 具体语法

创建、修改、查询和删除。

可以在另外一个视图中创建视图。

## 对视图进行修改

### 条件

- 视图基于**单表**且无聚合函数无子查询
- 必须包含基表的所有非空字段
- 即视图的一行一一对应基表中的一行（不能一对多）

> **注意**：对视图的修改会在基表进行修改！

### With Check Option

`WITH [CASCADED | LOCAL] CHECK OPTION`：对视图的修改等操作进行条件检查，使其能够符合视图的 WHERE 条件。

| 特性 | LOCAL CHECK OPTION | CASCADED CHECK OPTION |
|------|-------------------|----------------------|
| 当前视图条件 | ✅ 检查 | ✅ 检查 |
| 底层视图条件 | 仅当底层视图有 WITH CHECK OPTION 时检查 | ✅ 总是检查（无论是否有 WITH CHECK OPTION） |
| 默认行为 | MySQL 8.0 之前是默认 | MySQL 8.0 起默认是 CASCADED |
| 级联检查 | 不级联 | 级联检查所有底层视图 |
