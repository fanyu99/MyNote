# 存储过程

## 基础语法

### 1. 创建存储过程

```sql
-- 1. 修改语句结束符（因为存储过程中包含分号，为了防止冲突，需临时修改结束符）
DELIMITER $$

-- 2. 创建存储过程
CREATE PROCEDURE 存储过程名称 ([参数列表 IN/OUT/INOUT 参数名 参数类型])
BEGIN
    -- 这里写具体的 SQL 语句和业务逻辑
    SELECT 'Hello, MySQL Procedure!';
END
$$

-- 3. 将语句结束符改回分号
DELIMITER ;

-- 4. 调用存储过程
CALL 存储过程名称();
```

### 2. 删除和查看存储过程

```sql
DROP PROCEDURE 名称;
SHOW CREATE PROCEDURE 名称;
```

## 参数

| 参数类型 | 说明 |
|---------|------|
| `IN`（默认） | 调用时需要传入值 |
| `OUT` | 作为参数输出，即作为返回值 |
| `INOUT` | 既能作为输入参数也能作为输出参数 |

## 变量

### 1. 系统变量（`@@`）

- **全局变量**（`GLOBAL`）：全局有效
- **会话变量**（`SESSION`）：仅对当前对话有效

```sql
-- 查看变量
SHOW SESSION VARIABLES;
SHOW GLOBAL VARIABLES;

-- 设置变量
SET SESSION 变量名 = 值;
SET GLOBAL 变量名 = 值;
```

### 2. 用户变量（`@`）

- **作用域**：在当前的客户端连接中有效
- **特点**：弱类型，直接赋值即可

```sql
SET @my_name = '黑马程序员';
SELECT @my_name;                              -- 输出结果
SELECT ... FROM ... INTO @变量名;              -- 将查询结果赋值给变量
```

### 3. 局部变量（`DECLARE`）

- **作用域**：在 `BEGIN ... END` 代码块之间有效
- **特点**：具有严格的数据类型

```sql
CREATE PROCEDURE test_var()
BEGIN
    -- 1. 声明局部变量（必须指定数据类型，可设默认值）
    DECLARE stu_count INT DEFAULT 0;

    -- 2. 变量赋值方式一：直接 SET
    SET stu_count = 10;

    -- 3. 变量赋值方式二：通过 SELECT 查询结果赋值（要求查询结果必须只有一行）
    SELECT COUNT(*) INTO stu_count FROM student;

    -- 4. 使用变量
    SELECT stu_count;
END $$
```

## 流程控制

### 条件判断

**IF 语句：**

```sql
IF score >= 90 THEN
    SET result = '优秀';
ELSEIF score >= 60 THEN
    SET result = '及格';
ELSE
    SET result = '不及格';
END IF;
```

**CASE 语句：**

```sql
CASE [字段]
    WHEN ... THEN ...;
    WHEN ... THEN ...;
    ELSE ...;
END CASE;
```

### 循环语句

**WHILE 语句：**

```sql
WHILE 条件 DO
    -- 循环体
END WHILE;
```

**REPEAT 语句：**

```sql
REPEAT
    -- 循环体
UNTIL 条件
END REPEAT;
```

**LOOP 语句：**

```sql
[loop_label:] LOOP
    -- 循环体
    -- ITERATE loop_label;  -- 跳到下轮循环
    -- LEAVE loop_label;    -- 退出循环
END LOOP [loop_label];
```

## 游标

用来存储查询结果集的数据类型。

```sql
-- 声明（必须位于变量后声明）
DECLARE 游标名 CURSOR FOR 查询语句;

-- 打开游标
OPEN 游标名;

-- 获取游标（一般用于循环中）
FETCH 游标名 INTO 变量列表;

-- 关闭游标
CLOSE 游标名;
```
