
# 分层

实体：在n层的活动元素（软件+硬件）称为第n层实体
对等层：不同机器上的同一层
对等实体：对等层的实体
协议：对等实体所遵循的规则，水平
接口：同一个节点内相邻两层交换信息的逻辑接口（服务访问点）
服务：下层为紧邻的上层提供的功能调用，垂直

协议数据单元：对等层之间传送的*数据单元*，PDU,包含SDU、PCI
服务数据单元：为完成上一层实体要求的功能而传送的*数据*，SDU
协议控制信息：控制协议操作的信息，PCI
n-SDU +n-PCI = n-PDU = (n-1)-SDU

网络协议三要素：
1. 语法：协议中的数据、控制信息格式
2. 语义：发送什么控制信息、完成什么操作/需要怎么应答
3. 同步（时序）：事件的实现顺序

### TCP/IP模型（实际上的标准）
1. 应用层：包括格式转换、会话管理等操作
2. 传输层：确保数据*全局传输正确*
3. 网络层（IP层）：路由选择、*分组转发*、拥塞控制，无差错控制等功能
4. 网络接口层：分组传输，不具体描述数据传输的要求


### OSI模型（法律上的标准）
1. 应用层：实现特定网络应用，例如HTTP协议
2. 表示层：解决不同主机上信息表示不一致的问题，*数据格式转缓缓*
3. 会话层：管理进程间的会话，*会话管理*
4. 传输层：*报文传输*，实现端口到端口的通信（进程间通信）
5. 网络层：*分组传输*，将分组从源节点转发到目的节点，实现*路由选择、分组转发*、拥塞控制、网际互连，*分组的差错控制和流量控制*、连接建立和释放、可靠传输管理，确保的是分组的传输正确
6. 数据链路层：*帧传输*，确保相邻节点的链路逻辑上无差错，重要功能为*差错控制*、流量控制，确保的是帧传输正确
7. 物理层：完成相邻节点之间的*比特传输*，例如网线接口等

>[!OSI模型和TCP/IP模型中的数据链路层和网络层区别]
>
>OSI模型的数据链路层和网络层按照==🔴数据局部正确！=数据全局正确==思想进行确保数据传输的正确性，因此会在两个层次都进行**差错控制**等校验
>
>TCP/IP模型按照==🔴数据全局正确 -> 数据局部正确==思想，只在传输层进行校验，网络层**不进行差错控制**等校验

常见网络设备功能层次
- 集线器：物理层
- 交换机：物理层、数据链路层
- 路由器：物理层、数据链路层、网络层
- 主机：1-7层
