# 计算机网络的分类与性能指标

> 概述：本篇解决「网络怎么分类」与「用哪些指标衡量网络好坏」两个问题，主线为 **五种分类维度 → 性能指标（速率 / 带宽 / 吞吐量 / 时延 / 时延带宽积 / RTT / 信道利用率）**。

---

## 一、计算机网络的分类

### 1. 按分布范围

| 类型 | 全称 | 范围 | 特点 |
| --- | --- | --- | --- |
| **广域网 WAN** | Wide Area Network | 跨城市、国家 | 距离远、速率相对低，是 Internet 的核心 |
| **城域网 MAN** | Metropolitan Area Network | 一个城市 | 介于 WAN 与 LAN 之间 |
| **局域网 LAN** | Local Area Network | 一栋楼 / 一个校园 | 距离近、速率高、时延低 |
| **个域网 PAN** | Personal Area Network | 个人周围十米 | 如蓝牙、个人热点 |

### 2. 按传输技术

- **广播式网络**：所有节点**共享一条通信信道**，某节点发送的数据可被其他节点收到（无线网络多为广播式）。
- **点对点网络**：每条链路只连接**一对**节点，数据需经中间节点存储转发（广域网多采用）。

### 3. 按拓扑结构

| 拓扑 | 传输方式 | 争用问题 | 例子 |
| --- | --- | --- | --- |
| **总线型** | 广播式 | 存在「总线争用」 | 用集线器连接的早期以太网 |
| **环形** | 广播式 | 用**令牌**解决争用 | 令牌环网 |
| **星形** | 点对点（经中央设备） | 无总线争用 | 以太网交换机连接的设备 |
| **网状** | 点对点（存储转发） | 无 | 由众多路由器构成的广域网 |

> 星形拓扑中，**中央设备一旦故障会导致全网瘫痪**（单点故障），但便于集中管理。

### 4. 按使用者

- **公用网**：面向全社会开放（如电信运营商网络）。
- **专用网**：面向特定单位 / 机构（如军队、企业内部网）。

### 5. 按传输介质

- **有线网络**：双绞线、同轴电缆、光纤。
- **无线网络**：Wi-Fi、蓝牙、蜂窝移动网络。

## 二、性能指标

### 1. 信道

**信道**指信息传输的通道，是**单向**的。一条通信线路往往对应一个**接收信道** + 一个**发送信道**（即一条线路可支持双向通信）。

### 2. 速率（比特率）

- 单位：**bit/s**，写作 **bps** 或 **b/s**。
- 也常用 **Byte/s**（Bps、B/s），换算 **1 B = 8 bit**。
- **计算机网络中一律用十进制**：K = 10³、M = 10⁶、G = 10⁹、T = 10¹²。

> [!warning] 网速 vs 内存：十进制 vs 二进制
> - **网速**用**十进制**：1 kBps = 10³ Bps = 1000 B/s。
> - **内存 / 存储**常用**二进制**：1 KiB = 2¹⁰ B = 1024 B。
> 别把两者混用（题目里常故意考这个）。严格写法：十进制用 kB / MB，二进制用 KiB / MiB。

### 3. 带宽

- 某信道**所能传送的最高速率**，单位 bps。
- 早期指频带宽度（单位 Hz），现在通常被理解为「最高数据率」。
- 节点实际能达到的最高传输速率受**带宽**与**节点处理性能**共同限制——**短板效应**。

### 4. 吞吐量

- 单位时间内通过某个网络（或信道、接口）的**实际数据量**，单位 bps。
- 受**带宽**（上限）和**网络负载**（实际拥塞程度）影响。
- 关系：**吞吐量 ≤ 带宽**。

### 5. 时延（延迟 / 迟延）

**总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延**

| 时延 | 含义 | 计算 |
| --- | --- | --- |
| **发送时延**（传输时延） | 节点把数据**推上链路**所用的时间 | `数据长度 / 发送速率(带宽)` |
| **传播时延** | 电磁波在信道中**传播一定距离**的时间 | `信道长度 / 电磁波传播速率` |
| **处理时延** | 路由器分析首部、查找转发表等的时间 | — |
| **排队时延** | 分组在路由器**输入 / 输出队列**中排队的时间 | — |

电磁波传播速率：铜缆 / 光纤中约 **2×10⁸ m/s**，真空中 3×10⁸ m/s。

> [!example] 算一算（对应上图）
> 取分组大小 **1000 B = 8000 bit**，链路速率 **100 Mbps**，铜缆 **1000 km**（v = 2.3×10⁵ km/s）：
> - 发送时延 = 8000 / (100×10⁶) = **8×10⁻⁵ s = 80 μs**
> - 传播时延 = 1000 / (2.3×10⁵) ≈ **4.35×10⁻³ s = 4.35 ms**
>
> 可见此处**传播时延远比发送时延大**，瓶颈在「距离」而不在「速率」。

> [!warning] 高速链路只降低「发送时延」
> 提高带宽只能缩短**发送时延**；**传播时延由信道长度和电磁波速度决定，与带宽无关**。所以「网络快不快」要看瓶颈在哪一段。

### 6. 时延带宽积

```
时延带宽积 = 传播时延 × 带宽
```

- 单位是 **bit**，又称「**以比特为单位的链路长度**」。
- 物理意义：链路中「正在飞行」的比特数，相当于这条链路的**管道容积**（链路越长、带宽越大，能容纳的在途比特越多）。

### 7. 往返时延 RTT

**定义**：从发送方**发出数据**到发送方**收到接收方的确认**所经历的总时间。

- 包含：**往返传播时延** + 接收方**处理时延** + 接收方**发送确认时延** + 途经节点的处理 / 排队时延。
- 日常说的「游戏延迟」通常就是 RTT。
- **RTT 越大，在收到确认前可发送的数据越多**（与「停等协议」的效率相关）。

> [!warning] 发送时延是否计入，取决于计时起点
> - 若从「**开始发送**数据」计时 → **包含**发送方把数据推上链路的发送时延；
> - 若从「**发送完毕**」计时 → **不包含**发送方的发送时延。
> 做题时以题目给定的口径为准。

### 8. 信道利用率

- 定义：某信道**有数据通过的时间**占总时间的比例。
- `信道利用率 = 有数据通过的时间 / 总时间`
- 也可写成：`利用率 = 数据总量 / (发送速率 × 总时间)`。
- **过低** → 浪费资源；**过高** → 容易造成拥塞、时延剧增。

---

## 三、易错点 / 注意事项

- **网速十进制（1 kBps = 1000 Bps），内存二进制（1 KiB = 1024 B）**，切勿混用。
- **发送时延**取决于「数据长度 ÷ 带宽」；**传播时延**取决于「距离 ÷ 电磁波速度」，二者别搞反。
- **提高带宽只减少发送时延，传播时延不变**——高速链路不等于低时延。
- **带宽是上限（最高速率），吞吐量是实际值，吞吐量 ≤ 带宽**。
- **时延带宽积的单位是 bit**，不是秒。
- **RTT 是往返**（含回程 + 确认），别只算单程；是否含发送时延看计时起点。
- 「速率 / 带宽」用**十进制**单位换算（1 Gbps = 10⁹ bps）。

---

## 四、小结

- 分类五维：**分布范围（WAN / MAN / LAN / PAN）· 传输技术（广播 / 点对点）· 拓扑（总线 / 环 / 星 / 网状）· 使用者（公用 / 专用）· 传输介质（有线 / 无线）**。
- 性能指标：**速率、带宽、吞吐量、时延、时延带宽积、RTT、信道利用率**。
- 核心公式：`总时延 = 发送 + 传播 + 处理 + 排队`；`时延带宽积 = 传播时延 × 带宽`。
- 记牢三组对比：**十进制 vs 二进制**、**发送时延 vs 传播时延**、**带宽 vs 吞吐量**。
