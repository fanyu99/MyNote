## 一、命令结构与选项作用域

```bash
ffmpeg [全局选项] [输入选项] -i 输入文件 [输出选项] 输出文件
```

**选项的位置很重要**，同一个参数放在 `-i` 前后，含义可能完全不同：

| 参数 | 放在 `-i` 前 | 放在 `-i` 后 |
| --- | --- | --- |
| `-ss 00:01:00` | 输入侧快速定位，跳到最近关键帧 | 输出侧裁剪，重编码时更精确，先解码再丢弃 |
| `-t 30` | 限制读取输入的时长 | 限制输出时长 |
| `-re` | 按原始帧率读取，常用于推流 | 不适用（输入选项必须放在 `-i` 前） |

常用全局选项：

| 选项 | 作用 |
| --- | --- |
| `-y` / `-n` | 覆盖 / 不覆盖输出文件 |
| `-hide_banner` | 隐藏版权与编译信息 |
| `-loglevel error` | 只显示错误 |
| `-stats` | 显示处理进度 |

> [!tip] 最小上手
> - 看信息：`ffprobe -v error -show_format -show_streams input.mp4`
> - 标准转码：`ffmpeg -i input.mp4 -c:v libx264 -crf 23 -pix_fmt yuv420p -c:a aac -b:a 128k output.mp4`
> - 只换容器：`ffmpeg -i input.mkv -c copy output.mp4`

## 二、参数总表

| 参数 | 作用 |
| --- | --- |
| `-i` | 输入文件 |
| `-c:v` / `-c:a` / `-c:s` | 视频/音频/字幕编码器 |
| `-c copy` | 所有流直接复制，不重新编码 |
| `-b:v` / `-b:a` | 视频/音频目标码率 |
| `-crf` | 恒定质量（x264/x265） |
| `-r` | 输出帧率 |
| `-s` / `-vf scale` | 输出分辨率 |
| `-ar` / `-ac` | 音频采样率 / 声道数 |
| `-pix_fmt` | 像素格式 |
| `-map` | 选择输入流 |
| `-vn` / `-an` / `-sn` / `-dn` | 禁用视频/音频/字幕/数据流 |
| `-ss` / `-t` / `-to` | 起始时间 / 时长 / 结束时间 |
| `-vf` / `-af` / `-filter_complex` | 视频滤镜 / 音频滤镜 / 复杂滤镜图 |
| `-g` | GOP 长度 |
| `-preset` / `-tune` | 编码速度 / 内容优化 |
| `-movflags +faststart` | 把 MP4 索引移到文件头，利于网络播放 |
| `-f` | 强制指定容器格式 |
| `-y` | 覆盖输出文件 |

## 三、查看信息

```bash
# 查看容器与所有流
ffprobe -v error -show_format -show_streams input.mp4

# 只看视频流关键信息
ffprobe -v error -select_streams v:0 \
  -show_entries stream=codec_name,width,height,r_frame_rate,avg_frame_rate,bit_rate,pix_fmt,color_space,color_range,time_base \
  -of default=noprint_wrappers=1 input.mp4

# 查看时长、文件大小、总码率
ffprobe -v error -show_entries format=duration,size,bit_rate \
  -of default=noprint_wrappers=1 input.mp4

# 查看 ffmpeg 支持的容器/格式
ffmpeg -formats
```

> [!tip] 排查第一步永远是 ffprobe
> 确认容器、编码、像素格式、色彩范围、时间基、流数量，再决定是重封装还是转码。相关概念见 [[容器与封装]]、[[视频参数]]、[[时间轴与同步]]。

## 四、转码与压缩

```bash
# 通用转码：H.264 + AAC，兼容性最好
ffmpeg -i input.mp4 -c:v libx264 -preset medium -crf 23 \
  -pix_fmt yuv420p -c:a aac -b:a 128k output.mp4

# 高质量小体积：更慢的 preset + 更低 CRF
ffmpeg -i input.mp4 -c:v libx264 -preset slow -crf 20 \
  -pix_fmt yuv420p -c:a aac -b:a 160k output.mp4

# 固定码率（直播/带宽受限）
ffmpeg -i input.mp4 -c:v libx264 -preset veryfast -b:v 2500k \
  -maxrate 2500k -bufsize 5000k -c:a aac -b:a 128k output.mp4

# 指定 H.264 Profile / Level
ffmpeg -i input.mp4 -c:v libx264 -profile:v high -level 4.1 \
  -crf 23 -c:a aac -b:a 128k output.mp4
```

```bash
# 用 VMAF 比较两个视频（需要 ffmpeg 带 libvmaf）
ffmpeg -i distorted.mp4 -i reference.mp4 -lavfi libvmaf -f null -
```

> [!tip] CRF 怎么选
> 离线转码优先 CRF：18 左右接近视觉无损，23 常用，28 体积更小。码率控制模式见 [[视频参数#七、码率与码率控制]]。

## 五、重封装与流操作

流的选择用 **stream specifier**，格式是「输入序号:流类型:流序号」：

```bash
0:v:0     # 第 0 个输入的第 0 条视频流
0:a:1     # 第 0 个输入的第 1 条音频流（从 0 开始）
0:s:0     # 第 0 个输入的第 0 条字幕流
```

> [!warning] 默认只选一条
> ffmpeg 默认通常只选一条视频、一条音频（以及部分容器下的一条字幕），多音轨、多字幕很容易被丢掉。想全部保留用 `-map 0`，想精确选择用 `-map 0:v:0 -map 0:a:1`。

重封装与流操作：

```bash
# 只换容器，不重新编码
ffmpeg -i input.mkv -c copy output.mp4

# 显式指定输出容器（当扩展名不能表达时）
ffmpeg -i input.mp4 -c copy -f mpegts output.ts

# MP4 网络播放优化：把 moov 移到文件头
ffmpeg -i input.mp4 -c copy -movflags +faststart output.mp4

# 保留所有流（多音轨、多字幕）
ffmpeg -i input.mkv -map 0 -c copy output.mkv

# 只保留第一条视频和第二条音频
ffmpeg -i input.mkv -map 0:v:0 -map 0:a:1 -c copy output.mkv

# 去掉字幕流
ffmpeg -i input.mkv -map 0 -map -0:s -c copy output.mkv
```

> [!warning] 重封装的兼容性
> `-c copy` 到 MP4 时，如果视频/音频/字幕编码不被 MP4 支持（例如 ASS 字幕、某些 DTS 音轨），会报 `Could not find tag for codec ...`。此时要么换 MKV，要么重新编码对应流。

## 六、提取与替换

```bash
# 去掉视频流，只保留音频（-vn = video no）
ffmpeg -i demo.mp4 -vn demo.mp3

# 提取音频（原样复制）
ffmpeg -i input.mp4 -vn -c:a copy output.m4a

# 提取音频并转 MP3
ffmpeg -i input.mp4 -vn -c:a libmp3lame -b:a 192k output.mp3

# 提取 PCM WAV
ffmpeg -i input.mp4 -vn -c:a pcm_s16le -ar 48000 -ac 2 output.wav

# 多声道转立体声
ffmpeg -i input.mp4 -vn -ac 2 -c:a aac -b:a 192k output.m4a

# 响度标准化（常用 -16 LUFS）
ffmpeg -i input.mp4 -af "loudnorm=I=-16:TP=-1.5:LRA=11" \
  -c:v copy -c:a aac -b:a 192k output.mp4

# 替换视频中的音频
ffmpeg -i video.mp4 -i audio.mp3 -map 0:v:0 -map 1:a:0 \
  -c:v copy -c:a aac -b:a 192k -shortest output.mp4

# 提取第一条文本字幕（输出 SRT）
ffmpeg -i input.mkv -map 0:s:0 output.srt
```

> [!tip] 音频参数
> 采样率、位深、声道、PCM 码率的含义见 [[音频基础]]；响度目标见 [[音频基础#六、音频同步与响度]]。

## 七、裁剪、抽帧与截图

```bash
# 快速裁剪（-ss 在 -i 前；-c copy 只能切在关键帧）
ffmpeg -ss 00:01:00 -i input.mp4 -t 30 -c copy output.mp4

# 精确裁剪（重新编码）
ffmpeg -i input.mp4 -ss 00:01:00 -t 30 \
  -c:v libx264 -crf 23 -c:a aac -b:a 128k output.mp4

# 每秒抽一帧
ffmpeg -i input.mp4 -vf fps=1 frame_%04d.jpg

# 截取第 5 秒的一帧
ffmpeg -ss 00:00:05 -i input.mp4 -frames:v 1 shot.png

# 只抽关键帧
ffmpeg -i input.mp4 -vf "select='eq(pict_type,I)'" -fps_mode vfr key_%04d.jpg

# 只解码关键帧（更快的关键帧抽取）
ffmpeg -skip_frame nokey -i input.mp4 -fps_mode passthrough key_%04d.png
```

时间戳修正与 GOP 控制：

```bash
# 保持原始时间戳，并把起始时间归零
ffmpeg -copyts -start_at_zero -i input.mp4 -c copy output.mp4

# 避免负时间戳
ffmpeg -i input.mp4 -c copy -avoid_negative_ts make_zero output.mp4

# 重新生成缺失的时间戳
ffmpeg -fflags +genpts -i input.mp4 -c copy output.mp4

# 固定 GOP：25fps 下 50 帧约 2 秒
ffmpeg -i input.mp4 -c:v libx264 -crf 23 -g 50 -keyint_min 50 -sc_threshold 0 output.mp4

# 按时间强制关键帧（每 2 秒一个）
ffmpeg -i input.mp4 -c:v libx264 -crf 23 \
  -force_key_frames "expr:gte(t,n_forced*2)" output.mp4
```

> [!note] 为什么裁剪可能不准
> 使用 `-c copy` 时，视频只能从关键帧开始切，所以起点可能比指定时间提前。需要精确裁剪就重新编码。原理见 [[编码原理与帧类型#五、seek 与抽帧为什么慢]]。

## 八、缩放、帧率与图片序列

```bash
# 缩放到 720p，宽度自动计算并保证偶数
ffmpeg -i input.mp4 -vf "scale=-2:720" -c:v libx264 -crf 23 -c:a copy output.mp4

# 改帧率（用 fps 滤镜，更可控）
ffmpeg -i input.mp4 -vf "fps=30" -c:v libx264 -crf 23 -c:a copy output.mp4

# 强制输出 30fps（会复制/丢帧）
ffmpeg -i input.mp4 -r 30 -c:v libx264 -crf 23 -c:a copy output.mp4

# 保留可变帧率
ffmpeg -i input.mp4 -fps_mode vfr -c:v libx264 -crf 23 -c:a copy output.mp4

# 图片序列合成视频
ffmpeg -framerate 30 -i frame_%04d.png -c:v libx264 -pix_fmt yuv420p output.mp4

# 叠加水印（filter_complex 多输入滤镜图）
ffmpeg -i input.mp4 -i logo.png -filter_complex "[0:v][1:v]overlay=10:10" \
  -c:v libx264 -crf 23 -c:a copy output.mp4

# 裁剪画面（宽:高:x:y）
ffmpeg -i input.mp4 -vf "crop=1280:720:0:0" -c:v libx264 -crf 23 -c:a copy output.mp4
```

> [!note] `-vsync` 与 `-fps_mode`
> 新版本 ffmpeg 用 `-fps_mode cfr|vfr|passthrough|auto` 替代了旧的 `-vsync`。老脚本里看到 `-vsync 0/1/2` 也不必奇怪，含义相近。

## 九、合并、字幕与推流

```bash
# 合并同编码文件：先写 list.txt
# file 'a.mp4'
# file 'b.mp4'
ffmpeg -f concat -safe 0 -i list.txt -c copy output.mp4

# 烧录字幕（硬字幕，必须重新编码）
ffmpeg -i input.mp4 -vf "subtitles=sub.srt" \
  -c:v libx264 -crf 23 -c:a copy output.mp4

# 给 MP4 添加软字幕
ffmpeg -i input.mp4 -i sub.srt -map 0 -map 1 \
  -c copy -c:s mov_text output.mp4

# 推流到 RTMP
ffmpeg -re -i input.mp4 -c:v libx264 -preset veryfast \
  -b:v 2500k -maxrate 2500k -bufsize 5000k \
  -c:a aac -b:a 128k -f flv rtmp://server/live/stream
```

> [!note] 字幕格式
> MP4 常用 `mov_text`，ASS 复杂样式会丢失；MKV 对 ASS/SSA 支持最好。字幕类型见 [[容器与封装#六、字幕的封装]]。

## 十、硬件加速

先查看本机支持哪些能力：

```bash
# 查看支持的硬件加速 API
ffmpeg -hwaccels

# 查看可用编码器 / 解码器
ffmpeg -encoders
ffmpeg -decoders
```

常见硬件编码示例：

```bash
# NVIDIA 解码 + 编码
ffmpeg -hwaccel cuda -i input.mp4 -c:v h264_nvenc -preset p5 -cq 23 \
  -c:a aac -b:a 128k output.mp4

# Intel QSV
ffmpeg -hwaccel qsv -i input.mp4 -c:v h264_qsv -global_quality 23 \
  -c:a aac -b:a 128k output.mp4

# macOS VideoToolbox
ffmpeg -i input.mp4 -c:v h264_videotoolbox -b:v 5M -c:a aac -b:a 128k output.mp4
```

> [!tip] 硬件加速怎么选
> 先运行 `ffmpeg -hwaccels` 看支持哪些 API，再运行 `ffmpeg -encoders | grep`（Windows 用 `findstr`）看有没有对应的编码器。硬件编码通常用 `-cq` / `-global_quality` 而不是 `-crf`。

## 十一、小结

- **命令结构**：`ffmpeg [全局选项] [输入选项] -i 输入 [输出选项] 输出`；注意 `-ss` 等选项的位置。
- **查看信息**用 `ffprobe`，先确认容器、编码、像素格式、色彩范围、时间基和流数量。
- **通用转码**优先 `libx264 + CRF + yuv420p + AAC`，兼容性最好。
- **重封装**用 `-c copy`，只换容器；要改画面参数必须重新编码。
- **流选择**用 stream specifier 和 `-map`，默认只选一条流。
- **裁剪**分快速（关键帧）和精确（重编码）；抽帧按时间或关键帧筛选。
- **字幕**分软字幕和硬字幕；硬字幕必须重新编码。
- **硬件加速**先查 `-hwaccels` 和 `-encoders`，同码率画质通常不如软件编码。
