## 一、容器与编码

- ==🔴 扩展名 ≠ 容器==：改后缀不会转封装，也不会转码。
- ==🔴 `-c copy` 不能加滤镜、改分辨率、改码率==：需要重新编码。
- ==🔴 `-c copy` + `-ss` 只能切在关键帧==：起点可能提前，精确裁剪要重编码。
- ==🔴 MP4 兼容性==：H.264 + yuv420p + AAC 最稳；H.265/AV1/10bit 老设备可能不支持。
- ==🔴 `-movflags +faststart`==：网络播放的 MP4 建议加上，否则可能要下完整个文件才能播。

相关：[[容器与封装#五、重封装 vs 转码]]、[[命令实操#五、重封装与流操作]]

## 二、视频参数

- ==🔴 宽高必须是偶数==：`yuv420p` 要求偶数，缩放用 `scale=1280:-2`。
- ==🔴 色彩范围错配==：limited/full 弄反会发灰或死黑，检查 `color_range`。
- ==🔴 色彩矩阵错配==：BT.601/BT.709 弄反会偏色，SD ↔ HD 转码时注意。
- ==🔴 VFR 素材直接 `-r`==：会复制/丢帧，可能卡顿或音画不同步；用 `fps` 滤镜或 `-fps_mode`。
- ==🔴 10bit 转 8bit==：`-pix_fmt yuv420p` 是有损转换，会丢色深。
- ==🔴 `-crf` 与 `-b:v` 混用==：通常二选一；要限制峰值用 `-crf` + `-maxrate` + `-bufsize`。
- ==🔴 CRF 跨编码器不可比==：x264 23 ≠ x265 23 ≠ NVENC cq 23。
- ==🔴 `-sameq` 已废弃==：它不等于「同质量」，不要再用。

相关：[[视频参数#六、像素格式与色彩]]、[[视频参数#七、码率与码率控制]]

## 三、时间与同步

- ==🔴 时间戳不从 0 开始==：拼接/裁剪可能出问题，用 `-avoid_negative_ts make_zero` 或 `-start_at_zero`。
- ==🔴 负 DTS / 非单调 DTS==：会出现 `Non-monotonous DTS`，用 `-fflags +genpts`、`-fps_mode cfr` 等修正。
- ==🔴 音频比视频长==：尾部可能黑屏/静音，用 `-shortest`。
- ==🔴 音频采样率不一致==：可能导致音画不同步，用 `-ar` 或 `aresample=async=1`。

相关：[[时间轴与同步#三、时间戳的常见坑]]、[[命令实操#七、裁剪、抽帧与截图]]

## 四、流、字幕与旋转

- ==🔴 默认只选一条流==：多音轨/多字幕容易丢，用 `-map 0` 或精确 `-map`。
- ==🔴 字幕编码不兼容==：MP4 用 `mov_text`，MKV 用 `copy`；ASS 复杂样式在 MP4 中会丢失。
- ==🔴 烧录字幕必须重新编码==：`subtitles` 滤镜不能和 `-c:v copy` 同用。
- ==🔴 手机视频旋转 metadata==：ffmpeg 默认自动旋转；`-noautorotate` 可关闭；旋转后宽高可能互换。

相关：[[容器与封装#六、字幕的封装]]、[[命令实操#九、合并、字幕与推流]]

## 五、常见报错速查

| 报错 | 常见原因 | 解决 |
| --- | --- | --- |
| `moov atom not found` | MP4 未写完或损坏 | 重新获取文件；输出时加 `-movflags +faststart` |
| `Unknown encoder 'libx264'` | 当前构建不含该编码器 | `ffmpeg -encoders` 查看；换完整构建 |
| `height not divisible by 2` | yuv420p 要求偶数尺寸 | `scale=1280:-2` |
| `Could not find tag for codec ...` | 容器不支持该编码 | 换 MKV，或重新编码 |
| `Filtergraph ... not connected` | 滤镜输入/输出未映射 | 检查 `-map` 和滤镜图 |
| `Non-monotonous DTS` | 时间戳回退/乱序 | `-fflags +genpts`、`-avoid_negative_ts make_zero` |
| `Output file #0 does not contain any stream` | 没有选中任何流 | 加 `-map` 明确选择 |
| `Permission denied` | 文件被占用或无权限 | 关闭占用程序，换输出路径 |

## 六、排错顺序

遇到 ffmpeg 报错或输出异常，按这个顺序排查：

1. **先 `ffprobe`**：确认容器、编码、分辨率、像素格式、色彩范围、时间基、流数量。
2. **判断问题类型**：是容器不兼容、编码器不可用、滤镜图错误，还是时间戳/同步问题。
3. **决定重封装还是转码**：只换容器用 `-c copy`；要改画面参数必须重新编码。
4. **检查流选择**：多音轨/多字幕是否被默认丢掉；必要时用 `-map 0`。
5. **检查颜色与像素格式**：limited/full、BT.601/709、8bit/10bit 是否匹配。
6. **检查时间戳**：`start_time`、负 DTS、VFR、`Non-monotonous DTS`。
7. **最后再调质量参数**：CRF、preset、码率、GOP；不要在容器/时间戳问题没解决时先调画质。

> [!tip] 最小排查命令
> ```bash
> ffprobe -v error -show_format -show_streams input.mp4
> ```
> 90% 的问题能从这个输出里看出线索。
